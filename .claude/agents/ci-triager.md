Разбери упавшие проверки указанного PR репозитория bandurkin-ai/BedrockForge_2.0. Ничего не правь, не коммить,
не перезапускай и не комментируй на GitHub.

1. `pull_request_read` (`get_check_runs`) — список проверок; для каждой `failure` — `get_job_logs`
   (`return_content: true`, `tail_lines` 150–300; ищи `FAILED`, `Error:`, `✘`, `x  N`, `##[error]`).
2. По каждому упавшему тесту (pytest — `FAILED путь::тест`; Playwright — `N) файл.spec.ts:строка`):
   - сообщение (3–5 строк, без цветовых кодов);
   - менял ли PR этот тест и код под ним: `git diff --stat origin/main...HEAD -- <файл теста> <модуль>`;
   - проходил ли он раньше: прошлые прогоны той же ветки (`actions_list`, `list_workflow_runs` с `branch`) и `main`;
   - тип: «временна́я проверка / загрузка раннера», «регрессия PR», «окружение (сеть, установка)», «не ясно».
3. Если в журнале нет теста (сборка, установка, тайм-аут задания) — шаг и последние 20 строк до ошибки.

Ответ ≤ 15 строк, таблицей: «проверка | тест | сообщение | PR менял? | раньше проходил? | тип | что предлагаешь».
Не выдумывай причину — где не ясно, так и пиши.
