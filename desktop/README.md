# BedrockForge by Mikhail Bandurkin — программа для Windows 11

Тонкий клиент из `docs/DESKTOP.md`, часть 1: окно программы вместо браузера и контейнера `web`. Сервер (`api`, `db`, `worker`) работает в Docker как раньше.

## Запуск

| Шаг | Что сделать |
|---|---|
| 1 | Запустить Docker Desktop и `scripts/BedrockForge.bat` (поднимает сервер на `localhost:8000`) |
| 2 | Запустить `BedrockForge-<версия>-portable.exe` — без установки, или поставить `BedrockForge-<версия>-setup.exe` |
| 3 | SmartScreen «Неизвестный издатель»: **Подробнее → Выполнить в любом случае** (сертификата подписи нет) |

- Пока идёт запуск, показана заставка **BedrockForge by Mikhail Bandurkin**.
- Если сервер недоступен, заставка показывает причину, поле адреса сервера и повторяет подключение каждые 3 с — после старта Docker программа откроется сама.
- Адрес сервера по умолчанию `http://localhost:8000`; меняется на заставке или переменной `BF_SERVER` (только на один запуск).

## Клавиши окна

| Клавиша | Действие |
|---|---|
| `F5` / `Ctrl+F5` | Перезагрузить интерфейс / без кеша |
| `F11` | Полный экран |
| `Ctrl+Shift+I` | Инструменты разработчика |

Остальные клавиши — у приложения (`Ctrl+K`, `Ctrl+F1`, `T`, `X`, `F` и т. д.); своего меню у окна нет, чтобы не перехватывать их.

## Где что лежит

| Что | Где |
|---|---|
| Настройки окна и адрес сервера | `%APPDATA%\BedrockForge\settings.json` |
| Журнал клиента | `%APPDATA%\BedrockForge\logs\desktop.log` |
| Интерфейс | внутри `.exe` (`resources\web`), собирается из `web/` |

## Сборка

Готовые файлы собирает GitHub Actions (`.github/workflows/desktop.yml`, `windows-latest`): вкладка **Actions → Desktop (Windows) → артефакт BedrockForge-windows**, в нём `.exe` и `SHA256SUMS.txt`. Тег `v*` дополнительно создаёт черновик выпуска.

Вручную на Windows (нужен Node.js 22):

```bat
cd desktop
npm ci
npm run dist
```

Результат — в `desktop\release\`. Запуск из исходников без сборки: `npm --prefix ..\web run build`, затем `npm start`.

## Устройство

| Файл | Назначение |
|---|---|
| `src/main.js` | Главный процесс: заставка, окно, протокол `app://bedrockforge`, пересылка `/api/*` и `/mcp` на сервер |
| `src/proxy.js` | Чистые функции протокола: пути, CSP, заголовки, разрешённые внешние адреса (покрыты `npm test`) |
| `src/preload.js` | Мост `window.bfDesktop` для окна: адрес сервера, версия, открытие ссылки в системном браузере |
| `src/ui/` | Заставка и экран «Сервер недоступен», значок |

Безопасность (K4): `contextIsolation`, `sandbox`, без `nodeIntegration`; строгий CSP (встроенные скрипты — только по хешу); переход на чужие адреса запрещён; во внешнем браузере открываются только `https` адреса Anthropic, Claude и GitHub; запросы уходят только на адрес сервера из настроек. Для ноутбуков с двумя видеокартами запрашивается дискретная (P3).
