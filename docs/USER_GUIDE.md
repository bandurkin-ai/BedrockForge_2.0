# BedrockForge 2 — руководство пользователя

Руководство дополняется на каждом этапе: разделы — по вкладкам ленты и модулям.

## Запуск
| Вариант | Как работает |
|---|---|
| `BedrockForge-x.y.z-portable.exe` | Без установки. При первом запуске распаковывается рядом с собой (папка `BedrockForge-x.y.z`), если папка только для чтения — в `%LOCALAPPDATA%\BedrockForge\portable\x.y.z`; дальше запуск сразу |
| `BedrockForge-x.y.z-setup.exe` | Установщик для текущего пользователя, права администратора не нужны |

- Без подписи кода Windows SmartScreen покажет «Неизвестный издатель»: «Подробнее» → «Выполнить в любом случае».
- При запуске показывается заставка, пока не будет готово вычислительное ядро; затем открывается главное окно.
  Если ядро не запустилось, заставка показывает причину и кнопки «Скопировать журнал», «Закрыть».
- Запускается один экземпляр программы.
- Журналы: `%LOCALAPPDATA%\BedrockForge\logs\` (`shell.log` — оболочка, `core.log` — ядро).
- Служебные клавиши окна: `F5` — перезагрузить окно, `F11` — полный экран, `Ctrl+Shift+I` — инструменты разработчика.

## Интерфейс
**Заголовок:** логотип «BedrockForge by Mikhail Bandurkin», выбор проекта ⚙, поиск команд `Ctrl+K`,
кнопка темы, значок ⓘ «О производителе» (справа от переключателя темы), кнопка «Claude».

**Лента** — 6 вкладок. `Ctrl+F1` сворачивает ленту. При узком окне группы справа ужимаются:
сначала малые кнопки, затем только значки.

| Вкладка | Назначение |
|---|---|
| «Главная» | Проект, импорт, настройка (в т. ч. «О производителе»), лицензия |
| «Вид» | Поворот вида («В план», «Сбоку», «Вписать», «Разрез»), окно, слои, стиль, панели |
| «Моделирование» | Построение моделей (по этапам); «Поверхности» › «Построить ЦТМ» |
| «Анализ» | Группа «Аудит и статистика», графики, отчёты (по этапам) |
| «Настройки проекта» | Группа «Обслуживание» › «Очистить выполненные задания» |
| «Claude» | Ассистент |

Кнопки будущих этапов видны, но серые, с причиной «Функция появится на этапе ЭN».

**Дерево данных** (слева) — 8 разделов: «Виды» (первым), «Скважины», «Каркасы», «ЦТМ», «Линии», «Растры», «Блочные модели», «Аудит и статистика».

| Действие | Как |
|---|---|
| Свернуть/развернуть раздел или узел | только стрелка ▸/▾ |
| Выбрать | щелчок по названию (по набору — активный набор, в строке состояния «Набор: …») |
| Действие по умолчанию | двойной щелчок (набор — таблица, отображение — форма) |
| Клавиши | `↑`/`↓`; `→` раскрыть / войти; `←` свернуть / к родителю; `Enter` — выбрать; пробел — галочка; `Home`/`End` |
| Изменить порядок разделов | перетащить заголовок |
| Добавить объект | «+» у раздела |
| Меню раздела | правая кнопка мыши |
| Импорт с заданным типом | перетащить файлы из Проводника на раздел |
| Пустое дерево | кнопка «Загрузить демо-проект» |

**Панели**

| Место | Вкладки |
|---|---|
| Справа | «Свойства», «Claude» |
| Снизу | «Таблица», «Аудит и статистика», «Статистика», «Swath plot», «Задания», «Журнал команд» (`Ctrl+Ё`) |
| Строка состояния | ядро, проект, набор, выбор, вид, Claude, аудит |

«Журнал команд»: время, кто («Вы» / «Claude»), команда, параметры, результат; последние 200.

**Палитра команд `Ctrl+K`:** поиск по названию, пути «вкладка › группа» и подсказке; до 60 результатов;
`↑`/`↓` — выбор, `Enter` — выполнить, `Esc` — закрыть. Запрос «скв » ищет скважины (с Э4).

**Окна и диалоги** — собственные: плавающие окна (перетаскивание, размер, развернуть, закрыть;
щёлкнутое выходит наверх), подтверждения, сообщения с кнопками «Скопировать» и «Сохранить .txt».

**Темы:** тёмная (по умолчанию) и светлая; выбор запоминается.

**Фирменный стиль:** палитра Anthracite / Cobalt / Copper Orange / Light Stone / Slate; шрифты Montserrat (заголовки) и Inter (текст) встроены, интернет не нужен; знак-куб в заголовке и на заставке; иконка у приложения.

### Горячие клавиши по умолчанию
Работают в русской и английской раскладке. Одиночные клавиши не срабатывают в поле ввода.

| Клавиша | Действие |
|---|---|
| `T` | «В план» — вид сверху на то, что на экране |
| `X` | «Сбоку Z/X» — вид на север |
| `Y` | «Сбоку Z/Y» — вид на запад |
| `F` | «Вписать» — показать всё, не поворачивая вид |
| `S` | «Разрез» — провести линию разреза |
| `C` | «Отсечение» по окну разреза |
| `[` / `]` | Предыдущий / следующий профиль разреза |
| `Esc` | Снять выбор скважины |
| `Ctrl+Shift+F` | Счётчик кадров 3D («Счётчик кадров») |
| `Ctrl+Shift+H` | «Очистить окно» — скрыть все объекты в 3D |
| `Ctrl+Z` / `Ctrl+Y` | В форме отображения: отменить / повторить правку |
| `Ctrl+K` | Палитра команд |
| `Ctrl+J` | Панель «Claude» |
| `Ctrl+B` | Дерево данных |
| `Ctrl+Ё` | Нижняя панель (клавиша над Tab) |
| `Ctrl+F1` | Свернуть/развернуть ленту |

## Проекты
Окно «Проекты»: кнопка с названием проекта в заголовке (или «Проект не открыт»), «Главная» › «Проекты», `Ctrl+K` → «Проекты».

| Блок | Что в нём |
|---|---|
| «Открытый проект» | Название, «Переименовать», «Экспорт»; поля «Месторождение», «Лицензия», «Стадия работ» (сохраняются при уходе из поля); даты создания и изменения; состав: наборы скважин, скважины, замеры, пробы, интервалы таблиц, каркасы, линии, растры, блочные модели, графики, диалоги Claude |
| «Все проекты» | Поиск по названию и описанию; у строки — число скважин и объектов, дата изменения; «Открыть» (или двойной щелчок), значки «Переименовать», «Экспорт», «Удалить» |
| Внизу | «Новый проект», «Демо-проект», «Импорт…» |

- Названия уникальны без учёта регистра: занятое название отклоняется сообщением.
- При запуске открывается последний проект. Каждое изменение записывается сразу; если ядро аварийно завершилось, подтверждённые правки сохранены.
- «Удалить» — с подтверждением; вся папка проекта удаляется.
- Проект, открытый в другом окне BedrockForge, открывается «только чтение».

**Где хранятся.** Папка `<Название>.bfproj` в `Документы\BedrockForge\Проекты` (меняется в «Настройка» › «Общие», действует после перезапуска).

| Внутри папки | Назначение |
|---|---|
| `project.bfproj`, `project.sqlite` | Описание и данные проекта |
| `blobs`, `cache` | Хранилище файлов и кеш |
| `backups` | Автокопия раз в сутки, хранятся 5 последних |
| `logs`, `project.lock` | Журналы; отметка «проект открыт» |

Сетевые диски не поддерживаются; путь к проекту — не длиннее 180 символов.

## Перенос проекта (`.bfggis`)
Весь проект — один сжатый файл для другого компьютера.

**Экспорт:** «Главная» › «Экспорт проекта», «Экспорт» в окне «Проекты» или значок в строке проекта.

| Элемент окна | Назначение |
|---|---|
| Состав | Что войдёт в файл |
| «Сохранить как…» | Имя по умолчанию «<Название>_ГГГГ-ММ-ДД.bfggis» |
| «Пароль», «Повтор пароля» | Необязательно: шифрование AES-256; пароль нигде не сохраняется — без него файл не открыть |
| «Настройки вида» | Видимость слоёв, стили, порядок дерева |

Экспорт идёт заданием `export.project` во вкладке «Задания»; у готового — «Показать в папке».

**Импорт:** «Главная» › «Импорт проекта», «Импорт…» или перетащить `.bfggis` на окно.

| Шаг | Что происходит |
|---|---|
| Проверка | Название, описание, дата экспорта, версии программы и схемы, состав; для зашифрованного файла — пароль («Неверный пароль» — импорт не начинается) |
| Название занято | «Создать копию «Имя (2)»», «Другое название» или «Заменить существующий» (старый проект удаляется только после успешного импорта) |
| «Применить настройки вида из файла» | Если они есть в файле |
| Импорт | Задание `import.project`; у готового — «Открыть проект» |

- Оборванный или повреждённый файл не оставляет ничего; заменяемый проект остаётся целым.
- Файл новее программы отклоняется: «обновите программу».
- Файлы BedrockForge 1 распознаются (название, состав), но перенос их данных появится на следующих этапах: кнопка «Импортировать» серая.

## Импорт скважин
«Главная» › «Скважины» (`import.open`) открывает мастер «Импорт скважин». Файлы можно перетащить из Проводника на окно (DAT, CSV, TXT, Excel) — мастер откроется с ними.

| Шаг | Что загружается |
|---|---|
| «1. Устья» | Collar |
| «2. Инклинометрия» | Survey |
| «3. Интервалы и события» | Пробы, интервальные таблицы, события |
| «4. Импорт» | Набор, система координат, запуск |

Заголовок показывает «Шаг N из 4». «Добавить файлы…» принимает несколько файлов сразу: каждый попадает на шаг по определённому типу таблицы.

**«Главная» › «Импорт файлов»** (`import.files`): выбор файлов и передача в нужный мастер.

| Файлы | Куда |
|---|---|
| Таблицы | «Импорт скважин» |
| `.bfggis` | Импорт проекта |
| Линии, точки, растры (и файлы привязки) | Окно «Импорт файлов», см. «Линии, растры, ЦТМ» |
| Каркасы, OMF | Сообщение, на каком этапе появятся: каркасы — Э8, OMF — Э11 |

**Форматы:** Micromine DAT (в том числе кодовая страница BOCU-1), CSV/TXT/TSV/PRN, Excel `.xlsx`/`.xlsm` и `.xls` (чтение).

### Карточка файла
| Элемент | Назначение |
|---|---|
| Сводка | Как прочитан файл |
| «Кодировка» | Авто, UTF-8, UTF-16, cp1251, cp866, KOI8-R, latin-1 |
| «Разделитель» | Авто, `;`, `,`, табуляция, `\|`, пробелы |
| «Лист» | Для книг Excel |
| «Строка заголовка» | Номер строки с названиями; 0 — без заголовка |
| «Строки файла» | Первые строки как в файле |
| «Тип таблицы» | «Устья», «Инклинометрия», «Пробы», «Интервальная таблица», «События» |
| «Название таблицы» | Для интервальных таблиц |

- Обязательные поля помечены `*`.
- Колонки назначаются сами по словарям Micromine, Datamine, Surpac, Vulcan, Leapfrog, acQuire и русским названиям; регистр, разделители и единицы не важны, названия, обрезанные до 8–10 символов, узнаются.
- Для проб: флажок «компонент» и единица (из названия: ppm, г/т, %, ppb). Остальные колонки можно сохранить как «атрибут».

### Числа и пропуски
| В файле | В проекте |
|---|---|
| Запятая или точка; пробелы между разрядами («4 584 699,70») | Число |
| «<0,005» | 0,0025 (половина); счётчик замен на экране |
| «>1000» | 1000; счётчик замен на экране |
| «-», «н/д», «н.о.», «NA», «N/A» | Пусто (не 0) |

### Замечания
- Список замечаний: текст в числовой колонке останавливает импорт.
- Флажок «Загрузить с ошибками — исправлю в BedrockForge»: значение становится пустым, исходный текст — в атрибуте «<колонка> (исходное)». Строка без номера скважины получает «БЕЗ НОМЕРА (строка N)», повторное устье — «<номер> (повтор k)».
- Ошибки назначения колонок так не загружаются.
- Предпросмотр показывает первые нормализованные строки.

### Шаг «4. Импорт»
| Элемент | Назначение |
|---|---|
| «Новый набор» | Название нового набора |
| «В существующий» | Выбор набора; заменяется только в нём («Заменить»): пробы — таблица проб набора (она одна), интервальные таблицы и события — таблица того же типа и названия |
| «Система координат» | «Из файла .prj…» |
| «Состав» | Что будет загружено и что заменится («заменит таблицу «…»») |
| «Импортировать» | Запускает задание «Импорт скважин» (вкладка «Задания») |

- Загружаются все файлы или ни одного.
- Несколько файлов устьев или инклинометрии объединяются; скважина в двух таких файлах — ошибка.
- Два файла в одну таблицу (например, два файла проб) не загружаются вместе: уберите лишний или переименуйте таблицу.
- Исходные файлы и назначение колонок хранятся в проекте (история импорта).
- Ориентир по скорости: 5 млн проб с номером пробы — около 40 с, около 1,8 ГБ памяти (тестовый компьютер).

### Журнал операции
Значок журнала в заголовке мастера (красный, если были ошибки) открывает журнал.

| В журнале | Содержимое |
|---|---|
| Среда | Время, версии, система, размер окна, проект |
| Файлы | Как прочитаны, назначение колонок, проверки |
| Запросы к ядру | Статус и время; пароли скрыты |
| Задание | Состояние, результат или ошибка и журнал задания — до его окончания, даже после закрытия мастера |
| Ошибки | `detail` и `trace` ядра |

Кнопки: «Копировать», «Сохранить .txt» (имя `bedrockforge-import-ГГГГ-ММ-ДД_чч-мм-сс.txt`), «Обновить». «OMF» › «Журналы» (`logs.open`) — последние 30 журналов сеанса. Во вкладке «Задания» у задания мастера — ссылка «журнал операции».

## Наборы скважин
Наборы лежат в дереве данных в разделе «Скважины».

| Действие | Как |
|---|---|
| Сделать набор активным и открыть его таблицу | щелчок по набору |
| Открыть «Устья» / «Инклинометрия» / «Пробы» | правая кнопка › одноимённый пункт |
| «Переименовать…» | правая кнопка |
| «Удалить…» | правая кнопка; с подтверждением; удаляются скважины, таблицы и история импорта набора |
| «Новый набор…» (`set.create`) | создаёт пустой набор; скважины добавляются вручную |

## Таблица
Вкладка «Таблица» нижней панели: выбор набора и вкладки таблиц с числом строк — «Устья», «Инклинометрия», «Пробы», остальные интервальные таблицы, события.

| Действие | Как |
|---|---|
| Прокрутка | Строки грузятся страницами: таблица на 5 млн строк не загружается целиком |
| Сортировка | Щелчок по заголовку: по возрастанию → по убыванию → выключена; пустые значения — в конце |
| Одна скважина | Щелчок по номеру скважины (кроме таблицы «Устья»); метка «Скважина … ✕» снимает отбор |
| Фильтр | Поле выражения: `Enter` — применить, `Esc` — очистить |
| Статистика колонки | Кнопка Σ в заголовке |

**Фильтр-выражение.** Пример: `AU > 0,5 и [Литология] = "гранит"`.

| Элемент | Правила |
|---|---|
| Связки | `и`, `или`, `не` |
| Имена | Если в имени пробел — в квадратных скобках: `[Литология]` |
| Аргументы функций | Через `;` |
| Проверка значений | `isnull(x)`, `notnull(x)`, `between(x; a; b)`, `inlist(x; a; b…)` |
| Числа | `abs`, `sqrt`, `log`, `log10`, `exp`, `round`, `floor`, `ceil`, `min`, `max` |
| Текст | `upper`, `lower`, `trim`, `contains` |

**Σ — статистика колонки:** заполнено, пусто, min, max, среднее, медиана, std; для текста — число уникальных и частые значения. Учитывается выбранная скважина и фильтр.

### Правка
| Действие | Как |
|---|---|
| Править ячейку | Щелчок по ячейке |
| Сохранить / следующая колонка / отмена | `Enter` / `Tab` / `Esc` |
| Очистить значение | Стереть текст и `Enter` |
| Числа | «12,5» и «12.5» — одно и то же, 12,5 |
| Новая строка | «+ Строка» (форма) |
| Удалить строку | 🗑 в начале строки |

Проверки при сохранении (нарушение — сообщение, правка не записывается):

| Проверка |
|---|
| Обязательные поля (помечены `*`) заполнены |
| «До» не меньше «От» |
| Второе устье с тем же номером скважины отклоняется |
| Переименование скважины в уже существующий номер отклоняется |

### Журнал правок
Кнопка «Журнал правок»: время, пользователь, таблица, скважина, что изменено (было → стало).

| Действие | Результат |
|---|---|
| «Отменить» у записи | Возвращает прежнее значение |
| Отмена удаления строки | Строка возвращается как новая |
| Отмена действия инструмента (замена, вычисляемое поле, объединение…) | Отменяется целиком сразу |

### Инструменты ▾
| Инструмент | Что делает |
|---|---|

## 3D-окно
Центральная область. Показывает устья и стволы всех видимых наборов; траектории рисуются с точностью до 1 см, координаты не округляются. Открытие проекта — до первого кадра не более 5 с (устья появляются первыми, затем стволы).

**Мышью:** вращение, сдвиг, масштаб. Проекция по умолчанию ортогональная. Положение камеры в проекте не хранится: при открытии проекта выполняется «Вписать».

**Панель над окном** (подсказки на кнопках; каждая кнопка — команда, есть в ленте и `Ctrl+K`). Кнопки крупные: 42×39 px, значки 24 px. В ленте те же кнопки — на вкладке «Вид» (с «Главной» группы «Вид» и «Разрез» убраны).

| Группа | Кнопки |
|---|---|
| Поворот вида | «В план» (`T`), «Сбоку Z/X» (`X`), «Сбоку Z/Y» (`Y`), «Вписать» (`F`), «Разрез» |
| Разрез | «Разрез» (`S`), «Разрез через скважину», «Авто-разрез» (пока линии нет); при линии — «Отсечение» (`C`), «Предыдущий профиль» (`[`), «Следующий профиль» (`]`), «В плоскость разреза», «План», «Сбросить разрез» |
| Окно разреза | Поля «От», «До» (м) и «Аз.» (азимут линии, градусы) — при заданной линии |
| Вид | «Вертикальное преувеличение» ×1, ×2, ×3, ×5; «Непрозрачность каркасов» 0,1–1 (по умолчанию 0,7); «Перспектива»; «Сетка» («Координатная сетка с подписями») |
| Просмотр | «Данные по скважинам» (нужен активный набор) |

| Вид | Что делает |
|---|---|
| «В план» | Сверху (Y вверх, X вправо): поворот вокруг центра вида, масштаб и центр сохраняются |
| «Сбоку Z/X» / «Сбоку Z/Y» | На север: Z вверх, X вправо / на запад: Z вверх, Y вправо |
| «Вписать» | Все видимые объекты без поворота; при отсечении — только то, что в окне разреза |
| «В плоскость разреза» | Z вверх, линия слева направо |

**Гизмо осей** (левый нижний угол): X красная, Y зелёная, Z синяя, поворачивается вместе с камерой. Щелчок по головке оси — вид вдоль оси с её положительной стороны (головка Z — сверху), по кружку напротив — с отрицательной (кружок Z — снизу). Поворот плавный; новый щелчок прерывает начатый.

**Выбор.** Щелчок по устью (в пределах 8 px) или стволу (6 px) выбирает скважину: карточка в «Свойствах», строка в таблице. `Esc` или «Выделение» › «Снять выбор» — снять. «Найти скважину» — `Ctrl+K`, запрос «скв ».

**Цвет устьев по аудиту**

| Цвет | Значение |
|---|---|
| Красный | Есть критичные замечания |
| Жёлтый | Есть предупреждения |
| Синий | Только информация |
| Зелёный | Находок нет |
| Серый | Аудит не запускался |

Если аудит устарел, в легенде плашка «устарел», цвета остаются. Проектные скважины рисуются пунктиром; у канав свой цвет.

**Видимость и сохранение.** Слои (набор, устья, стволы, отображения) включаются и выключаются галочками; команда `layer.show`. В проекте запоминаются: перспектива, сетка, преувеличение, видимость слоёв, линия разреза и отсечение, стили устьев и стволов набора, включённые отображения. Правка данных, импорт и удаление набора обновляют окно сами: удалённый набор сразу исчезает.

**Если графика остановилась.** Нет WebGL2 — окно «3D-окно недоступно» с причиной и вариантом «Программная отрисовка (медленно)». Потеря контекста — плашка «Графика перезапускается…», затем кадр восстанавливается. Три потери за минуту — нагрузка снижается, в углу пометка.

**Счётчик кадров (`Ctrl+Shift+F`).** Показывает кадры/с (текущее, минимум, среднее), мс на кадр, число треугольников и вызовов отрисовки, оценку памяти видеокарты, класс и название видеокарты, долю «упрощено». Итог замера можно скопировать. Цель на встроенной графике ПК приёмки — не менее 20 кадров/с на 50 000 стволов. Окно в углу «Программная отрисовка» — видеокарта не используется, 3D медленнее.

**Очистить окно.** «Вид» › «Окно» › «Очистить окно» (`Ctrl+Shift+H`, `Ctrl+K`, ассистент) скрывает все объекты (наборы, устья, стволы, отображения…) при любом их числе и снимает выбор скважины. Камера, разрез, сетка и сохранённые виды не меняются. Галочка показывает объект снова; набор, импортированный после очистки, показывается. Состояние сохраняется в проекте.

Будет позже: пересечения стволов с каркасами и блочными моделями, подсказка при наведении на устье, показ каркасов, линий, растров и блочных моделей, наклонные разрезы.

### Разрезы
| Действие | Как |
|---|---|
| Линия двумя щелчками | `S` (или «Разрез»), щелчок — начало, второй щелчок — конец, в виде сверху, сбоку или на мини-плане. Затем включается отсечение, вид разворачивается в плоскость разреза, линия вписывается от края до края данных |
| Через скважину | Выбрать скважину → «Разрез через скважину»: линия через устье по азимуту скважины в плане, вся скважина в плоскости разреза; у вертикальной азимут прежний |
| Авто-разрез | «Авто-разрез»: поперёк простирания устьев видимых наборов, через их центр |
| Окно | «От» (к наблюдателю) и «До» (от наблюдателя), по умолчанию 25 и 25 м; «Аз.» — азимут линии |
| Профили | `[` и `]` сдвигают линию ровно на «От» + «До» |

## Отображения по стволу
Данные любых таблиц набора вдоль стволов в 3D: содержания, литология, события.

**Открыть:** «Вид» › «По стволу» › «Содержания…», «Литология…», «События…» (нужен активный набор; пункт задаёт первое поле). Для Claude — `holes.show_data` (таблица и поле).

**Как работает**
- Изменения сразу видны на скважинах как черновик. В дерево (строкой под «Стволами» набора) отображение попадает только по «Сохранить».
- Сохранённые отображения: галочка — показать на скважинах, щелчок — показать или скрыть, двойной щелчок — настройки. Включённые встают рядом: колонки подряд от ствола, трубки одна в другой.
- Закрытие формы с несохранённым спрашивает подтверждение.
- Легенда в окне вида: слои и число интервалов в классах; щелчок по слою открывает его настройки.
- При удалении отображения (с подтверждением) стили библиотеки остаются.

| Зона формы | Что в ней |
|---|---|
| Шаблон | Весь набор слоёв как стиль из библиотеки: выбрать, связать 🔗, сохранить, сохранить как, применить к другим таблицам, экспорт, импорт, удалить |
| Слои | Поля любых таблиц набора; «+ Добавить» (поиск, несколько полей); порядок перетаскиванием; глаз; ⋯ — дублировать, стиль, применить к другим полям, удалить; «Разложить» — трубка на стволе, остальные по сторонам; несколько слоёв выбираются Shift/Ctrl и правятся вместе |
| Стиль слоя | Выбрать, связать, сохранить, сделать умолчанием для поля |
| Данные | Таблица и поле; скважины — все или выбранные; глубины «от — до» |
| Вид | Столбцы, ступени, линия, точки, трубка, лента, текст (у событий — значок); сторона слева / справа / обе; ширина и отступ; прозрачность, зазор, заливка; трубка постоянной толщины или по значению |
| Шкала | От — до (пусто — по данным), «мин — макс», «P2 — P98», «0 — P99»; логарифмическая; выше максимума — обрезать, с пометкой или как есть |
| Цвет | Один цвет; градации на гистограмме (границы мышью и стрелками; авто — квантили, равные, логарифмические и др.; число и доля проб в классе); непрерывная шкала и градиенты; цвет по другому полю; для текстовых полей — значения с поиском, глазом, порядком и цветом |
| Фильтр | Все / от борта / диапазон; пустые — пропуск или цветом; ноль и отрицательные; коды вроде −999 — как пустые |
| Подписи | Шаблон (`{AU} г/т`, `{from}`, `{to}`, `{len}`), знаки, только ≥ X, размер, цвет, не больше N (самые высокие) |
| Низ | «Сохранить», «Отменить изменения» (к сохранённому), `Ctrl+Z` / `Ctrl+Y` |

Пропуски не превращаются в ноль: пустое значение остаётся пустым и рисуется по настройке фильтра.

**Библиотека стилей проекта** (раскраска, стиль слоя, шаблон)
- Выбранный стиль копируется в слой. Со связью 🔗 правка стиля («Изменить стиль» в предупреждении над разделами) перестраивает все связанные отображения; «Только здесь» оставляет изменение в слое.
- «Где используется» — список отображений со стилем.
- Удаление используемого стиля оставляет слоям копию настроек: вид не меняется.
- Умолчание по полю: маска `AU` или `AU*` без учёта регистра; применяется само при добавлении такого поля (в том числе `AU_CUT` из другой таблицы); побеждает самая точная маска.
- Встроенные стили (только чтение): столбцы, градации, ступени, линия, трубка по шкале, лента по градациям, литология, события.
- Обмен: «Вид» › «По стволу» › «Экспорт стилей» / «Импорт стилей» — файл `.bfstyle.json` (до 1000 стилей и 4 МБ; файлы BedrockForge 1 читаются). При совпадении названий: «заменить», «оставить оба» (к имени добавляется «(2)»), «пропустить».

## Данные по скважинам
Каротажная диаграмма нескольких скважин рядом. «Вид» › «Просмотр» › «Данные по скважинам» или кнопка на панели 3D (`holes.data_window`); нужен активный набор. Только просмотр и экспорт, ничего не сохраняется. Для Claude — `chart.striplog` (текст CSV).

| Блок | Что делает |
|---|---|
| «Скважины» | До 30 рядом, поле «поиск»; 31-ю отметить нельзя; открытая из 3D выбранная скважина идёт первой |
| «Глубина» | «от, м», «до, м» (пусто — устье и забой); «Масштаб»: вписать, 1:2000, 1:1000, 1:500, 1:250, 1:125, 1:50; «общая шкала глубин» |
| «Таблица» | Таблица набора; её поля становятся колонками |
| «Колонки» | «Левее» / «Правее» / «Убрать»; «Вид»: столбцы, линия, цвет, текст, цвет + текст (у событий — значки); «Ширина»; шкала «от» / «до» (пусто — авто), «лог.»; «Раскраска»: один цвет, по градациям, непрерывная шкала, раскраска проекта; «границы интервалов»; поля других таблиц — «+ колонка…» |
| Экспорт | «PNG», «SVG», «CSV» через окно «Сохранить как» |

- Подсказка при наведении: скважина, глубины, значение; под колонками легенда категорий.
- SVG и PNG содержат фирменные шрифты; PNG — в двойном размере.
- CSV: строки `Скважина;От;До;<колонки…>`, на каждой скважине объединены границы всех колонок; пустое остаётся пустым; разделитель «;», кодировка UTF-8 с BOM.
- Не больше 20 000 строк на скважину и таблицу; при обрезке окно сообщает об этом.

## Аудит данных
«Анализ» › «Аудит данных» или «Запустить аудит» (`audit.run`) проверяет активный набор 27 правилами; идёт заданием в фоне. Результат — на вкладке «Аудит и статистика» нижней панели.

| Элемент | Что делает |
|---|---|
| «Таблица проб» | Какую таблицу проверять: по умолчанию «Пробы», иначе первая таблица проб; отчёт помнит, какая проверена |
| «Пороги» | Допуск глубины 0,01 м; изгиб 10° на 30 м; изоляция устья 10× медианного расстояния до ближайшего; скачок Z 50 м от медианы соседних; выброс 8 робастных σ от log10 значения; маркеры плановых: `project`, `planned`, `plan`, `проект`, `план` |
| «Отчёт Excel…» | Файл (`audit.export`) с листами «Сводка», «По правилам», «Находки» |

- Список правил показывает все 27, в том числе пройденные (✓), важность К / П / И (Критично, Предупреждение, Информация), число строк и скважин. Щелчок по правилу отбирает его находки.
- Находки можно отобрать по важности, таблице и скважине. У находки: скважина, правило, строки, до 20 примеров с русскими названиями полей.
- Новый запуск заменяет прежний результат. После импорта или правки результат помечается «устарел».
- Строка состояния: «Аудит: N критично, N предупр., N инф.» (при устаревшем — «(устарел)»); щелчок открывает вкладку.
- Карточка скважины в «Свойствах» перечисляет замечания по ней.

### Правила
Важность: К — критично, П — предупреждение, И — информация.

**Устья**

| Код | Важн. | Смысл |
|---|---|---|
| `COLLAR_MISSING_COORDS` | К | Не заданы координаты X/Y/Z |
| `COLLAR_INVALID_TD` | К | Глубина скважины не задана или не положительна |
| `COLLAR_ANGLE_RANGE` | К | Азимут или наклон вне допустимого диапазона |
| `COLLAR_ISOLATED` | П | Устье далеко от всех остальных |
| `COLLAR_Z_JUMP` | П | Отметка Z резко отличается от соседних устьев |
| `COLLAR_PLANNED_WITH_DATA` | П | Плановая скважина с данными |
| `COLLAR_EMPTY_STATUS` | И | Пустой статус устья |
| `COLLAR_WITHOUT_SURVEY` | П | Скважина без инклинометрии |
| `COLLAR_WITHOUT_ASSAY` | И | Скважина без проб |

**Инклинометрия**

| Код | Важн. | Смысл |
|---|---|---|
| `SURVEY_ORPHAN_HOLE` | К | Инклинометрия по скважине, которой нет в устьях |
| `SURVEY_EMPTY_VALUES` | П | Пустые значения глубины, азимута или наклона |
| `SURVEY_ANGLE_RANGE` | К | Азимут или наклон вне допустимого диапазона |
| `SURVEY_BEYOND_TD` | К | Замер глубже забоя |
| `SURVEY_DUPLICATE_DEPTH` | К | Повторяющаяся глубина замера |
| `SURVEY_NOT_ASCENDING` | П | Замеры идут не по возрастанию глубины |
| `SURVEY_FIRST_NOT_ZERO` | И | Первый замер не на устье |
| `SURVEY_DOGLEG` | П | Слишком резкий изгиб ствола |
| `SURVEY_COLLAR_MISMATCH` | П | Первый замер расходится с наклоном или азимутом устья |

**Пробы**

| Код | Важн. | Смысл |
|---|---|---|
| `ASSAY_ORPHAN_HOLE` | К | Пробы по скважине, которой нет в устьях |
| `ASSAY_INVALID_INTERVAL` | К | Некорректный интервал |
| `ASSAY_BEYOND_TD` | К | Интервал глубже забоя |
| `ASSAY_OVERLAP` | К | Перекрытие интервалов |
| `ASSAY_GAP` | П | Разрыв между интервалами |
| `ASSAY_DUPLICATE_SAMPLE` | К | Повторяющийся номер пробы |
| `ASSAY_NEGATIVE_VALUE` | К | Отрицательное содержание |
| `ASSAY_EMPTY_VALUE` | П | Пустое содержание компонента |
| `ASSAY_OUTLIER` | И | Экстремально высокое содержание |

Скорость (тестовый компьютер): 50 000 скважин и 5 млн проб — около 23 с вместе с чтением из проекта, 1,3 ГБ памяти.

## Линии, растры, ЦТМ
Линии и точки, растры и цифровые модели рельефа (ЦТМ) в проекте и в 3D.

### Импорт
«Главная» › «Импорт файлов» (или перетащить файлы на окно); отдельно — «Линии» и «Растры» в той же группе.

| Что | Форматы |
|---|---|
| Линии и точки | Micromine STR и `.PIT`, Surpac STR, DXF (линии, точки, текст, дуги и сплайны — ломаными), ESRI Shapefile, MapInfo MIF/MID, точки XYZ (CSV, TXT, DAT) |
| Растры | JPG, PNG, TIFF, BMP + world-файл; GeoTIFF; MapInfo TAB; Micromine GRF; вертикальные растры |

- Окно «Состав загрузки» до импорта показывает слои, линии, вершины, растры с привязкой и то, что не загрузится, с причиной. Нечитаемый файл пропускается, запись остаётся в «Журнале операции». Повтор имени — «имя (2)».
- Файлы привязки растра (world, TAB, GRF) подхватываются рядом с изображением.
- «Уровень растров по Z»: высота загружаемых растров и сдвиг; числа с запятой или точкой (`250,5`). Потом меняется в «Свойствах» растра.
- Слой линий — код стринга, номер Surpac, слой DXF, файл SHP или MIF; у MIF — до трёх слоёв «(линии)», «(точки)», «(текст)». Пустое значение остаётся пустым.
- Отмена импорта не оставляет объектов.

### Канавы по полилиниям
«Главная» › «Канавы» (или «+» у «Скважин» › «Импорт канав…»; первый шаг мастера скважин).

| Элемент | Назначение |
|---|---|
| Файл | STR, DXF или таблица вершин «канава, X, Y, Z» (CSV, TXT, DAT) |
| «Имя канавы» | Из стринга (слоя) или из «Поля с именем канавы»; несколько линий стринга — «имя-1», «имя-2» |
| «Обратить» | Меняет направление: устье — первая вершина |
| «Предпросмотр» | «Канава», «Вершин», «Длина по 3D, м», «Устье X / Y / Z» |

Длина и «от — до» проб считаются по 3D-длине вдоль полилинии; траектория проходит ровно через вершины. Пробы загружаются как в мастере скважин. «Заменить» инклинометрию станции канав не трогает.

### Дерево и «Свойства»
| Раздел дерева | Что внутри и что в «Свойствах» |
|---|---|
| «Линии» | Файл → слои, галочка у файла и у слоя (у файла > 200 слоёв общей галочки нет). Слой: цвет, длина, замкнутость, «Атрибуты слоя» по страницам |
| «Растры» | Высота (пусто — под самым низким объектом), «Сдвиг по Z» и «Сдвинуть» (плюс — вверх), «Вертикальный растр», «Непрозрачность растра», края X/Y и «Верх Z», «На текущий разрез» (в плоскость линии разреза), отклонения по опорным точкам |
| «Каркасы» | Видимость, цвет; «Перенести в ЦТМ» |
| «ЦТМ» | У строк нет кнопок: щелчок открывает «Настройки ЦТМ» вверху «Свойств»; в меню — «Настройки ЦТМ…» и «Вернуть в каркасы» |

«Настройки ЦТМ»: «Растр на рельефе» (вертикальные не предлагаются), «Скрыть данные за ЦТМ», «Цвет растра», «Непрозрачность растра», «Тени рельефа», «Вернуть в каркасы» (с подтверждением: настройки сбросятся, растр снимется). Растр, лежащий на ЦТМ, удалить нельзя — сообщение называет ЦТМ.

Объект переименовывается и удаляется из меню дерева или кнопками «Переименовать объект», «Цвет объекта», «Удалить объект» («Главная»); удаляется растр, каркас или ЦТМ, слой линий — только вместе с файлом.

### Построить ЦТМ
«Моделирование» › «Поверхности» › «Построить ЦТМ» (`model.dtm`) — заданием в фоне, ход и журнал на вкладке «Задания»; результат сразу в разделе «ЦТМ».

| Элемент | Назначение |
|---|---|
| Источники | Слои точек и линий, устья скважин; «Название ЦТМ» |
| Отрезки линий | Становятся рёбрами поверхности: бровки и подошвы не срезаются |
| «Слой границы», «Номер линии границы» | Замкнутая линия; высоты границы по умолчанию не берутся (контур часто на Z = 0); без точек внутри — отказ с подсказкой |
| «Наибольшая длина ребра, м» | Пусто — без ограничения |

«В ЦТМ» переносит выбранный каркас в раздел «ЦТМ». Изолинии, объём и обрезка — позже. Каркасы из файлов — в разделе «Каркасы».

### Экспорт
| Команда | Что делает |
|---|---|
| «Моделирование» › «Стринги» › «В STR», «В DXF» | Окно «Формат»: Micromine STR, Surpac STR, DXF, CSV («Запись CSV»: разделитель, десятичный знак), Micromine DAT; «Слои»; «Файл» |
| «Моделирование» › «Растры» › «Экспорт растра» | Исходный файл с привязкой (world-файл, `.prj`) или GeoTIFF |

Существующие файлы без подтверждения не перезаписываются. Слои точек в STR не пишутся (предупреждение). Команды экспорта не принимают путь: файл выбирает человек.

### В 3D
- Линии, точки и подписи текста (до 1000 подписей на часть); на дальнем плане линии упрощаются, помета «упрощено».
- Растры в плане и вертикальные (при разрезе — подложкой, скважины видны поверх); на ЦТМ — драпировка, одинаковая на любом уровне детализации.
- Щелчок по линии, точке, растру или поверхности выбирает объект (`object.select`), карточка — в «Свойствах»; `Esc` снимает выбор объекта и скважины (`selection.clear`). Линия под курсором выигрывает у растра.
- «Очистить окно» (`Ctrl+Shift+H`) скрывает и эти объекты.
- Пустая высота вершины рисуется на нижней высоте части.

### Ограничения
- SHP, MIF/MID и растры проверены на синтетических файлах; реальные образцы владельца ожидаются.
- Без imagecodecs 16-бит LZW читается с потерей до 8 бит; float LZW и JPEG — отказ. EXIF-поворот изображений не учитывается.
- MIF: Arc, Ellipse и Roundrect пропускаются с предупреждением; пользовательские датумы (МСК) — без системы координат.
- Растр больше 400 Мпикс — отказ; не JPEG — до 2,2 ГБ памяти.
- Писателей SHP и MIF нет; сдвига по Z у слоёв линий нет; выбрать отдельные слои при импорте нельзя.
- Редактор линий и версии слоя — в разделе «Редактор стрингов» ниже. Каркасы, DWG и Datamine — в разделе «Каркасы».

## Каркасы
Объёмные и поверхностные каркасы из файлов: загрузка, проверка, показ в 3D, точный выбор, сечения, пересечения со стволами, экспорт.

### Импорт
«Главная» › «Импорт файлов» (или перетащить файлы на окно); отдельно — «Каркасы» в той же группе.

| Формат | Что читается |
|---|---|
| Micromine TRIDB | Все каркасы файла: имена, цвета, атрибуты |
| DXF | Сетки (polyface, mesh, `3DFACE`, `MESH`) — каркасом на слой; линии и точки того же файла грузятся вместе с ними |
| DWG | Через ODA File Converter («Настройка › Внешние программы»); без него — подсказка с кнопкой «Настройка › Внешние программы…» и «Прочитать снова» |
| OBJ | Каркас на `o`/`g`; цвет — из комментария `# color` |
| STL | Двоичный и текстовый; координаты float32 — помечено в «Свойствах» |
| Surpac DTM + STR | Каркас из `.dtm`; одноимённый `.str` рядом подхватывается как спутник |
| Datamine | Пары «треугольники + точки» (`tr` + `pt`), каркасы и стринги; пара ищется по имени, иначе по содержимому |

- Каждый каркас — отдельный объект в разделе «Каркасы»; повтор имени — «имя (2)».
- Окно «Состав загрузки» показывает таблицу «Каркас / Треугольников / Вершин / Атрибуты»; что не загрузится — с причиной и подсказкой. Битый каркас пропускается, остальные грузятся, запись остаётся в «Журнале операции».
- Datamine: «Делить на каркасы по полю» (пусто — «не делить: один каркас») и «Слои по полю» (пусто — «один слой»). Формат помечен «Предварительно»: он прочитан по описанию и проверен на синтетических файлах — сверьте число треугольников, положение и объём с исходной программой.
- После импорта каркасы автоматически проверяются заданием в фоне; ход — на вкладке «Задания».
- Отмена импорта не оставляет объектов.

### «Свойства» каркаса
| Блок | Что показывает |
|---|---|
| Цвет, «показан в 3D» | Цвет поверхности («Без цвета» — умолчание), видимость |
| Общее | «Площадь», «Площадь в плане», «Объём» (только у замкнутого; иначе «нет: каркас не замкнут»), «Замкнутость», «Открытых рёбер», «Неманифолдных рёбер», «Вырожденных треугольников» |
| «Проверки» | «Нормали», «Самопересечения», «Проверено»; кнопка «Проверить» запускает проверку заново (идёт заданием, пока она работает, кнопка ждёт) |
| «Источник» | «Файл», «Формат», «Имя в файле», «Слой», «Точность» |
| «Треугольник по клику» | Точка, «Угол падения», «Азимут падения», «Площадь треугольника», «Треугольник №» |
| «Атрибуты» | Свои атрибуты: «Добавить», изменить, переименовать, удалить |

«Самопересечения» показываются красным в 3D-окне; число пар — в «Проверках». Проверка также доступна из ленты («Моделирование» › «Правка каркасов» › «Проверить», «Самопересечения»). «Перенести в ЦТМ» — как раньше.

### В 3D
- Точный выбор: щелчок по каркасу находит треугольник по настоящей геометрии (не по упрощённой копии показа); «Свойства» показывают азимут и угол падения. Пока точный треугольник уточняется, там написано «точка — по копии для показа».
- Разрез с «Отсечением» рисует линии сечения каркаса плоскостью разреза.
- Метки пересечений стволов с каркасами: в «Устья и стволы: стили» › «Пересечения» — «отмечать точки пересечения», «с каркасами», «только с видимыми объектами». Галочка «с ЦТМ» по умолчанию выключена: рельеф, построенный через устья, дал бы метку «0,000 м» у каждой скважины.
- «Очистить окно» скрывает и каркасы.

### Экспорт каркасов
«Моделирование» › «Экспорт каркасов» («В TRIDB», «В DXF», «В DWG», «В OBJ», «В STL», «В Surpac DTM») или «Экспорт каркасов…» в меню раздела «Каркасы» (у ЦТМ — «Экспорт ЦТМ…»). Все кнопки открывают окно «Экспорт каркасов» с выбранным форматом.

| Элемент | Назначение |
|---|---|
| «Формат» | Micromine TRIDB, DXF, DWG, OBJ, STL, Surpac DTM (`.dtm` + `.str`) |
| «Версия DWG» | AutoCAD-версия файла (только для DWG; нужен ODA File Converter) |
| «Запись STL» | «двоичный (float32, файл меньше)» — с предупреждением о потере точности координат; «текстовый (координаты без потерь)» |
| «Каркасы» | Галочки по разделам и папкам дерева, итог «треугольников и каркасов» |
| «Файл» | «Сохранить как…» |

Экспорт идёт заданием: ход и журнал — на вкладке «Задания». Если файл уже существует, окно спросит о замене («Отмена» оставляет окно открытым). DXF пишется всегда в формате R2004; DWG без конвертера — отказ с кнопкой «Внешние программы…».

### Настройка › Внешние программы
«Главная» › «Настройка» › «Внешние программы»: путь к `ODAFileConverter.exe` (или к его папке).

| Кнопка | Что делает |
|---|---|
| «Выбрать…» | Диалог выбора файла (только в приложении) |
| «Найти» | Поиск в стандартных местах: переменная `BF_ODA_CONVERTER`, `PATH`, `Program Files\ODA` |
| «Проверить» | Проверяет введённый путь и запоминает его; программа при этом не запускается, версия — из имени папки |
| «Очистить» | Убирает путь, поиск — в стандартных местах |

BedrockForge не распространяет ODA File Converter (установите его отдельно, подсказка — в окне); он запускается только для преобразования DWG в DXF и обратно.

### Ограничения
- Datamine: проверено на синтетических файлах («предварительно»); писателя Datamine нет. Surpac DTM — по описанию формата; Vulcan и двоичный Surpac — позже.
- DWG на Windows — только через ODA File Converter; файл с кириллицей в имени пользователя и повреждённый чертёж проверяются вручную (см. CHECKLIST).
- Очень много мелких каркасов грузятся медленнее (около 6 мс на каркас: 3000 каркасов в DXF — около 19 с).
- Показ крупных карьеров с рельефом упрощается сильнее (отклонение до 2–5 м на дальних уровнях детализации); точный выбор и сечения работают по полной геометрии.
- Порядок треугольников после импорта не сохраняется, DXF при повторном экспорте совпадает по составу (не по рамке файла с датой).
- Изолинии, объём, обрезка, исправление, упрощение и булевы операции — в разделе «Операции с линиями и каркасами».

## Облака точек и фильтр земли
Облако точек (лидар, съёмка с дрона) → классы «земля / растительность / шум» → ЦТМ из земли. Рассчитано на 10–50 млн точек; облако хранится как слой раздела «Линии» (значок облака).

### Загрузка
«Главная» › «Загрузка» › «Облако точек» (`points.import`) — окно «Импорт файлов» в режиме облака; файл `.las` из «Импорта файлов» тоже грузится облаком.

| Формат | Что читается |
|---|---|
| LAS 1.2–1.4 | Форматы точек 0–10; координаты с масштабом и смещением (float64); класс ASPRS, номер возврата и число возвратов; система координат из файла — как метка, без пересчёта |
| XYZ, CSV, TXT | Колонки «Колонка X», «Колонка Y», «Колонка Z», «Колонка класса» (необязательно); разделитель и десятичный знак определяются по началу файла; остальные колонки не грузятся (предупреждение); строка без Z пропускается и считается |

- «Каждая k-я запись» — прореживание при загрузке (пусто или 1 — все точки); для файла больше 50 млн записей окно предлагает значение с кнопкой «Применить». Карточка файла показывает версию, формат точек, число записей, охват, масштаб, систему координат и классы по выборке.
- LAZ не поддерживается: окно отвечает «Сжатые облака LAZ не читаются» и подсказывает сохранить как LAS (CloudCompare: «Сохранить как» › LAS; LAStools: `laszip -i облако.laz -o облако.las`).
- Цвета RGB, интенсивность и время GPS не загружаются (в карточке они в списке «не загружается»); при экспорте LAS «по исходному файлу» они сохраняются.
- Облако больше 2 млн точек через обычный «Импорт файлов» (слой точек) — предупреждение «загрузите как облако».

### В 3D и «Свойства» облака
Точки по 2 px; при отдалении облако редеет, помета «упрощено». Щелчок по точке — «Точка № …» в «Свойствах»: X, Y, Z, «Класс: 2 — земля», «Возврат», «Высота над землёй», «Отклонение от ЦТМ».

| Элемент «Свойств» | Что делает |
|---|---|
| «Цвет точек» › «Режим» | «Класс»; «Цвет слоя»; «Высота над землёй (h)» — после «Фильтра земли»; «Отклонение от ЦТМ (dz)» — разность Z точки и ЦТМ, после «Карты разностей» или «Построить ЦТМ из облака» |
| «Классы» | Таблица «Класс / Точек» с цветом и галочкой видимости; «Показать все», «Скрыть все». Видимость действует в режимах «Класс» и «Цвет слоя»; скрытые точки не рисуются и не выбираются |
| «Земля и ЦТМ» | Параметры последнего фильтра; кнопки «Фильтр земли…», «Построить ЦТМ из облака…», «Карта разностей…»; сводка карты разностей: с какой поверхностью сравнивали, когда, СКО, P95, наибольшее отклонение и число точек вне поверхности |
| «Точки облака» | Таблица X, Y, Z и поля по страницам |

Названия классов — по ASPRS: 0 «создана, не классифицирована», 1 «не классифицирована», 2 «земля», 3–5 «низкая / средняя / высокая растительность», 6 «здание», 7 «низкая точка (шум)», 9 «вода», 10 «железная дорога», 11 «дорожное покрытие», 17 «настил моста», 18 «высокий шум»; 19–63 «резерв ASPRS», 64–255 «пользовательский».

### Фильтр земли
«Моделирование» › «Поверхности» › «Фильтр земли» (`ground.classify`; также меню облака в дереве и кнопка в «Свойствах»). Идёт заданием, ход и журнал — на вкладке «Задания».

Принцип: облако мысленно переворачивают и опускают на него «ткань» с шагом CR; ткань не гнётся и ложится на самые нижние точки. Точка ближе к ткани, чем CT, — земля.

| Параметр | Простыми словами | Диапазон (умолчание) |
|---|---|---|
| «Шаг ткани CR, м» | Размер ячейки поверхности земли: меньше — подробнее рельеф и дольше расчёт | 0,1–50 (1) |
| «Жёсткость ткани RI» | Насколько ткань «перекрывает» пропуски в данных: 3 — жёсткая (равнина), 1 — мягкая (крутые склоны) | 1–3 (2) |
| «Порог земли CT, м» | Точка не выше поверхности земли более чем на CT (по нормали к ней) — земля | 0,05–5 (0,5) |
| «Искать землю у вертикальных граней», «Радиус R_б, м» | Уступ с вертикальной или нависающей стенкой: точки стенки — земля, если выше и ниже неё в пределах R_б (в плане) есть земля; стена здания такого не имеет | 1–20 (5) |
| «Искать шум (класс 7)», «Радиус шума, м», «Соседей не меньше» | Точка, у которой в радиусе меньше заданного числа соседей, — шум и дальше не участвует | 0,5–20 (2); 1–20 (3) |

| Профиль | Для чего |
|---|---|
| «Карьер» (по умолчанию) | Уступы, бермы, откосы, бровки: ткань мягче, рост по склону до 55°, грани включены |
| «Равнина» | Пологий рельеф: жёсткая ткань, рост по склону до 30°, грани не ищутся |
| «Свой» | Числа профиля («На основе профиля») можно менять; поля вводятся с запятой или точкой |

Результат: классы облака заменяются — 2 «земля», 3–5 растительность и постройки по высоте над землёй (пороги 0,5 и 2 м), 1 «не классифицирована», 7 «шум»; здания отдельно не выделяются (класс 6 не ставится). Появляется режим цвета «Высота над землёй». Журнал задания: профиль, CR, RI, CT, R_б, шум, число точек по классам до и после, время. Повторный фильтр заменяет классы заново; прежних классов из файла вернуть нельзя (кроме повторной загрузки). Команда спрашивает подтверждение.

### Построить ЦТМ из облака
«Моделирование» › «Поверхности» › «Построить ЦТМ из облака» (`terrain.from_points`) — окно «Построение ЦТМ» с блоком «Источники: облака точек»; облако можно сочетать с другими источниками.

| Элемент | Назначение |
|---|---|
| Галочка облака, «Классы» | Какие классы брать; по умолчанию 2 «земля». Нет точек земли — подсказка и кнопка «Фильтр земли…» |
| «Шаг прореживания, м» | В ячейке остаётся одна точка — с нижней медианой высоты над землёй; пусто — шаг подбирается так, чтобы вершин было не больше 2 млн (шаг пишется в журнал) |
| «Слой границы» | Замкнутая линия, как у обычного «Построить ЦТМ» |
| «Наибольшая длина ребра, м» | Пусто — 5 шагов ткани последнего фильтра (иначе 5 м) |
| «Карта разностей для облаков» | Включено по умолчанию: облака-источники сразу получают отклонение от построенной ЦТМ (см. «Карта разностей») |

Вершины ЦТМ — исходные точки облака без изменения координат.

### Карта разностей
Насколько точки облака отстоят от поверхности: dz = Z точки − высота ЦТМ или каркаса под ней (над ней). Считается сама после «Построить ЦТМ из облака» (галочка «Карта разностей для облаков») или по команде «Моделирование» › «Поверхности» › «Карта разностей» (`cloud.dz`; также «Карта разностей…» в меню облака в дереве и в «Свойствах» облака, блок «Земля и ЦТМ»).

| Элемент окна «Карта разностей» | Назначение |
|---|---|
| «Облако точек» | Выбранное облако или единственное в проекте |
| «Поверхность» | Любая ЦТМ или каркас проекта; по умолчанию — та, с которой сравнивали в прошлый раз, иначе последняя ЦТМ, построенная из этого облака |
| «Рассчитать» | Задание «Карта разностей» (ход — на вкладке «Задания»); окно показывает «Итог»: СКО, P95, наибольшее по модулю, по каким точкам мерено, «Точек с отклонением», «Вне поверхности» |

- Меры считаются по точкам земли (класс 2); если земли под поверхностью нет — по всем точкам. У точки вне поверхности в плане отклонения нет (пусто, не ноль); такие точки считаются отдельно.
- После расчёта у облака появляется режим цвета «Отклонение от ЦТМ (dz)» (шкала ±2,5 м), в «Свойствах» точки — «Отклонение от ЦТМ», в таблице точек — столбец «Отклонение от ЦТМ, м». Новый расчёт заменяет прежние отклонения.
- Отказы: «Под точками облака … нет поверхности» — поверхность лежит в стороне от облака; «Облако точек изменилось, пока шёл расчёт» — облако отфильтровали заново (повторите команду); каркас удалён — обновите дерево. Удалённая поверхность остаётся в сводке с пометкой «(удалена)».

### Экспорт облака
Щёлкните облако в дереве правой кнопкой → «Экспорт…» (или «Экспорт линий» с отмеченным облаком): откроется окно «Экспорт линий» с форматом LAS. Для облака доступны только «LAS» и «CSV (X;Y;Z;класс;h)»; остальные форматы скрыты, а LAS для обычных слоёв недоступен. Облако экспортируется одно: если вместе с ним отмечены другие слои, окно сразу скажет «Облако точек экспортируется отдельным файлом…», и кнопка «Экспортировать» будет недоступна.

Для LAS выберите «Запись LAS»: «По исходному файлу (меняются только классы)» — по умолчанию для облака из LAS; для облака из таблицы XYZ этот вариант недоступен (подсказка объясняет почему), и пишется «Новый файл». Для CSV можно выбрать разделитель столбцов и десятичный знак. Экспорт идёт как задание, ход и журнал — на вкладке «Задания».

| Формат | Что в файле |
|---|---|
| LAS «по исходному файлу» (для облака из LAS) | Копия исходного файла, в записях меняются только классы: цвет, время GPS, система координат — как были |
| LAS «новый файл» | LAS 1.2 формат 0 (при кодах класса больше 31 — 1.4 формат 6); масштаб и смещение исходника, если облако из LAS; координаты без потерь |
| CSV | X; Y; Z; класс (и h после фильтра), порядок хранения |

Существующий файл без подтверждения не перезаписывается.

### Ограничения
- Проверено на синтетических облаках (равнина со зданиями и деревьями, воронка с бортом 50°, уступы со стенками 15 м); реальное облако карьера ждём от владельца. Числа профилей предварительные.
- Останец круче угла профиля вне края съёмки (узкий отвал, скала) может остаться растительностью; профиль «Карьер» поднимается по откосу до 55°.
- Растительность над бортом, под которой нет ни одной точки земли, может быть принята за землю в пределах CT.
- Облако в градусах: фильтр считает в метрах — предупреждение при загрузке.
- Больше 200 млн точек после прореживания — отказ («каждая k-я запись»). Точки с NaN и значениями больше 1e9 по модулю пропускаются и считаются.
- Облако не редактируется: отмены фильтра нет, только повторный фильтр или загрузка; ручной правки классов, обрезки по контуру, LAZ, E57, PLY нет.
- Диск: на 50 млн точек около 1,5 ГБ данных плюс исходный LAS; расход памяти — 10 млн: фильтр около 0,7 ГБ, ЦТМ около 1,1 ГБ.

## Редактор стрингов
Оцифровка и правка линий и полигонов в 3D-окне с версиями слоя. Лента «Моделирование» › группа «Стринги»; те же команды — в `Ctrl+K`. Правка идёт над рабочей копией в окне, в проект она попадает только по «Сохранить».

### Начало работы
| Что | Как |
|---|---|
| Новый слой | «Моделирование» › «Стринги» › «Новый слой» или «Новый слой…» в меню раздела «Линии» (`lines.new_layer`): пустой слой в новом файле линий и сразу правка; название — код стринга в STR; занято — «имя (2)» |
| Правка готового слоя | «Редактировать» (`lines.edit`) для выбранного слоя; открытая правка другого слоя сначала завершается (с вопросом о несохранённом) |
| Сохранить | «Сохранить» (`Ctrl+S`, с подтверждением): новая версия слоя |
| Выйти | «Завершить» (в панели — «Завершить правку»); при несохранённом — окно «Завершить правку»: «Сохранить», «Не сохранять», «Отмена» |

Панель «Редактор стрингов» над 3D-окном: у каждой кнопки подсказка — название, действие, клавиши и, если кнопка недоступна, причина. Сохранённый слой на время правки скрыт, слой правки рисуется поверх.

### Инструменты (`lines.tool`)
| Инструмент | Клавиша | Что делает |
|---|---|---|
| «Выбор и перемещение» | `V` | Щелчок — выбрать, тянуть — переместить вершину или линию; `Ctrl` + тянуть — рамка; `Shift` — добавить к выбору; двойной щелчок по отрезку — вставить вершину |
| «Линия» | `L` (при активной серии разрезов — `Shift+L`: `L` там фиксирует вид) | Щелчок — точка; щелчок по концу готовой линии продолжает её |
| «Полигон» | `P` | Щелчок — вершина; при завершении полигон замыкается |
| «Точка» | `T` | Щелчок — отдельная точка |
| «Тай-линия» | `Y` | Две точки на вершинах контуров соседних разрезов; линия получает метку `ROLE = TIE` и служит связью для сшивки контуров |
| «Вставить вершину» | `I` | Щелчок по отрезку — новая вершина на нём |

Куда ложится точка: в плане — на уровень `Z` из панели (запятая и точка равноправны); при разрезе с отсечением — в вертикальную плоскость середины окна разреза; при привязке — в точку цели (или в её проекцию на плоскость разреза).

| Клавиша | Действие |
|---|---|
| `Enter`, двойной щелчок, правая кнопка (щелчок без перетаскивания) | Закончить линию; полигон замыкается |
| `Backspace` | Убрать последнюю точку |
| `Esc` | Снять выбор |
| `Delete` | Удалить выбранные вершины или линии |
| `Ctrl+Z`, `Ctrl+Y` (или `Ctrl+Shift+Z`) | «Отменить», «Повторить» (до 200 шагов и 256 МБ заменённых линий) |
| `Ctrl+S` | «Сохранить» |

Клавиши действуют при фокусе 3D-окна в режиме правки и не срабатывают в полях ввода.

### Ввод координат
Поле «Координаты точки» в панели (`Enter` — поставить точку или перенести выбранную вершину, `Esc` — выйти из поля):

| Запись | Смысл |
|---|---|
| `X Y Z` | Абсолютные координаты проекта; `X Y` — высота с панели |
| `@азимут расстояние [наклон]` | От предыдущей точки; азимут — от севера по часовой стрелке, наклон — от горизонта, вверх — плюс. `@90 100` от (0, 0, 0) даёт (100, 0, 0) |
| `@@dX dY [dZ]` | Приращения от предыдущей точки |

Для ассистента — команда `lines.add_line {points, closed}` (без правки — отказ с подсказкой «Новый слой» или «Редактировать»).

### Привязка
Кнопка «Привязка» включает и выключает её; «Цели привязки» (кнопка рядом) — что ловить. Каждое изменение — команда `lines.snap`.

| Цель | Что ловит |
|---|---|
| «вершина», «середина», «на линии» | Вершины, середины и ближайшая точка сегментов рабочей копии и других видимых слоёв линий |
| «вершина каркаса», «ребро каркаса» | Вершина и ребро треугольника под курсором (точный выбор по настоящей геометрии) |
| «сечение каркаса» | Линия сечения каркаса на разрезе |
| «устье», «траектория», «граница интервала» | Устья, стволы и границы интервалов скважин (рассчитывает ядро) |
| «узел сетки» | Узел сетки с шагом «Шаг сетки, м» |

Остальное в панели целей: «Радиус, px» (2–60) и «проецировать в плоскость разреза» — на разрезе точки скважин и каркасов ложатся в плоскость разреза; привязка к устью на разрезе даёт точку в этой плоскости. Слои больше 500 тыс. вершин и облака точек в привязке не участвуют — панель целей пишет об этом.

### Правка линий (`lines.modify`)
Кнопки группы «Правка линий»; действия с числами открывают окно «Правка выбранного» (числа с запятой и точкой; «Применить», «Отмена»). Выбирайте линии инструментом «Выбор» (`Shift` — добавить).

| Кнопка | Что делает | Поля окна |
|---|---|---|
| «Закончить линию» | Закончить рисуемую линию (`Enter`) | — |
| «Замкнуть» / «Разомкнуть» | Линия ↔ полигон | — |
| «Разорвать» | Разорвать линию в выбранной вершине | — |
| «Соединить» | Соединить две выбранные линии ближайшими концами | — |
| «Развернуть» | Обратить направление | — |
| «Сдвинуть…» | Сдвинуть на вектор, в том числе по Z | «ΔX, м», «ΔY, м», «ΔZ, м» |
| «Копия на вектор…» | Копия, сдвинутая на вектор | «ΔX, м», «ΔY, м», «ΔZ, м» |
| «Копия со смещением…» | Параллельная копия; у полигона больше нуля — наружу, меньше — внутрь | «Смещение, м» |
| «Проредить…» | Убрать вершины ближе допуска к линии (Дуглас–Пекер) | «Допуск, м» (больше 0) |
| «Сгустить…» | Отрезки не длиннее шага | «Шаг, м» (больше 0) |
| «Сгладить…» | Срезание углов | «Проходов» (1–10) |
| «Удалить» | Удалить выбранные вершины или линии (`Delete`) | — |

Вершина без высоты остаётся без высоты: в 3D-длину и площадь она не входит, нулём не становится. Действие, не изменившее слой, истории не добавляет.

### Измерения
«Измерить» (`lines.measure`) и строка под панелью: вершины, длина 3D и в плане, периметр, площадь полигона в его плоскости и в плане — для выбранного и для всего слоя, с несохранёнными правками. Площадь квадрата 10 × 10 в плане — 100.

### Версии
Каждое «Сохранить» — новая версия слоя; ничего не стирается. «Версии…» (`lines.versions`) открывает окно «Версии»:

| Колонка | Что показывает |
|---|---|
| «Версия», «Когда», «Кто», «Действие» | Номер, время, автор и действие (импорт, создание, сохранение, возврат, перенос, операция) |
| «Линии», «Вершины» | «было → стало» |
| «Заметка» | Заметка к версии |
| «Вернуть» | Создаёт версию N + 1 с геометрией выбранной (с подтверждением, `lines.restore`); текущая помечена «текущая» |

Если слой сохранён кем-то после начала вашей правки, «Сохранить» ничего не записывает и открывает окно «Слой изменён»: «Слой «имя» сохранён после начала правки (версия N, кто, когда). Ничего не записано.» Кнопки: «Сохранить как новый слой» (правка пишется отдельным слоем «имя (правка)» в том же файле), «Перечитать слой» (несохранённые правки пропадут), «Отмена». Смена цвета или названия слоя сохранение не блокирует.

«Перенести в другой слой…» (`lines.move_selected`, с подтверждением): окно «Перенести в другой слой» — поле «Найти слой», список слоёв, «Перенести». Выбранные линии уходят в выбранный слой, оба слоя получают новую версию; новые несохранённые линии сначала сохраните.

### Ограничения
- Правится слой до 1 млн вершин. Облака точек не правятся (отказ «not_editable»). В проекте «только чтение» сохранение недоступно.
- Автоматической очистки журнала версий нет: каждая версия хранит полную копию геометрии слоя; размер журнала растёт.
- Привязка не берёт слои больше 500 тыс. вершин и облака точек.

## Операции с линиями и каркасами
Построение и правка тел и поверхностей из линий и каркасов. Лента «Моделирование»: группы «Каркас из контуров», «Правка каркасов», «Операции», «Поверхности»; те же команды — `model.*`, `Ctrl+K` и ассистент (`model.operation`, с подтверждением).

### Общие правила
- Операция идёт заданием (`geometry.operation`) с ходом и отменой на вкладке «Задания»; результат — новый объект в папке первого исходного, исходные не меняются. Занятое имя — «имя (2)».
- Входы до 2 млн треугольников идут в быструю очередь, больше — в общую; долгий импорт не задерживает быструю операцию. Отмена и сбой не оставляют ни объектов, ни временных файлов.
- Предусловия проверяются до запуска, окно показывает исходные, число треугольников на входе и очередь. Пример отказа: «Каркас «Тело 2» не замкнут: открытых рёбер — 14.» с подсказкой и кнопкой «Исправить каркас».
- После операции каркасы результата проверяются автоматически (`wireframe.check`); отчёт открывается окном «Отчёт операции».

### Окно операции
Одно окно на операцию; «Обрезать» — одно окно трёх операций (переключатель «Операция»). Поля ставит ядро (список операций — `GET /operations`).

| Элемент | Назначение |
|---|---|
| Поля параметров | По таблице ниже; поля, зависящие от других, появляются по месту |
| «Название результата» | Пусто — имя по операции и исходным |
| Строка проверки | «Исходные: …», число треугольников, очередь; или причина отказа |
| «Выполнить», «Отмена» | Запуск через `model.operation` / закрыть |
| После запуска | Состояние и ход задания, «Отменить», «К параметрам» (при ошибке или отмене), «Отчёт», «Закрыть» |

Правила: булева работает только с замкнутыми телами (замкнутость видна в «Свойствах»; для незамкнутого — «Исправить каркас»). «Самопересечения» только отмечаются красным, не исправляются. Вершины исходных контуров попадают в результат сшивки без изменений.

### Сшивка контуров
- Контуры группируются в разрезы по положению вдоль общей нормали; соседние разрезы связываются лентой по кратчайшему пути между вершинами (алгоритм Фукса–Кедема–Юзелтона, перенесён из BedrockForge 1): разное число вершин не мешает, лента без перекрута.
- Тай-линия закрепляет пару вершин: линия из двух вершин с атрибутом `ROLE = TIE` (инструмент «Тай-линия») либо линия без метки, концы которой стоят на вершинах контуров (до 1 мм). Каждая тай-линия становится ребром результата.
- Разветвление: один контур на разрезе против нескольких на соседнем; родительский контур режется одной прямой хордой.
- Торцы: «Плоская крышка», «В точку», «В линию (гребень)», «Продолжение контура», «Открыто».
- Два контура 10 × 10 через 10 м с плоскими торцами дают замкнутое тело объёмом 1000.

### «Собрать из контуров»
«Моделирование» › «Каркас из контуров» › «Собрать из контуров» (`model.assemble`): как связывание стрингов в Micromine. Откройте слой в редакторе и щёлкайте замкнутые контуры по порядку — каркас растёт в окне; повторный щелчок по контуру убирает его. Контуры берутся из рабочей копии, сохранять слой заранее не нужно.

| Элемент панели «Сборка каркаса» | Назначение |
|---|---|
| «контуров N · тай-линий M» | Сколько выбрано; тай-линии считаются только с концами на вершинах выбранных контуров |
| «Убрать последний контур» | Каркас становится на контур короче |
| «Замкнуть торцы» | Плоские крышки по первому и последнему контуру — замкнутое тело с объёмом; повторное нажатие открывает торцы |
| «треугольников N · объём V м³» | Предпросмотр; при ошибке — причина («Каркас строится…», «Щёлкните следующий контур») |
| «Создать каркас» | Недоступна при меньше чем двух контурах или ошибке; сохраняет слой (если изменён) и строит объект операцией «Сшить контуры» в фоне |
| «Отмена» (`Esc`) | Выход; контуры не меняются |

- Тай-линии ставит инструмент «Тай-линия» (`Y`); затем вернитесь к «Выбору» (`V`).
- Предпросмотр ограничен 500 контурами и 50 тыс. вершин; больше — создайте каркас операцией «Сшить контуры».

### «Править треугольники»
«Моделирование» › «Каркас из контуров» › «Треугольники» (`model.triangles`): панель «Треугольники: <имя каркаса>» над 3D-окном. Результат — новый каркас, исходный не меняется.

| Элемент | Назначение |
|---|---|
| «Отметить к удалению» | Щелчок по треугольнику (точный выбор) отмечает его; повторный щелчок снимает отметку |
| «Добавить по трём вершинам» | Три щелчка; щелчок берёт ближайшую к нему вершину треугольника под курсором. Щелчок в пустое отверстие — отказ с подсказкой |
| «Убрать последнее» (правый щелчок — то же) | Выбранная вершина, новый треугольник или отметка |
| «к удалению N · новых M · вершин K из 3» | Счётчики |
| «Применить» | Недоступна, пока нет правок; операция «Править треугольники» строит новый каркас в фоне |
| «Отмена» | Выход, каркас не меняется |

Панель не открывается, пока открыт редактор стрингов: оба занимают инструмент 3D-окна.

### Отчёт и «Свойства» результата
Окно «Отчёт операции»: «Создано» (каркасы с объёмом, слои), таблица «Показатель / Было / Стало» (исправление, упрощение, сглаживание: объём, треугольники, проверки), числа операции (изменение объёма, отклонение, выемка и насыпь), шаги и предупреждения; «Скопировать» кладёт отчёт в буфер.

В «Свойствах» результата — блок «Операция»: операция и время, «Исходные объекты» (удалённый исходный остаётся по имени), «Параметры», «Допуски», кнопки «Перестроить» и «Отчёт». Связь с исходными — по номерам: удалить контуры после построения тела можно.

### Перестроить (`model.rebuild`)
Повторяет операцию на текущих исходных с теми же параметрами и тай-линиями (контуры берутся по устойчивому номеру линии: вставки и удаления линий их не сбивают); результат — новый объект с пометкой «Перестроено: прежний объект №N не изменён». Исходный удалён или линии нет — отказ с именем. ЦТМ перестраивается заданием «Построить ЦТМ» с прежними параметрами. Команда спрашивает подтверждение.

### Ограничения
- Самопересечения не исправляются автоматически.
- Разветвление режет контур одной прямой хордой; неразделимые ветви — отказ с номерами разрезов (помогают тай-линии или промежуточный контур). Контур не должен быть повёрнут больше чем на 60° от плоскости разрезов.
- Полигон обрезки и «Полигон в плане» — один простой замкнутый контур без отверстий.
- Оболочки (shell) нет.
- Булева: отмены внутри одной булевой нет — только между этапами; незамкнутый каркас — отказ с числом открытых рёбер.
- Поверхность, не перекрывающая тело, — отказ при обрезке поверхностью; крутой разлом — подсказка выбрать «По нормали поверхности».
- Номера линий в параметрах окна — с 1; «Перестроить» ЦТМ читает границу по позиции в слое, после правки слоя она может не совпасть.

### Ориентир по скорости
Тестовый компьютер; у вас время зависит от процессора и памяти.

| «Исправить каркас», 1 млн треугольников | около 4 с |
| «Сшить контуры», 500 разрезов × 500 вершин | около 3 с |
| Предпросмотр «Собрать из контуров» | около 50 мс |
| «Объём», 2 поверхности × 1 млн треугольников | около 7 с |

## Серии разрезов
Серия — набор параллельных разрезов с одним шагом: по ним оцифровывают контуры и строят тело («Каркас по серии»). Вкладка ленты «Разрезы»; раздел «Серии разрезов» в дереве; те же команды `series.*` — в `Ctrl+K` и у ассистента (создание, копия, удаление, переименование — с подтверждением). Серия хранится в проекте и переносится в `.bfggis`; текущий разрез — в виде проекта (`]` серию не меняет).

### Типы и параметры
Окно «Новая серия» (`series.new`): параметры подставляются по линии разреза и видимым данным; «По видимым данным» ставит пределы кратно шагу.

| Тип | Что задать | Замечание |
|---|---|---|
| «Вертикальная» | «X P1», «Y P1», «P1 → P2» или «P1 и азимут» («Азимут A, °»), «Начало s0, м», «Конец s1, м», «Шаг Δ, м» | Разрезы сдвигаются поперёк линии |
| «План» | «Верхняя отметка, м», «Нижняя отметка, м», шаг по Z | Горизонтальные срезы сверху вниз |
| «Наклонная» | то же и «Наклон φ, °» (0–90) | Пока серия активна, преувеличение ×1: кнопки ×2…×5 недоступны с причиной |
| «Ломаная» | «Вершины ломаной» («X; Y» по строке, до 1 000), «Ширина коридора, м» (25) | Одна развёртка: серия из одного разреза; в 3D — текущий сегмент, `]` / `[` переключают сегменты |

| Поле | Правило |
|---|---|
| «Окно «к себе», м» и «Окно «от себя», м» | 0,01–10 000 (по умолчанию 25 и 25); окно полуоткрытое: точка ровно на грани уходит в следующий разрез. При Δ = сумме окон окна соседних разрезов смыкаются |
| «Шаг Δ, м» | 0,01–10 000; разрезов не больше 5 000; серий в проекте — до 1 000 |
| «Шаблон имён» | Только `{k}` (с 1), `{s}`, `{X}`, `{Y}`, `{Z}` и формат числа; пусто — по азимуту: `{Y:.0f}N`, `{X:.0f}E`, для плана `{Z:.0f}`, иначе `{s:+.0f}`. Повтор имени — ошибка «добавьте {k}» |
| «Тень» | «Нет», «Предыдущий» (по умолчанию), «Следующий», «Оба» |

- Быстрые способы: «Из линии разреза» (`series.from_line`), «Через скважину» (`series.through_hole`), «Из одного разреза» (`series.from_section`).
- Числа вводятся с запятой или точкой; ошибка называет поле и даёт подсказку.
- Изменить P1, азимут, φ, шаг или пределы можно и при готовых контурах: их атрибуты не пересчитываются; для новой геометрии рядом — «Копировать».

### «Менеджер серий»
«Разрезы» › «Серия» › «Менеджер серий» (`series.manager`). Список серий; кнопки «Создать…», «Копировать», «Удалить» (с вопросом), «Параметры…», «Сделать активной»; таблица разрезов (номер, «Имя», «s, м», «к себе, м», «от себя, м»); линии серии на плане. Свои окна разреза правятся в таблице, «Вернуть окно серии» убирает их; двойной щелчок по строке — переход к разрезу. Если серию изменили в другом окне, программа просит повторить правку (таблица уже обновлена). Удаление серии контуры не трогает.

### Переходы
Строка состояния: «Серия «Профили» · разрез 3 из 12 · 5050N». Клавиши работают при фокусе 3D-окна, не в полях ввода.

| Действие | Клавиша / кнопка |
|---|---|
| Следующий, предыдущий | `]`, `[` — «Следующий», «Предыдущий» (без серии — сдвиг линии разреза на ширину окна) |
| Первый, последний | `Home`, `End` — «Первый», «Последний» |
| По имени или номеру | `Ctrl+G` — «Перейти…»: «Имя или номер разреза (1–N)» с подсказками |
| Из дерева | Щелчок по разрезу в разделе «Серии разрезов» (до 1 000 строк, дальше — «Перейти…»); меню серии: «Сделать активной», «Копировать», «Переименовать», «Удалить» |

- На краю серии разрез не меняется, в строке состояния — сообщение.
- Свободный разрез (`S`, «Через скважину», «Авто-разрез») снимает активную серию, сама серия остаётся.
- «Зафиксировать вид» (`L`): камера по нормали к разрезу, вращение выключено, сдвиг и масштаб работают; при переходе точка остаётся на месте экрана. Во время правки на разрезе серии инструмент «Линия» — `Shift+L`.
- Если сменить разрез во время рисования, линия завершается (как по `Enter`, полигон замыкается) и остаётся на своём разрезе.
- «Отсечение» (`C`) работает и для наклонной серии и плана. «Часть каркаса в окне» (по умолчанию включена): кроме линий сечения — сам каркас, обрезанный окном; сечения каркасов считаются точно, соседние разрезы готовятся заранее и в фоне.
- «Тень»: контуры соседних разрезов серым пунктиром; не выбираются и не являются целями привязки.

### Контур на разрезе
«Оцифровка» › «Контур на разрезе» (`series.digitize`): включается отсечение, открывается правка слоя контуров серии (нет слоя — новый «Контуры <серия>» в файле «Серии разрезов»), инструмент «Полигон». Вершины ложатся в плоскость разреза (точность до 1e−9 м на координатах UTM); `Enter` — замкнуть, `]` / `[` — соседний разрез, `Ctrl+S` — сохранить. Линии получают атрибуты `SECTION_SET` (номер серии), `SECTION` (номер разреза с 1), `SECTION_NAME`; они справочные: контур относится к разрезу по положению (все вершины в окне), контуры из STR без атрибутов тоже годятся. Линии вне текущего разреза видны, но не правятся.

### «Каркас по серии»
«Оцифровка» › «Каркас по серии» (`series.stitch`): окно со списком контуров по разрезам («Разрез», «Контур», «Площадь, м²», «Связи»).
- Связи строятся сами: проекции контуров соседних разрезов перекрываются, иначе центры не дальше Δ. Щелчок по контуру выбирает его, щелчок по контуру соседнего разреза связывает или развязывает; выбранный остаётся, поэтому возможно разветвление 1 → N. «Автосвязи» возвращает автоматические связи, линии связей видны в 3D.
- Связи N : M в одной паре разрезов — отказ «разделите связи». Связь через пустой разрез не строится: он заканчивает тело торцом.
- «Начальный торец» и «Конечный торец»: «Продолжение на Δ/2, плоская крышка» (по умолчанию), «Плоская крышка на крайнем разрезе», «Выклинивание в точку на Δ/2», «Выклинивание в линию (гребень) на Δ/2».
- Связная группа контуров — отдельный каркас «<серия> — тело N»; «Одним каркасом» собирает тела в один объект.
- «Создать каркас» — задание (подтверждение, ход и «Отменить» в окне и на вкладке «Задания»), затем «Отчёт» (объём, треугольники, замкнутость). Ошибка называет разрезы: «между 5050N и 5075N: самопересечение». Контуры дальше 1e−3 м от плоскости — предупреждение, незамкнутые и вне окон — пропускаются со счётом. «Перестроить» в «Свойствах» тела работает как для других операций.

### Демо
Серия № 1 «Разрезы рудного тела 3» (Y 8000…8250, шаг 50, окна 25 / 25) с контурами; «Каркас по серии» даёт одно замкнутое тело около 0,86 млн м³ (8 связей, тай-линии пропускаются). Серия № 2 «Планы по рельефу» (через 2 м).

### Ограничения
- «Печать серии»: кнопка недоступна («Печать серии — этап Э22»); печать и листы — Э22.
- Ломаный разрез — одна развёртка; серий параллельных ломаных нет.
- Наклонная серия — преувеличение ×1.
- Блоки в разрезе — этап Э17; самопересечения тела не исправляются.
- Окно разреза на экране замкнутое: точка ровно на грани видна в обоих соседних разрезах.

## Задания
Вкладка «Задания» нижней панели (`Ctrl+K` → «Задания») — долгие операции (экспорт, импорт) идут в фоне.

| Колонка | Что показывает |
|---|---|
| № | Номер задания |
| Задание | Название; щелчок открывает журнал («Скопировать», «Сохранить .txt») |
| Состояние | «В очереди», «Выполняется», «Готово», «Ошибка», «Отменено»; после запроса отмены — «Отмена…» |
| Ход | Процент, сообщение, полоса |

| Кнопка | Когда |
|---|---|
| «Отменить» | В очереди или выполняется; в очереди — сразу, выполняется — на ближайшем шаге; ничего неполного не остаётся |
| «Повторить» | Задание в состоянии «Ошибка» |
| «Показать в папке» | Готовый экспорт |
| «Открыть проект» | Готовый импорт |
| «Очистить выполненные» | Есть готовые или отменённые задания (флажок «и с ошибкой» добавляет «Ошибка») |

«Очистить выполненные» после подтверждения «Убрать N заданий из списка?» убирает готовые и отменённые задания с их журналами; задания в очереди и выполняемые не трогаются, файлы экспортов остаются. Нет выполненных — кнопка недоступна («Нет выполненных заданий»). В проекте «только чтение» — понятная ошибка. Та же команда: «Настройки проекта» › «Обслуживание» › «Очистить выполненные задания».

**Почему задание ждёт** (под названием): «Нет работающего исполнителя…» с кнопкой «Перезапустить исполнителей»; «Впереди заданий: N, №… выполняется M мин»; нехватка памяти.
Если исполнитель прервался посреди задания, оно возвращается в очередь; после 3 неудач (для импорта — 2) — «Ошибка».
