### 2. Расчёт (8.10)
| № | Решение |
|---|---|
| 3 | t_b = V_b·FRAC_b·f_b·ρ_b: V и FRAC — `geometry.row_volumes`; f — доля дерева правил (решение 8); ρ — поле или число > 0. Блок с f = 0 не считается (№ 65); без объёма — `excluded.no_volume`; без плотности (NaN) — в «Контроль», не 0 |
| 4 | Группа — сочетание **до 3 ключей**: категорийное поле (домен, категория, любое), уступ (решение 7). Код группы — смешанное основание (код + 1 на ключ, 0 = «(пусто)»); число сочетаний ≤ 20 000, ячеек ≤ 2·10⁶ (`report_too_big`). Числовое поле группой — отказ с подсказкой «переведите в категории калькулятором» (№ 112). Пустые сочетания не выводятся |
| 5 | Ядро `resources/kernels.py` — перенос `blocks/report_kernels.py`: Neumaier (сумма, перенос) на (группа, корзина борта), в порядке строк файла; итог — отдельные аккумуляторы (не сумма групп), чтобы «Контроль» проверял сумму групп. Корзины — по объединению бортов таблицы, кривой и балансовых; отдельная корзина «нет g_б». Строки — суффиксы корзин сверху (Neumaier), интервалы — сумма корзин диапазона (не разность суффиксов) |
| 6 | Борт c по полю g_б (может не входить в отчётные, например AuEq): S = {b ∈ G: g_б ≥ c}; c = null — «без борта»: все блоки G, **и без g_б** (как BF `cutoff=None`, Т8.10-2). Борта — список (≤ 200) или диапазон {от, до, шаг}. Балансовые g_б ≥ c_б, забалансовые c_з ≤ g_б < c_б — строки `kind` = `balance` / `offbalance` (интервал корзин) |
| 7 | Уступ: параметры {Z₀, H, z_min?, z_max?} (по умолчанию — охват модели по Z, Z₀ = кратное H ниже низа); доля блока в уступе j = длина([z_b − dz/2; z_b + dz/2] ∩ [Z₀ + jH; Z₀ + (j + 1)H]) / dz (поворот модели — только вокруг Z, ADR 0023: dz — по оси Z). Часть блока вне диапазона уступов — в «(пусто)» (№ 107). Подпись «+250…+260». Т8.10-4: блок Z 0…10, граница 5 — по половине |
| 8 | f_b — одно дерево правил `filters/schema` (И = произведение): фильтр библиотеки `filter_id` И быстрый `restrict` И ярлыки окна «Карьер» (`PIT <= n` — выражение; каркас карьера — лист `wireframe` внутри) и «Ниже рельефа» (лист `surface` below, по доле). Поле PIT появится в Э21; без поля — 422 `filter_field_missing` с подсказкой |
| 9 | **Расширение Э17** — лист `slab {axis: x / y / z / u / v, from, to, by: centre / share}`: по центру — 1 при from ≤ c < to; `share` — только z (доля высоты, как решение 7). Нужен Д-36 (ячейка «уступ») и переходу из полосы swath. `to_text` → null (как каркас), `title_of` — «Z от … до …»; `restrict.py` — `_slab`; конструктор ui показывает лист только для чтения |
| 10 | ḡ_e = Σ_S t·g_e / Σ_(S, g_e не NaN) t; M_e = Σ_S t·g_e·k_e; блок без g_e — в `missing_tonnes`/`missing_blocks` элемента, не в среднее и металл; Σ t = 0 — ḡ пусто (не 0). Металл хранится в базовой единице: г (г/т, ppm: k = 1; ppb: k = 1e−3), т (%: k = 0,01); показ — единица шаблона (решение 19). Единица поля может быть задана в окне (поле без единицы — металла нет, предупреждение) |
| 11 | Кривая «тоннаж — содержание»: 100 бортов (2–500) от min до max g_б по статистике поля (как Э17), по итогу; T, ḡ и M каждого элемента от борта. Кривая группы — через ограничитель (вне ТЗ — нет) |
| 12 | Порядок сумм — 8.0.1: float64, фиксированный порядок; результат побитно одинаков при любых порциях и потоках (решение 27). ALGO = `resources-1` |

### 8. Д-36: переход из отчёта к блокам и пробам
| № | Решение |
|---|---|
| 22 | `resources.drill {report_id, group: [подписи] / null, cutoff, kind}` → `{rules, cell {blocks, volume, tonnes}, stale}`: правила = ограничитель отчёта И `cond` ключей (`=` подпись; «(пусто)» — `empty`) И `slab` уступа (`share`) И `expr` борта (`g_б >= c`, интервал для баланса). Синхронно (дерево без расчёта); `stale` — состояние отчёта в графе (устарел — предупреждение «набор блоков может отличаться») |
| 23 | Набор блоков = блоки с f > 0 этого дерева; Σ V·FRAC·f и Σ t тем же ядром = ячейке (ТД36-1, 1e−12 отн.); повтор при тех же входах — тот же набор (дерево — функция `params` и ячейки) |
| 24 | Показ: `blocks.filter {model_id, restrict: rules}` в 3D (как быстрый ограничитель Э17); таблица блоков ячейки — `POST /resources/reports/{id}/drill/rows` (страницы по 1000: i, j, k, центр, размеры, f, V, t, элементы, ключи; CSV). Строка или блок в 3D → `estimate.inspect` (Д-30) → проба → интервал 7.17. Полоса swath оценки (8.8.3) → правила серии И `slab {axis, from, to, by: centre}` — тот же путь |

### 9. Д-37: сравнение
| № | Решение |
|---|---|
| 25 | `estimate.compare {model_id, field_a, field_b, domain?, out?}` — задание `estimate.compare` (quick): поле Δ = A − B (NaN, если пропуск в любом; `source {op: "compare", a, b}`, вход графа — оба поля), статистика Δ (n, среднее, СКО, min, max, перцентили), гистограмма (`stats/histogram`, по числу блоков), таблица по доменам: средние A, B, Δ взвешены объёмом (№ 108), число блоков со сменой `STATUS` (если у A и B есть `<префикс>STATUS`), раскраска Δ в 3D — обычный показ поля |
| 26 | `resources.compare {report_a, report_b}` (синхронно, по `data` обоих): строки совмещаются по (ключи, `kind`, борт); ΔT, ΔV, Δḡ, ΔM; строка только в одном — пропуск с пометкой, не 0; две кривые на одном графике; шапка — модель, `inputs` (имя, fp, дата) и состояние графа обоих. Разные модели или `cells_sha` — флаг «сетки различаются» (сравнение только отчётов); разные g_б или единицы — предупреждение. ТД37-1: A = B → Δ = 0; ТД37-2 — № 109 |

### 10. Производительность, задания, интерфейс
| № | Решение |
|---|---|
| 27 | Ранняя точка 20.2: на 20 млн — время чтения столбцов, ограничителя и ядра отдельно.
