### Находки при подготовке эталонов (записаны в `manifest.json`)

- Блочный `kb2d` GeostatsPy (`nxdis·nydis > 1`) неработоспособен: `NameError: real`, внутренний цикл суммирует только последнее `j`. Эталон блочного кригинга — замкнутая форма numpy (соглашение GSLIB: нуггет внутри блока снят), сверка с GeostatsPy — только для точечного.
- `kb2d` отдаёт сетку, перевёрнутую по Y; `gamv` включает самопару в лаг 0 (n, а у всенаправленной — 2n).
- Стохастические программы (`sgsim`, `sisim`) не замораживаем: потоки случайных чисел различны — приёмка статистическая.

### Атрибуция и лицензии

- Перенос алгоритма из MIT-кода — только с указанием источника в docstring модуля и в `docs/USER_GUIDE.md` («Использованные работы»); тексты лицензий (MIT, © авторов) сохраняются рядом с данными (`tests/data/ext/`).
- Данные McLaughlin — MineLib (Espinoza, Goycoolea, Moreno, Newman, 2013, *Annals of Operations Research* 206(1), 93–114); проект получен через учебник Incline Design (MIT).
- В `core/uv.lock` и `package-lock.json` ничего не добавляется; проверки `tools/ci/check_licenses_*` не затрагиваются.

## Что не берём (решение владельца — после В4)

Календарное планирование отработки, транспорт и циклы самосвалов, БВР, резервы по подэтапам, OMF 2, экспорт блоков в VTK/HTML, неопределённость контактов (Монте-Карло), ориентации по точкам поверхности (Incline п. 7–11, 14–17 разбора). Отдельный ADR при запросе; потребует `highspy` (MIT) для задач LP/MIP.
