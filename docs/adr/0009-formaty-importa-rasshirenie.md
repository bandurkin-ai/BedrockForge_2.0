# ADR 0009. Расширение импорта: Datamine, Surpac, Vulcan, DWG, SHP, MapInfo, DNG (Д-13)

**Статус:** проект, 2026-11-17. Принимается ответом владельца на вопросы ТЗ 7.35.6 № 2–4. Зависимости вводятся дополнениями ADR 0001 на этапах, где появляются их читатели.

## Контекст

- ТЗ 9.12, последняя строка: «Datamine DM, DWG, Shapefile — нет в v1; DWG — «сохраните в DXF»; DM — после образцов от заказчика». Владелец (Д-13) просит импорт Datamine, Micromine, Surpac, Maptek Vulcan, DWG, DXF, GeoTIFF, SHP, MapInfo и «DNG» — это меняет принятый состав форматов.
- Уже в плане: Micromine DAT/STR/TRIDB (Э3, Э7, Э8), Surpac STR и DTM текстом (Э7, Э8), DXF (Э7, Э8), растры с привязкой world/TAB/GRF и GeoTIFF (Э7, tifffile).
- Правила: лицензии только MIT/BSD/Apache-2.0/MPL-2.0/ISC/PSF; GPL/LGPL/AGPL запрещены (5, 8.0.3, 17); готовые колёса `cp312-win_amd64`, сборка из исходников запрещена (ADR 0001, П4); дистрибутив ≤ 400 МБ при оценке 330–370 МБ (ADR 0001, «Последствия»).
- `tools/ci/check_licenses_py.py` проверяет лицензию в метаданных пакетов замыкания `[project].dependencies`; `check_licenses_npm.mjs` — поле `license` в `package.json` продуктового замыкания. Библиотеки DLL внутри колёс ни один из них не видит.

## Решение

| Формат | Описание | Решение | Зависимость | Этап | Приоритет |
|---|---|---|---|---|---|
| ESRI Shapefile `.shp/.shx/.dbf/.prj/.cpg` | Открыт (ESRI Shapefile Technical Description, 1998) | Читатель на pyshp: Point/MultiPoint → точки, PolyLine → линии, Polygon → замкнутые линии (кольца — отдельные линии с атрибутом «кольцо»); Z и M сохраняются; атрибуты DBF; кодировка `.cpg`, иначе cp1251 с предупреждением; СК — `.prj` (pyproj есть) | pyshp (MIT), дополнение ADR 0001 на Э7 | Э7 | обязательно |
| MapInfo MIF/MID | Открыт (MapInfo Interchange Format) | Свой разбор текста: Point, Line, Pline (в т. ч. Multiple), Region, Text; `CoordSys Earth Projection …` → EPSG/WKT через pyproj; `Delimiter`, `Charset` | — | Э7 | обязательно |
| MapInfo TAB (вектор) | `.map` двоичный не описан; реализован только в GDAL | Мастер отвечает: «Векторный TAB не читается: сохраните в MIF/MID (MapInfo, QGIS)». Растровый TAB (привязка) — как сейчас | — | — | позже |
| GeoTIFF | Открыт (OGC 19-008r4) | tifffile: `geotiff_metadata` (ModelPixelScale, ModelTiepoint, ModelTransformation, GeoKeys → EPSG); без сжатия и Deflate/PackBits — без новых пакетов; LZW, JPEG, LERC — imagecodecs (BSD-3, колесо 18 МБ) **только** если образцы владельца так сжаты | imagecodecs — по образцам | Э7 | обязательно |
| DXF | Открыт | Без изменений плана (9.12) | ezdxf (есть) | Э7, Э8 | обязательно |
| DWG | Закрыт (ODA, Autodesk); LibreDWG — GPL-3.0 | Вариант А (рекомендуется): ODA File Converter — бесплатная программа Open Design Alliance, пользователь ставит её сам; путь — в «Настройке»; ядро вызывает её как внешний процесс через `ezdxf.addons.odafc` (MIT, есть в ezdxf 1.4.5) во временную папку → DXF → наш читатель. BF2 программу не распространяет и не связывается с ней как с библиотекой. Б: коммерческий ODA SDK (членство, C++, своя сборка, бинарник в дистрибутиве) — расходы и проверка лицензии. В: только DXF (как сейчас). До ответа — В | — | Э8 | желательно |
| Datamine `.dm` | Частично: страничная структура и словарь полей описаны в справке Datamine Studio; открытых библиотек нет (PyPI `datamine` — пакет CME Group, к Datamine не относится) | Свой читатель по описанию и образцам: страницы, словарь полей (по справке: имя до 8 символов, тип A/N, одинарная или расширенная точность — сверить на образцах), записи; затем семантика файлов: каркас = пара `*tr` + `*pt`, стринги (PVALUE, PTN), точки, блочная модель (XC, YC, ZC, XINC…, IJK; повороты — 8.7.2) | — | Э8 (каркасы, стринги), Э17 (блоки) | желательно (нужны образцы) |
| Surpac двоичные STR/DTM, `.mdl` | Не описаны | Только по образцам; до них — «сохраните как текстовый STR/DTM» | — | — | позже |
| Maptek Vulcan `.00t`, `.bmf`, `.dgd.isis` | Закрыты; официальный доступ — `mapteksdk` (проприетарная лицензия, требует установленного продукта Maptek) | В v1 — через экспорт Vulcan в DXF, OMF, CSV; реверс — только после образцов и юридической проверки (условия лицензии Vulcan у владельца) | — | — | позже |
| Vulcan `.arch_d` | Текстовый архив дизайна, структура видна, официального описания нет | Читатель линий и точек по образцам | — | после образцов (Э9 при наличии) | позже |
| Micromine прочие (`.PIT`, `.GRD`, `.DHDB`) | `.PIT` = STR + Road (9.3); `.GRD` — заголовок 592 байта, double по строкам (9.10); `.DHDB` — не описан | `.PIT` — тем же читателем STR (Э7); `.GRD` — как ЦТМ-сетка после образца; `.DHDB` — реверс по образцам | — | Э7 / позже | желательно / позже |
| «DNG» | Неясно | Если Adobe Digital Negative (TIFF/EP): tifffile читает структуру и встроенное JPEG-превью без демозаики; полноценная обработка — rawpy (MIT), но внутри LibRaw под LGPL-2.1 или CDDL-1.0 — нельзя. Привязки у снимка нет (только GPS в EXIF) — растр с ручной привязкой. Если DGN (MicroStation): v7 открыт — свой читатель; v8 — только продукты ODA (ODA File Converter рассчитан на DWG/DXF — проверить при ответе) | — | после ответа | вопрос |

Общие правила читателей — 9.12 (потоково, прогресс, отмена, негативные тесты, «бомбы», журнал операции, цикл «импорт → экспорт → импорт» для форматов с экспортом). Мастер «Импорт файлов» (7.8) узнаёт новые расширения: `.shp .dbf .shx .prj .cpg .mif .mid .dm .dwg .pit` (`.dm`, `.dwg` — по ответам).

## Отвергнуто

| Вариант | Почему нет |

| LibreDWG, `@mlightcad/libredwg-web` 0.9.0 | GPL-3.0 |

## Причины

- SHP и MIF/MID открыто описаны и малы: pyshp — 73 КБ, чистый Python; MIF — текст, свой разбор короче и надёжнее, чем зависимость.
- DWG по варианту А не добавляет ни зависимости, ни лицензионного риска: программа пользователя, внешний процесс, обёртка уже в стеке (ezdxf MIT).
- Закрытые форматы (DM, Vulcan, двоичный Surpac) нельзя «угадывать» (17.1.3): только описание + образцы владельца + тесты на них.

## Последствия

- ТЗ 9.12: строка «Datamine DM, DWG, Shapefile — нет в v1» заменяется ссылкой на ТЗ 7.35 Д-13 (в docx v1.1).
- Новое правило проверки зависимостей: для колёс с вложенными DLL (`*.libs`, `*.dylibs`) — ручной разбор лицензий вложенных библиотек в ADR-дополнении; желательно — расширить `check_licenses_py.py` списком известных библиотек (GEOS, iconv, LibRaw, spatialite).
- Образцы владельца — в `tests/data/real/` (только чтение); без образца формат не объявляется готовым.

## Проверка

| Что | Как |
|---|---|
| SHP: точки, линии, полигоны с Z, атрибуты, cp1251, `.prj` | pytest на синтетике (pyshp пишет эталоны в тесте); негативные: обрезанный `.shp`, нет `.shx`, битый `.dbf` |
| MIF/MID: все типы объектов, CoordSys | pytest на синтетике и образце владельца |
| GeoTIFF: привязка по tiepoint + scale и по ModelTransformation | pytest: координаты углов = эталон (1e−9); сжатый файл без imagecodecs → понятная ошибка |
| DWG (А) | pytest с подменой конвертера (фальшивый исполняемый файл); ручная на Windows с установленным ODA File Converter; без него — сообщение с подсказкой |
| DM | pytest на образцах владельца: объём каркаса = объёму из Datamine (1e−9 отн.), число блоков и центры (1e−6 м) |
| Скорость | SHP и MIF 1 млн вершин ≤ 10 с; DM 20 млн блоков ≤ 8 мин (5.3); память — 5.3 |
| Лицензии | `check_licenses_py.py` после `uv lock`; запись версии и лицензии в ADR 0001 |
