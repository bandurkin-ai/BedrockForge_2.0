## Варианты
| Вопрос | Варианты | Выбор и причина |
|---|---|---|
| Решатель RBF | А) разбиение единицы (PoU), плотная LU на участок (8.9.2); Б) один глобальный итерационный (GMRES / FMM); В) одна глобальная плотная система | **А.** Задан ТЗ; участки независимы → потоки и побитность. Б — нет готовой библиотеки с разрешённой лицензией, итерации зависят от порядка суммирования; В — 100 тыс.² × 8 Б = 80 ГБ |
| Параллельность участков | А) потоки Python над `scipy.linalg.lu_factor/lu_solve` (LAPACK отпускает GIL), BLAS 1 поток (`threadpoolctl`); Б) процессы `spawn`; В) своя LU на numba `prange` | **А**, проверка спайком 19.2 (ускорение ≥ 3 на 4 потоках). Не прошло — **В** (детерминирована, без GIL, медленнее в 2–3 раза). Б — копии матриц и запуск процессов съедают выигрыш на участках ≤ 4 тыс. точек |
| Поле в узлах кирпичей | А) прямая сумма numba по кирпичу, список участков кирпича один на все его узлы; Б) расстояния через GEMM (‖x‖² + ‖y‖² − 2x·y) и BLAS | **А**: без вычитания близких чисел, побитна. Оценка: ≈ 1e11 слагаемых на 2 млн треугольников — на грани 90 с; замер 19.4, не укладывается — Б для узлов дальше 1e−3·R участка от точек, решение записывается |
| Разлом (Д-24) | А) разрывное поле f = f₁ / f₂ и особая изоповерхность у разлома; Б) поле на крыло, тело крыла = {f_k < 0} ∩ полупространство крыла (manifold3d) | **Б.** Изоповерхность 8.9.3 не меняется; каркасы крыльев замкнуты и не пересекаются по построению; граница крыла — точно по поверхности разлома |
| Выходы модели | А) каркасы (`wireframes`) с `parent_id` = модель; Б) blobs внутри модели и свой показ | **А.** Показ, LOD, проверки, экспорт, булевы, кодирование (Д-33, Д-34) уже работают с каркасами |
| «Обновить» (Т8.9-8) | А) кеш по содержимому: участок = хеш (центр, R, точки в каноническом порядке, значения, параметры), кирпич = хеш (узлы, участки); Б) правка октодерева на месте | **А.** Побитно равно полному построению по определению: всё, что не взято из кеша, считается тем же кодом; Б расходится с полным построением |
| Объём этапа | А) один PR; Б) два PR: Э19 (8.9, Д-15, Д-25, Д-32, Д-33, Д-34 ч. 1) и Э19б (Д-24, Д-31, Д-39, проектные скважины) | **Б** (как Э18/Э18б; № 96): ориентиры ТЗ ≈ 8 окон; Э19 — законченная функция, Э19б расширяет конвейер групп, не переписывая (Д-24: «расширить, не переписывать 8.9») |

### 6. Стек отношений (Э19б; `stack`, `faults`, `vein_system`)
| № | Решение |
|---|---|
| 19 | Порядок: разломы → группы от молодой к старой. «Эрозия» — точки старой группы с f_молодой < 0 отбрасываются, тело старой минус тело молодой; «Налегание» — точки молодой ниже старой поверхности отбрасываются, тело молодой ∩ {f_старой ≥ 0}; «Интрузия» (Д-31) — точки всех старших групп внутри {f_I < 0} отбрасываются, тело I вычитается из старших и обрезается младшими. Маска — по значению поля в точке (не по каркасу) |
| 20 | Разлом: своё RBF f_F; крылья — тело {f_F < 0} по 8.9.3 и его дополнение до границы; у группы «рассечена разломом» данные делятся по знаку f_F (abs(f_F) ≤ 1e−9·h — на оба крыла), поле крыла — свой PoU; тело крыла = {f_k < 0} ∩ крыло. Конечный разлом: g_k = w·f_k + (1 − w)·f_0, w = W(r/R_F), r — до ближайшей точки данных разлома, f_0 — поле без деления; за R_F g_1 = g_2 = f_0 побитно (Т8.9-12). Несколько разломов — крылья по сочетанию знаков, в порядке списка |
| 21 | Система жил (Д-39): по возрасту, тело древней минус тела младших; общее тело — объединение; линии пересечения — `geo/crossing.intersection_lines`; таблица пар (длина линии, объём общей зоны до обрезки). Общая зона отдельным кодом — нет (№ 94) |
