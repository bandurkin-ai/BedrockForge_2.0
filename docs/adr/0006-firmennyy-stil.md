# ADR 0006. Фирменный стиль: палитра, шрифты, знак

Статус: принято · 2026-11-17 · Этап: Э5 (по указанию заказчика, для всех выпусков)

## Контекст

Заказчик передал доску фирменного стиля (Concept 6): палитра из пяти цветов, шрифты Montserrat и Inter, знак-куб
«B» и иконка приложения; применять во всех выпусках. Приложение работает офлайн — шрифты должны быть встроены.

## Решение

| Пункт | Решение |
|---|---|
| Палитра | Anthracite `#1B222B`, Cobalt `#1F6BFF` (акцент `--accent`), Copper Orange `#F46A1A` (`--highlight`, «Forge»), Light Stone `#E6E9EE`, Slate `#8A99A8`; обе темы в `ui/src/styles/tokens.css` |
| Шрифты | `@fontsource/montserrat` 5.3.0 и `@fontsource/inter` 5.3.0 (точные версии, `--before=2026-11-09`), woff2 с подмножествами латиница + кириллица; заставка — копии woff2 в `app/static/fonts` |
| Лицензия шрифтов | **SIL OFL-1.1**: разрешает встраивание и распространение шрифтов вместе с программой любой лицензии; не копилефт для программы. Белый список ТЗ (MIT/BSD/Apache/MPL/ISC/PSF) относится к библиотекам кода; OFL-1.1 допускается **только для шрифтов**. `check_licenses_npm.mjs` запрещает GPL/LGPL/AGPL — OFL проходит |
| Знак и иконка | Растр с доски: `docs/brand/logo-mark.png` (прозрачный фон), `app-icon-256.png` → `app/assets/icon.ico` (16–256 px) и `app/static/icon.png` (иконка окна) |
| Правила выпусков | `docs/brand/README.md`, раздел «Выпуски» |

## Причины

- Встроенные шрифты одинаково выглядят на любой Windows 11 без интернета.
- @fontsource — те же файлы Google Fonts с подмножествами; разметка `unicode-range` загружает только нужные начертания.

## Последствия

- Размер интерфейса +≈1,5 МБ (woff2 всех подмножеств выбранных начертаний).
- Иконка 256 px — увеличение с доски; векторный знак — по получении от заказчика (замена файлов без правки кода).
- Заказчику: подтвердить допуск OFL-1.1 для шрифтов (вопрос в отчёте вехи В2).
