# ADR 0010. Экспорт проекта пакетом и менеджер данных (Д-17, Д-20)

**Статус:** проект, 2026-11-17. Принимается ответом владельца на вопросы ТЗ 7.35.6 № 10–11; реализация — Э11 (В3), листы PDF — Э22.

## Контекст

- ТЗ 7.4: «Экспорт проекта» — только `.bfggis` (перенос в BF2). Владелец (Д-17): «экспорт всех данных во всех поддерживаемых форматах одним комбайном; передача проекта целиком, включая настройки отображения (минимум — PDF)» — это второй назначенный способ экспорта, меняющий принятый текст 7.4 и подсказку кнопки 7.0.4.
- Д-20: менеджер данных «как ESRI ArcGIS — управление данными проекта как файлами, импорт и экспорт прямо из его области». Хранилище проекта — неизменяемые `blobs` с именами SHA-256 и описания в SQLite (ADR 0002 §5, 17.3.10): настоящих «файлов объектов» в папке проекта нет и быть не должно.
- PDF в ТЗ выбран на Э22: SVG листа → скрытое окно Electron → `webContents.printToPDF`, склейка — pdf-lib (8.12.1). Писатели форматов появляются на Э4 (DAT/CSV/XLSX), Э7 (STR, DXF, GeoTIFF), Э8 (TRIDB, DXF, OBJ, STL, DTM), Э11 (OMF), Э17 (блоки), Э22 (макеты).

## Решение

### 1. Пакет для передачи (Д-17)

| Тема | Решение |
|---|---|
| Окно | То же модальное «Экспорт проекта» (7.0.12), переключатель «Файл проекта (.bfggis)» / «Пакет для передачи». В пакете: матрица «тип объекта × формат» (по умолчанию — все форматы, где есть писатель), «Папка» или «ZIP», «Добавить .bfggis», путь — «Сохранить как» (папка) |
| Состав | `<Проект>_<ГГГГ-ММ-ДД>/`: `README.txt` (по-русски: что где и чем открыть), `manifest.json` (версии программы и схемы, список файлов с SHA-256, размером, исходным объектом и форматом), `Паспорт проекта.pdf` (всегда), `Скважины/<набор>/…` (DAT, CSV, XLSX), `Каркасы/`, `ЦТМ/`, `Линии/`, `Растры/` (исходник + привязка, GeoTIFF), `Блочные модели/` (с Э17), `OMF/<проект>.omf`, `Стили/styles.bfstyle.json`, `Виды/views.json` + PNG снимков, `Листы/` (PDF макетов, с Э22), по выбору `<проект>.bfggis` |
| Реестр писателей | `core/bf_core/exporting/registry.py`: `(kind, format) → writer(object, path, progress)`; регистрирует каждый модуль явным импортом (как обработчики заданий, 17.3.9). Пакет, менеджер данных и отдельные команды экспорта зовут один реестр |
| Задание | `export.package` (очередь `heavy`): пишет во временную папку рядом с целью, затем переименование (ZIP — `zipfile` стандартной библиотеки, ZIP64); отмена и сбой не оставляют частичного пакета; журнал операции (7.9); «Показать в папке» |
| Паспорт PDF | Интерфейс собирает HTML/SVG (фирменные шрифты, ADR 0006) → скрытое окно → `printToPDF` A4 (тот же путь, что 8.12.1, без новых зависимостей). Содержание: титул, состав и счётчики по типам, наборы (скважины, пробы, компоненты, итог аудита), системы координат, сохранённые виды (Д-09) — снимок PNG и легенда отображений, список файлов пакета. Водяной знак лицензии (5.7) |
| Ограничения | Режим «только просмотр» (5.7) — экспорт недоступен; задание с паролем — только для `.bfggis` внутри пакета (остальные файлы — открыты, предупреждение в окне) |
| Команда | `project.export {mode: "bfggis" или "package", formats?, zip?, include_bfggis?, filename}`; без `mode` — `bfggis` (старые вызовы работают) |

### 2. Менеджер данных (Д-20)

| Тема | Решение |
|---|---|
| Что это | Логический каталог над `objects` (тип, папка `objects.folder`, имя, `meta`, размеры blobs через `blob_owners`), а не файловая система. Хранилище не меняется |
| Окно | Плавающее «Менеджер данных · \<проект\>» (размер «обычный»): папки слева, таблица справа (виртуальная прокрутка), выбор нескольких, сортировка, поиск; строки дерева — общий `TreeRow` (ADR 0008) |
| Действия | Импорт в папку (системный диалог или перетаскивание из Проводника → мастер 7.8 с папкой назначения); экспорт выбранного (форматы — из реестра писателей); переименование; перенос между папками перетаскиванием (`dataset.move`); удаление (`askConfirm`, `danger`); «Показать в 3D»; «Свойства»; «Исходный файл → Сохранить копию как…» (копия blob исходника) |
| API | `GET /api/v1/catalog?folder=&q=&sort=&offset=&limit=` — страница строк каталога; остальное — существующие API импорта, экспорта, объектов |
| Команда | `data.manager` (uiOnly), кнопка «Настройки проекта → Данные → Менеджер данных» |

## Варианты

| Вариант | Плюсы | Минусы | Выбор |
|---|---|---|---|
| **А. Пакет — режим окна «Экспорт проекта», PDF через Chromium** | Одна точка экспорта; без новых зависимостей; PDF-конвейер Э22 начинается раньше и переиспользуется | Паспорт до Э22 — без листов в масштабе | **Да** |
| Б. Отдельная команда «Экспорт всего» | Не трогает 7.4 | Две похожие кнопки — владелец просит убирать дубли (Д-05, Д-08) | Нет |
| В. PDF в ядре (reportlab 5.1.0, BSD) | PDF без окна Electron | Второй конвейер PDF рядом с 8.12; свои шрифты и вёрстка; +2 МБ | Нет |
| Менеджер: настоящие файлы объектов в папке проекта | «Как в ArcGIS» буквально | Ломает ADR 0002 (неизменяемые blobs SHA-256, транзакции, сборщик) | Нет |

## Риски

| Риск | Мера |
|---|---|
| Пакет большого проекта долгий и тяжёлый | Потоковые писатели, прогресс по объектам; бюджет: проект 2 ГБ ≤ 5 мин, ≤ 1 ГБ (`bench/scenarios/project_package.py`) |
| Формат без писателя на момент Э11 | В матрице недоступен с причиной («Экспорт блочных моделей — этап Э17»); `manifest.json` перечисляет пропущенное |
| Имена файлов из имён объектов | Очистка запрещённых символов Windows, длина пути ≤ 260 (17.2.3), имена не различаются только регистром (17.2.1) — уникализация «(2)» |
| Снимки видов без GPU | Снимок с программного рендера помечается в паспорте; на ПК приёмки — ручная проверка |
| Менеджер дублирует дерево | Общие команды и `TreeRow`; одна модель каталога в чистом модуле |

## Последствия

- ТЗ 7.4 и 7.0.4 (подсказка «Экспорт проекта»), 9.12 (пакет — новый «формат») правятся в docx v1.1 через ТЗ 7.35.
- Ориентир Э11 растёт с 1 до 2–3 окон 5 ч (OMF + пакет + менеджер); если менеджер не укладывается — переносится на Э26 (приоритет «желательно»).
- Э22 добавляет в пакет папку `Листы/`; Э17 — блочные модели.

## Проверка

| Что | Как |
|---|---|
| Пакет демо-проекта | pytest: каждый файл импортируется обратно (счётчики, координаты побитно для STR/DXF/OBJ/TRIDB); SHA-256 манифеста совпадают |
| Отмена и сбой | pytest: снятие исполнителя посреди записи — ни папки, ни ZIP |
| Паспорт | E2E: PDF создан; pdfminer.six (dev) извлекает кириллический текст; страницы — сводка и по одной на сохранённый вид (до 20) |
| Менеджер | vitest: модель каталога; E2E: перетаскивание `.str` в папку, экспорт двух каркасов в DXF |
| Скорость | `project_package` в `bench` (`ci` — демо; `full` — 2 ГБ); список 1000 объектов ≤ 200 мс |
