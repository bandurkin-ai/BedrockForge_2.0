# Форматы файлов Micromine

Источник: официальная справка Micromine (Internal File Types, v18) и справка по импорту/экспорту (v21–25.5).
Побайтовой публичной спецификации вендор **не публикует** — ниже только то, что подтверждено документацией.

## Нативные форматы

| Данные | Расширение | Что известно |
|---|---|---|
| Таблицы (Data) | `.DAT` | «Текстовый» файл, но может содержать бинарные данные. Заголовок двух типов: Standard и Extended. Extended — одна или несколько страниц по 4096 байт; первые 42 символа первой страницы — «магическая» строка-идентификатор; остальное место заголовка — XML с описанием свойств файла. |
| Блочные модели | `.DAT` (+ `.metax`) | Частный случай Data-файла. Выделенных координатных полей нет — пользователь назначает поля центроидов. Поля с префиксом `_` — размеры блоков. Неактивные координатные поля считаются атрибутами. Метаданные — в extended-заголовке или в `.metax`. Индексы моделей — в подпапке `METADATA`. |
| База скважин | `.DHDB` | Collar (обязательно) + Survey (опционально) добавляются в БД и обновляются по необходимости. Interval и Event — только как внешние ссылки на файлы. |
| Каркасы | `.TDB` (≤ v14, 2013), `.TRIDB` (≥ v15, 2014) | БД, каркасы хранятся как BLOB с пользовательскими атрибутами по «Wireframe Type». Один файл БД на тип каркаса. |
| Каркасы (обмен) | `*_MMpt.dat`, `*_MMtr.dat` | Пара «точки + треугольники» в формате `.DAT`; читают/пишут Leapfrog и др. |
| Стринги | `.STR` | Data-файл с полем STRING и (опционально) JOIN. |
| Pit | `.PIT` | String-файл + дополнительное поле Road. |
| Survey | `.SVY` | Data-файл с маркшейдерскими данными. |
| Профили | `.SEC`, `.STP` | Data-файл, 3 поля: номер профиля, X, Y. STP — нумерация с 1 шагом 1; SEC — значения привязаны к сечениям (суффикс N/E). Внутри профиля сортировка по возрастанию X. |
| Контуры | `.OUT` | Формат отличается от Data. Набор полигонов с атрибутами отображения/группировки. |
| Гриды | `.GRD` | 2D-массив double по строкам с левого верхнего угла. Пустой узел = `-100000000`. Перед данными заголовок **592 байта**. |
| Контроль сечений | `.DAT` | Подпапка `SECTIONS` проекта. |
| Справочники | `.LDT`, `.LBN`, `.LK` | `.LDT` — lookup-таблица (исходник), `.LBN` — скомпилированная, `.LK` — файл ссылок на lookup. |
| Макросы | `.MCR` | Вызовы функций и сохранённых наборов форм. |
| Наборы форм | `.BDB` (MS Access), `.mmsetx`, `.set`, `.xpm` | Системные параметры: `FLDVAL125.bdb` в папке Environment. |
| Plot Editor | `.PEX`, `.PTX`, `.PEL`, `.PED`, `.PEP`, `.PLS`, `.PGL` (HPGL), `.PRN` | Макеты, шаблоны, данные плота. |
| Vizex | `.VFLY`, `.FLY`, `.GRF` | Траектории пролёта, георефенс-файлы. |
| Mine Design | `.RDF` | Параметры Ring Design. |
| Отчёты | `.RPT`, `.REP` | Результаты процессов, ASCII-отчёты. |

## Проект

Отдельного файла проекта нет — проект это **папка**. Подпапки:

| Папка | Содержимое |
|---|---|
| `SECTIONS` | `.DAT` контроля сечений |
| `METADATA` | индексы блочных моделей |
| `SchedulerDataFiles` | данные календарного планирования |
| `RingDesignDATFiles` | таблицы по кольцам |

Смена расширения файла ломает его поиск в проекте.

## Форматы обмена (импорт/экспорт Micromine)

| Тип | Форматы |
|---|---|
| Каркасы | DWG, DXF, DXB, DGN, Vulcan `.00t`, Surpac `.dtm`, Datamine `.tr`/`.tr.dm`, PLY, RAW, OMF, OBJ, DAE, BLEND, 3DS, ASE, FBX, STL, Leapfrog `.msh`, GOCAD `.ts` |
| Блочные модели | Vulcan `.bmf`, Surpac `.mdl`/`.fbm`/текст, Datamine текст/`.dm`, OMF, UBC Mesh, текстовый экспорт `.txt` |
| Стринги | Datamine `.dm`/текст, Surpac `.str`, текст |

## Не найдено (нужен реверс-инжиниринг)

- Типы полей, кодировка, порядок байт `.DAT`; схема XML extended-заголовка.
- Структура BLOB в `.TRIDB`/`.TDB`.
- Формат `.DHDB`.
- Структура `.OUT`.
- Открытых парсеров на GitHub не обнаружено.

## Рекомендации для разработки

- Нейтральный обмен: OMF, CSV, DXF.
- Старт реверса: `.DAT` с XML в заголовке (страница 4096 байт, magic 42 символа).
- Для `.GRD` формат известен достаточно: заголовок 592 байта + double.
