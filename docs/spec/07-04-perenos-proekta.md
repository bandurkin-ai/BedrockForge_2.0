### 7.4. Перенос проекта (`.bfggis`) \[Э2\]

**Назначение.** Весь проект — один сжатый файл `*.bfggis` для переноса на другой компьютер.

**Состав файла:** наборы со всеми таблицами; журнал правок (отмена работает в копии); аудит; каркасы и ЦТМ; линии с версиями; растры; блочные модели; графики; стили; диалоги Claude; исходные файлы. По желанию — настройки вида (видимость слоёв, открытые колонки, стили устьев, стволов и блоков, порядок разделов дерева). **Не входят:** задания, незавершённые загрузки \[сервер\], учёт расходов Claude.

**Экспорт** — «Главная → Экспорт проекта», «Экспорт» в окне «Проекты», значок в строке проекта, `project.export`. Окно: состав и объём; имя (по умолчанию «Проект_ГГГГ-ММ-ДД»), путь — «Сохранить как»; пароль — шифрование **AES-256**, пароль нигде не сохраняется; галочка «Настройки вида»; прогресс задания `export.project`; у готового задания — «Показать в папке». \[сервер\] «Скачать»: ссылка живёт **48 ч**, есть во вкладке «Задания», докачка (HTTP `Range`).

**Импорт** — «Главная → Импорт проекта», «Импорт…», `project.import`.

| **Шаг**      | **Требование**                                                                                                                                                                                                                              |
|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1\. Файл     | Системный диалог или перетаскивание; ядро читает файл с диска без копии; до **256 ГБ**. \[сервер\] Загрузка частями с SHA-256 каждой части, продолжение после обрыва или перезапуска клиента                                                |
| 2\. Проверка | Название, описание, дата экспорта, версии программы и схемы, состав; для зашифрованного — пароль. Название занято — «Создать копию «Имя (2)»», «Другое название», «Заменить существующий» (старый удаляется только после успешного импорта) |
| 3\. Импорт   | Прогресс задания `import.project`; «Открыть проект» применяет настройки вида из файла                                                                                                                                                       |

**Надёжность**

- Одна транзакция: при ошибке не остаётся ничего, заменяемый проект цел.

- Все id создаются заново, ссылки пересчитываются; результат содержит соответствие старых и новых id.

- Проверяются контрольные суммы таблиц и файлов.

- Файл новее программы отклоняется («обновите программу»); старый — обновляется до текущей схемы. Файлы `.bfggis` из BF открываются в BF2 как файлы старой версии.

- Пароль хранится в параметрах задания, только пока его не взял исполнитель; в состоянии задания и журналах его нет.

**Хранение.** Экспорт проект не меняет; импорт создаёт новый проект в папке данных (7.3).

**Приёмка**

- Экспорт → импорт дают тот же состав: счётчики, значения, итог аудита, версии линий; отмена правки, сделанной до экспорта, работает в копии.

- Неверный пароль останавливает импорт на шаге 2 с понятным сообщением.

- Обрыв на любом шаге (в том числе снятие процесса) не оставляет частичного проекта; при «Заменить» старый цел.

- Файл более новой версии отклоняется с текстом «обновите программу». Пароля нет в состоянии задания и журналах.

- `.bfggis` демо-проекта из BF открывается в BF2 с теми же счётчиками и итогом аудита.

- \[сервер\] Прерванная загрузка продолжается без повторной передачи принятых частей.
