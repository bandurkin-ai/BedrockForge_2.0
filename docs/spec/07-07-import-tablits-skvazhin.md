### 7.7. Импорт таблиц скважин (мастер) \[Э3\]

**Назначение.** Загрузка Collar, Survey, Assay, интервальных таблиц и событий в набор.

**Шаги:** «Устья» → «Инклинометрия» → «Интервалы и события» → «Импорт» («Шаг N из 4»). На шаге — файл и назначение колонок; несколько файлов сразу раскладываются по шагам по колонкам. **Форматы:** Micromine DAT, CSV/TXT, Excel `.xlsx`/`.xlsm`; `.xls` отклоняется с советом пересохранить в `.xlsx` (поддержка — 7.34).

| **Возможность**     | **Требование**                                                                                                                                                                                                                                                                                                                     |
|---------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Кодировка           | Автоопределение: UTF-8 (с BOM и без), UTF-16, cp1251, cp866, KOI8-R; ручной выбор                                                                                                                                                                                                                                                  |
| Разделитель         | `;`, `,`, табуляция, вертикальная черта, пробелы — по одинаковому числу полей в строках                                                                                                                                                                                                                                            |
| Заголовок           | Номер строки с названиями (пустые не считаются); 0 — без заголовка; титульные строки пропускаются                                                                                                                                                                                                                                  |
| Лист Excel          | Первый лист с данными, можно выбрать другой                                                                                                                                                                                                                                                                                        |
| Числа               | Точка или запятая, пробелы между разрядами (`4 584 699,70`)                                                                                                                                                                                                                                                                        |
| Предел обнаружения  | `<0.005` → 0.0025 (половина), `>1000` → 1000; показывается число заменённых                                                                                                                                                                                                                                                        |
| Пустые              | `-`, `н/д`, `н.о.`, `NA`, `N/A` и т. п.                                                                                                                                                                                                                                                                                            |
| Названия колонок    | Русские и английские («Скважина», «От», «До», «№ пробы», «Глубина (м)», «X, м», «Au, г/т»); единица — из названия                                                                                                                                                                                                                  |
| Подбор колонок      | Словарь Micromine, Datamine, Surpac, Vulcan, Leapfrog, acQuire и русских таблиц; без учёта регистра, разделителей и единиц (`Depth_m` = `DEPTH`); обрезанные до 8–10 символов (`DrillholeI` = `DrillholeID`, `GridBearin` = `GridBearing`); истинный или сеточный азимут предпочитается магнитному; пользователь правит назначение |
| Тип таблицы         | Автоопределение: устья, инклинометрия, пробы, интервалы                                                                                                                                                                                                                                                                            |
| Компоненты          | Галочкой, единица для каждого                                                                                                                                                                                                                                                                                                      |
| Ошибки в числах     | Текст в числовом поле — с примером и числом строк                                                                                                                                                                                                                                                                                  |
| Загрузка с ошибками | При ошибках только в данных — флажок «Загрузить с ошибками — исправлю в BedrockForge»: нечисловое значение пустое, текст — в атрибуте «\<колонка\> (исходное)»; без номера — «БЕЗ НОМЕРА (строка N)»; повтор устья — «\<номер\> (повтор k)». Ошибки назначения колонок так не загружаются                                          |
| Предпросмотр        | Нормализованные данные и замечания до записи                                                                                                                                                                                                                                                                                       |
| Режим               | «Заменить»: таблица того же типа заменяется только в своём наборе                                                                                                                                                                                                                                                                  |
| История импорта     | Файл, назначение колонок, число строк — в проекте вместе с исходным файлом                                                                                                                                                                                                                                                         |

**Эквивалентность.** Одни и те же данные в CSV (cp1251, `;`, десятичная запятая), Excel и DAT дают одинаковый проект: строки, значения, итог аудита.

**Хранение.** Строки — в таблицах набора (7.10); история импорта и исходный файл — в проекте.

**Приёмка**

- CSV в cp1251 с `;` и десятичной запятой читается без ручных настроек.

- `Hole_ID`, `From_m`, `To_m`, `Au_ppm` назначаются сами, единица `ppm` подставляется.

- `<0.01` сохраняется как 0.005, на экране — счётчик замен.

- `.xls` отклоняется с советом пересохранить.

- С флажком «Загрузить с ошибками» «abc» в AU становится пустым, а «abc» — в атрибуте «AU (исходное)».

- Повторный импорт устьев в набор 1 не меняет набор 2 с теми же номерами.

- Таблица на 5 млн проб импортируется без нехватки памяти.
