### 8.11. Оптимизация карьера \[Э21\]

#### 8.11.1. Функции

Вложенные оптимальные оболочки по коэффициентам выручки RF, как в Micromine Pit Optimiser: экономическая модель блока, углы бортов по секторам и доменам, рельеф, максимальное замыкание (эквивалент алгоритма Лерча–Гроссмана), отчёт pit-by-pit, лучший и худший случаи.

#### 8.11.2. Экономика и углы

    t_b = V_b·ρ_b·f_b, f_b — доля ниже рельефа; f_b = 0 — «воздух»: вне графа, не пустая порода
    R_b = Σ_e t_b·g_e,b·k_e·rec_e(r_b)·(RF·P_e − S_e)·(1 − roy_e)   (r_b — тип породы, S — сбыт на единицу металла, roy — роялти)
    C_m,b = t_b·(c_m0 + c_гл·max(0; (Z_ref − z_b)/H_гл));   C_p,b = t_b·(c_p(r_b) + c_mр)   (c_mр — доплата за добычу руды)
    v_b = max(R_b − C_p,b; 0) − C_m,b;  руда при R_b − C_p,b > 0;  тип «только пустая» → R_b = 0
    целые для решателя: v'_b = round(v_b/q), q = max(0,01; Σ abs(v_b)/10¹⁶); ошибка цели ≤ N·q/2 выводится
    угол φ(az): до 16 секторов (азимут центра, угол), между центрами — линейно; у домена своя таблица; выбор — по домену нижнего блока
    шаблон: смещения (Δi, Δj, m), m = 1…K уровней вверх; входит, если √((Δi·dx)² + (Δj·dy)²) ≤ m·dz/tan φ(az(Δi, Δj));
      исключается смещение, равное сумме смещений шаблона меньших уровней
    K — наименьшее ≥ 8 (и ≤ 20), при котором K·dz/(min(dx, dy)·tan φ_max) ≥ 8
    контроль угла: R(M) — достижимые замыканием шаблона на M = 2K уровней; ρ(az) = max_(o ∈ R(M)) o·û(az);
      φ_эфф(az) = atan(M·dz/ρ(az)) через 1°; ошибка max abs(φ_эфф − φ) > 2,5° — предупреждение «увеличьте K»

Проверено на прототипе: 45°, кубические блоки, K = 8 — 17 смещений, ошибка 1,44° (средняя 0,58°); секторы 40° (север) … 50° (юг) — 1,63°; 55°, K = 12 — 2,05°. v_b не убывает с RF, поэтому оболочки вложены при выборе наименьшего оптимального замыкания.

#### 8.11.3. Максимальное замыкание

    max Σ_(b ∈ C) v'_b по замкнутым C;  сеть: s → b (v'_b > 0), b → t (−v'_b при v'_b < 0), b → предшественник — бесконечность
    карьер — вершины, достижимые из s в остаточной сети (наименьшее оптимальное замыкание)
    предобработка: исключаются блоки вне объединения конусов над блоками с v_b > 0 при RF_max
    оболочки RF (по умолчанию 0,30…1,50 шаг 0,05): сначала RF_max на всём графе; для RF внутри (RF_a; RF_b) граф сужается до
      C(RF_b) \ C(RF_a), интервалы делятся пополам рекурсивно
    основной решатель — псевдопоток Хохбаум (HPF, вариант для задачи замыкания, нормализованное дерево) на numba;
      дуги не хранятся — строятся из шаблона и плотного индекса блоков (int32, nx·ny·nz); поток хранится только у рёбер дерева
      (у дуг вне дерева в задаче замыкания он нулевой — утверждение в отладочной сборке)
    запасной и эталонный (до 1 млн блоков в графе) — OR-Tools SimpleMaxFlow с явными дугами; в тестах — scipy.sparse.csgraph.maximum_flow
    режим «явные дуги» (список предшественников) — для наборов MineLib

#### 8.11.4. Отчёт и выходы

    оболочка C_k, приращение ΔC_k = C_k \ C_(k−1), базовая цена (RF = 1): руда и пустая (т), коэффициент вскрыши, содержания,
      металл в руде и извлекаемый, выручка, затраты на добычу, переработку, сбыт, недисконтированный поток CF
    лучший случай для конечного карьера n — ΔC_1 … ΔC_n по порядку; худший — C_n по уступам сверху вниз
    τ_i = max(O_i/Q_р; (O_i + W_i)/Q_гм);  t_i = Σ_(j<i) τ_j   (Q_р — переработка, Q_гм — горная масса, т/год)
    NPV = Σ_i CF_i·((1 + r)^(−t_i) − (1 + r)^(−(t_i + τ_i)))/(τ_i·ln(1 + r));  τ_i = 0: CF_i·(1 + r)^(−t_i)

Выходы: поле PIT (наименьшая оболочка с блоком, 0 — вне), поле ORE (руда при RF = 1); поверхности оболочек — ЦТМ (z столбца — низ нижнего вынутого блока, иначе рельеф); выбранная оболочка → каркас карьера (тело между рельефом и поверхностью, manifold3d); таблица pit-by-pit; график — столбцы руды и пустой, линии NPV лучшего и худшего случаев и CF; сравнение сценариев.

#### 8.11.5. Параметры, интерфейс, производительность

Параметры: RF 0,30–1,50 шаг 0,05 (0,01–5, до 200 оболочек); K — авто (1–20); r = 8 % (0–50 %); H_гл = 10 м, c_гл = 0; допуск угла 2,5° (0,5–10°). Вкладка «Карьер»: «Сценарий» — Новый сценарий, Экономика, Породы, Углы бортов, Рельеф, Календарь (Q_р, Q_гм, r); «Расчёт» — Проверить шаблон, Запустить (недоступна, пока не заданы цены, извлечения и затраты для всех типов пород); «Результаты» — Pit-by-pit, Поверхности, Каркас карьера, Сравнить. В проекте: «Сценарий» (параметры, хеш модели, шаблон, ошибка угла), поля PIT и ORE, ЦТМ оболочек, отчёт.
