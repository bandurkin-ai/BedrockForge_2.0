### 8.7. Блочные модели \[Э17\]

#### 8.7.1. Функции и решение о повороте

Создание и заполнение, субблоки, калькулятор, ограничители, плотность, категории, показ 20 млн блоков на встроенной графике, обмен. Закрывает CHECKLIST № 21, 31, 301–310, 335.

**Поворот в v1 — только вокруг Z** (один угол): модели вдоль простирания часты, а расчёты ведутся в локальных осях, поэтому поворот стоит одного преобразования координат на входе. Модель с поворотом вокруг X или Y импорт отклоняет: «поворот вокруг X/Y в v1 не поддерживается».

#### 8.7.2. Прототип, субблоки, хранение

    p = O + R_z(φ)·q,  R_z(φ) = [[cos φ, −sin φ, 0], [sin φ, cos φ, 0], [0, 0, 1]];  φ ∈ (−180°; 180°] — против часовой стрелки при виде сверху
    O — угол модели (минимум локальных координат); родитель (i, j, k): q ∈ [i·dx; (i+1)·dx) × [j·dy; (j+1)·dy) × [k·dz; (k+1)·dz)
    индекс P = (k·ny + j)·nx + i (int64), nx·ny·nz ≤ 2·10⁹
    субблоки — октодерево: уровень делит блок пополам по осям, где не исчерпано число уровней оси (Lx, Ly, Lz ≤ 7);
      субблок = P + смещение и размер в подъячейках 2^Lx × 2^Ly × 2^Lz (uint8 × 6); импорт принимает любые субблоки,
      выровненные по подъячейкам, иначе — отказ с номерами блоков

- Соглашения о повороте Micromine и Datamine задаются при импорте и проверяются: центры трёх блоков файла совпадают с вычисленными (≤ 1e−6 м). Прототип создаётся по охвату выбранных объектов с отступом, начало кратно размеру блока; в 3D — рамка с сеткой, рядом nx·ny·nz и объём на диске.

- Хранение — по 6.5: Parquet (zstd), строки в порядке (код Мортона родителя, sk, sj, si), группы строк по 2²⁰ с охватом и min/max полей; описание и атрибуты полей — в SQLite. Поле (или группа полей одного расчёта) — отдельный неизменяемый Parquet-файл в `blobs` с тем же порядком строк: новое или пересчитанное поле не переписывает остальные. Столбцы P и субблоков — один файл (субблоки — только при их наличии).

- Типы полей: float64 (по умолчанию для вычисленных), float32 (по выбору), int32/16/8, категория (int16 + словарь); у поля — единица, описание, источник. Расчёты читают столбцы группами строк в NumPy; распакованные копии для частого доступа (`.npy`, memmap) — в `cache\`. Запросы и группировки — DuckDB (встроенный parquet).

#### 8.7.3. Заполнение и кодирование каркасами

    1. каркасы замкнуты и согласованы (проверки раздела каркасов), иначе отказ с причиной; треугольники — в локальные оси
    2. родитель граничный, если его пересекает треугольник (тест параллелепипед — треугольник по разделяющим осям; индекс по ячейкам XY);
       неграничный — внутри или снаружи по чётности пересечений вертикального луча через центр столбца
    3. граничные делятся по уровням; на уровне L подъячейка относится к телу по центру
    4. FRAC (доля объёма) на уровне L и в режиме без субблоков — доля m×m×m центров подсетки внутри тела
    5. 8 потомков с одним кодом и FRAC ∈ {0; 1} сливаются в родителя рекурсивно
    6. лучи смещены от узлов на (√2·1e−6; √3·1e−6)·размер подъячейки — попадание в ребро или вершину исключено

Режимы: внутри, снаружи, оба; несколько каркасов — по приоритетам; выход — поле кода и FRAC. «Кодировать каркасами» — то же на готовой модели: по центру (субблоки не меняются) или с дроблением.

#### 8.7.4. Калькулятор полей

    операторы + − * / ^ ( );  = <> < <= > >=;  AND OR NOT;  IN ('A', 'B')
    функции ABS SQRT LN LOG10 EXP MIN MAX ROUND(x, n) FLOOR CEIL CLIP(x, a, b) IF(усл, a, b) ISNULL(x) COALESCE(x, y)
    поле — имя или [имя с пробелами]; строки — в одинарных кавычках
    NaN: арифметика → NaN; сравнение с NaN → ложь; IF с условием NaN → NaN
    собственный парсер (рекурсивный спуск) → дерево → numexpr или numpy по чанкам 2²⁰ строк; eval и exec запрещены;
    выражение ≤ 4000 символов, глубина ≤ 64; ошибка указывает позицию

Тот же движок — в редакторе таблиц (вычисляемые поля и фильтр, № 21, 31) и фильтрах показа и отчётов (№ 307). Блоки вне ограничителя не меняются или получают NaN (параметр).

| Ограничитель    | Внутри или снаружи каркаса (по FRAC или центру), выше или ниже поверхности (по центру или долей clip((z_пов − z_низ)/dz; 0; 1), z поверхности — в центре блока в плане), выражение; И, ИЛИ, НЕ (доля: И — произведение, ИЛИ — максимум). Объект дерева для отчётов, оценки, показа, калькулятора                                                                                                                   |
| Плотность       | Постоянная, поле, таблица «домен → плотность», формула; блок без плотности — значение домена по умолчанию и DENS_SRC = 1                                                                                                                                                                                                                                                                                           |

#### 8.7.6. Показ 20 млн блоков

- Режимы: оболочка блоков, прошедших фильтр; срез; все блоки в охвате (до лимита граней).

- Оболочку считает сервер (перенос BF `blocks/shell.py` с субблоками и фильтром); копланарные соседние грани одного цветового класса сливаются в прямоугольники; буферы float32 относительно центра объекта.

- Лимит видимых граней — по 6.8: 5·10⁶ (настройка 0,5–10·10⁶); выше — уровни 2×2×2, 4×4×4 … родителей (среднее по объёму, категория — мода), пометка «упрощено».

- Срез регулярной модели — одна текстура значений float32 и палитра в 1D-текстуре; с субблоками — растеризация на сетке подъячеек (до 4096×4096). Смена палитры не пересылает геометрию.

#### 8.7.7. Интерфейс, обмен, производительность

Вкладка «Блочные модели»: «Создание» — Прототип, Заполнить каркасами, Кодировать каркасами, Ограничитель; «Поля» — Калькулятор, Плотность, Категории, Регуляризация; «Вид» — Оболочка, Срез плоскостью, Фильтр; «Обмен» — Импорт, Экспорт. Форматы: Micromine DAT (чтение — перенос BF, запись — новая), CSV (центр, размер, поля; заголовок Micromine из 3 строк по выбору), OMF v1 (регулярные модели, поворот через `axis_u/v/w`; с субблоками — только после регуляризации), Parquet; Datamine DM — по разделу форматов. Экспорт — с ограничителем и выбором полей. В проекте: описание (прототип, поля, единицы, система координат, хеш), файлы 8.7.2, ограничители, правила категорий.
