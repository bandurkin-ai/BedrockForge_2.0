## 13. Модели и уровень усилий

### 13.1. Модели

| **Модель** | **Алиас** `/model` | **Позиционирование**                          | **Цена API, \$ за 1 млн токенов (вход / выход)**               | **Чтение кэша** |
|------------|--------------------|-----------------------------------------------|----------------------------------------------------------------|-----------------|
| Fable 5.2  | `fable`            | Сложные рассуждения и длинные агентные задачи | 8 / 40                                                         | 0,025×          |
| Opus 5.5   | `opus`             | Длинная агентная разработка — основная модель | 4 / 20                                                         | 0,05×           |
| Sonnet 5.5 | `sonnet`           | Скорость и качество для рутины                | 2 / 10                                                         | 0,05×           |
| Haiku 5.5  | `haiku`            | Поиск, извлечение, короткие задачи            | 0,10 / 0,50 (запрос до 100 тыс. токенов; больше — 0,50 / 2,50) | 0,01×           |

- У всех четырёх — контекст 1 млн токенов, вывод до 128 тыс.; размышления (thinking) не отключаются.

- Уровни усилий: `low`, `medium`, `high`, `xhigh`, `max`; по умолчанию в Claude Code — `medium`.

- Лимиты подписки Max: 5-часовое скользящее окно и недельный лимит — **общие для всех моделей**; на Max у Fable есть **отдельный недельный лимит**.

- Источник: документация Claude Code (`model-config`, `costs`, `errors`, `interactive-mode`, `sub-agents`) на 16.11.2026. Цены подписки не зависят от цен API; цены API приведены для сравнения стоимости.

### 13.3. Как переключать модели и усилия

| **Где**                              | **Команда**                                                                                                        | **Правило**                                                                                                                                                 |
|--------------------------------------|--------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Начало сессии (заказчик)             | `/model opus`, `/effort high`                                                                                      | Только здесь меняется модель основной сессии                                                                                                                |
| Начало сессии (заказчик, по желанию) | `/autocompact 400k`                                                                                                | Сжатие контекста раньше — шаг агента дешевле (проверить в `/help`)                                                                                          |
| Внутри сессии (исполнитель)          | Вызов субагента с `model` и `effort` из таблицы 13.2 (во frontmatter `.claude/agents/*.md` или параметрами вызова) | Исполнитель **не просит** сменить модель основной сессии посреди вехи: смена перезаписывает кэш всего контекста (в BF — 0,2–0,6 млн токенов, \$2–13 за ход) |
| Постоянно                            | `.claude/settings.json`: `"model": "opus"`, `"effortLevel": "high"`                                                | Задаётся на Э0                                                                                                                                              |
| Нельзя                               | `CLAUDE_CODE_SUBAGENT_MODEL`                                                                                       | Не задавать — перекрывает модели субагентов                                                                                                                 |
| Не использовать                      | `opusplan`                                                                                                         | Исполнение на Sonnet противоречит режиму качества для ядер                                                                                                  |

### 13.4. Режимы расхода

Исполнитель не видит счётчики лимитов. Режим задаёт заказчик сообщением «Режим: экономия» (или «норма», «минимум») по данным `/usage`; исполнитель записывает режим в `PROGRESS.md` и применяет до следующего указания.

| **Режим**                | **Когда (недельный расход по** `/usage`**)** | **Изменения**                                                                                                                         |
|--------------------------|----------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------|
| Норма                    | \< 60 %                                      | Таблица 13.2                                                                                                                          |
| Экономия                 | 60–85 %                                      | Интерфейсная рутина — субагент на Sonnet 5.5 / high; `reviewer` — Opus / medium; Fable — только Э9, Э18, Э19, Э21; без замеров `full` |
| Минимум                  | \> 85 %, до сброса \> 1 суток                | Довести текущий подшаг, чекпойнт, отчёт «Остановлено по лимиту», ждать сброса                                                         |
| Исчерпан лимит Fable     | Ошибка «limit» у субагента на Fable          | Повторить вызов с `model: opus`, `effort: xhigh`; отметить в `PROGRESS.md`                                                            |
| Исчерпан недельный лимит | Сообщение «weekly limit · resets …»          | Ждать сброса или включить `/usage-credits` (решает заказчик)                                                                          |
