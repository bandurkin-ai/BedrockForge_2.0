### 8.5. Истинная мощность и рудные пересечения \[Э15\]

#### 8.5.1. Формулы

    m = l·|n·d|                                        — общий векторный вид (n, d — 8.0.1)
    m = l·|cos α·cos θ − sin α·sin θ·cos(Aп − Aс)|     — развёрнутая формула
    β = 90° − θ (наклон скважины к горизонту), γ = Aс − Aп:   m = l·|sin α·cos β·cos γ − cos α·sin β|
      это формула Леонтовского m = l·(sin α·cos β·cos γ ± cos α·sin β): «+», если γ отсчитан от направления восстания
      (бурение навстречу падению), «−» — от направления падения;  навстречу (γ = 180°): m = l·sin(α + β);
      по падению (γ = 0°): m = l·|sin(α − β)|;  вертикальная скважина: m = l·cos α
    вырождение: |n·d| < ε_в (0,1) — скважина почти параллельна пласту, TT_FLAG = 1
    направление на глубине D между замерами D1, D2 (минимальная кривизна): ψ = arccos(t1·t2), f = (D − D1)/(D2 − D1),
      t(f) = [sin((1 − f)·ψ)·t1 + sin(f·ψ)·t2]/sin ψ;  при ψ < 1e−9: t(f) = t1
    искривлённый ствол: m = Σ_j l_j·|n·d_j|, части l_j ≤ 1 м, d_j — в середине части (для прямого ствола равно l·|n·d|)

#### 8.5.2. Ориентировка пласта

| **Источник**                    | **Правило**                                                                                                                                                                                                                                                                                                                                 |
|---------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Глобальная                      | α, Aп для всего расчёта                                                                                                                                                                                                                                                                                                                     |
| По домену                       | Таблица «код домена → α, Aп»                                                                                                                                                                                                                                                                                                                |
| Каркас или поверхность          | Ствол пересекает каркас внутри интервала — нормаль треугольника в точке пересечения; вход и выход из тела — n = норм(n_вх − n_вых) по внешним нормалям. Иначе — ближайшая к середине интервала точка каркаса (BVH) не дальше d_max (50 м): нормаль ближайшего треугольника или средняя по площади в радиусе r_n (0). n приводится к n_z ≥ 0 |
| Ориентированный керн (α_к, β_к) | Интервал с замером: m = l·sin α_к (несколько замеров — главный собственный вектор Σ n·nᵀ). Без замера — ближайший замер скважины не дальше d_к (10 м) по стволу, пересчитанный в мировую нормаль                                                                                                                                            |

    d — направление ствола на глубине замера; g = (0, 0, −1)
    e1 = (g − (g·d)·d)/‖g − (g·d)·d‖ — линия низа керна (BOH); для линии верха (TOH) e1 = −e1; при θ < 1° — замер не пересчитывается, флаг
    e2 = d × e1 (90° по часовой стрелке, если смотреть вниз по стволу)
    n = sin α_к·d − cos α_к·(cos β_к·e1 + sin β_к·e2)   — β_к отсчитан до дальней по стволу точки эллипса
    n_z < 0 → n = −n;  α = arccos n_z;  Aп = atan2(n_x, n_y) mod 360 (α < 1e−6 → Aп = 0)

Источник записывается у интервала (TT_SRC).

#### 8.5.3. Рудные пересечения

    вход: интервалы скважины (пробы или композиты), поле g, борт c, L_min (или m_min по истинной мощности),
          L_п — наибольшая внутренняя пустая порода; g = NaN — пустая порода с g = 0 (по умолчанию) или разрыв
    1. рудный интервал: g ≥ c; подряд идущие рудные интервалы — серии R_1 … R_k
    2. слева направо: тек = R_1; для R_(i+1): если пустая между ними ≤ L_п и среднее(тек ∪ пустая ∪ R_(i+1)) ≥ c —
       тек = объединение, иначе тек закрывается и тек = R_(i+1)
    3. пересечение принимается при длине ≥ L_min (m ≥ m_min);  4. «в том числе» — то же по борту c2 > c внутри принятого
    среднее = Σ l_i·g_i / Σ l_i, с плотностью — Σ l_i·ρ_i·g_i / Σ l_i·ρ_i

Таблица пересечений: HOLE, FROM, TO, LENGTH, TT, TT_FLAG, TT_SRC, ALPHA, DIPDIR, HOLE_THETA, HOLE_AZ, содержания, LENGTH·g (метропроцент; для г/т — метрограмм), TT·g, WASTE_LEN, N_INT, X, Y, Z середины, INCL, подпись «12,0 м @ 2,10 г/т (ИМ 9,8 м)». Показ — подписи на стволах в 3D, таблица в нижней панели, CSV/XLSX, элемент макета (8.12).

#### 8.5.4. Параметры, интерфейс, производительность

Параметры: ε_в 0,1 (0,01–0,5); часть ствола 1 м (0,1–10); d_max 50 м, d_к 10 м (0–1000); r_n 0 (0–200 м); L_min 2 м (0–100); L_п 2 м (0–50). «Анализ → Пересечения»: Истинная мощность (поле TT в таблице), Рудные пересечения (таблица-объект набора скважин); окно — источник ориентировки, параметры, предпросмотр по скважине. В проекте — таблица набора скважин и параметры. Время: TT для 5 млн интервалов — ≤ 10 с (глобальная, по домену), ≤ 60 с и ≤ 3 ГБ (каркас 10 млн треугольников); пересечения по 50 тыс. скважин — ≤ 20 с.
