### 7.19. Растры \[Э7\]

**Назначение.** Изображения с привязкой в плане и в вертикальной плоскости.

Изображение (JPG, PNG, TIFF, BMP) выбирается **вместе с файлом привязки** того же имени.

| **Привязка**  | **Файлы**                                    | **Использование**                               |
|---------------|----------------------------------------------|-------------------------------------------------|
| GeoTIFF       | Теги `.tif`                                  | Масштаб и точка или матрица                     |
| World-файл    | `.jgw .pgw .tfw .wld .jpgw .pngw .tifw .bpw` | 6 чисел; центр левого верхнего пикселя          |
| MapInfo TAB   | `.tab`                                       | Аффинное преобразование по опорным точкам (≥ 3) |
| Micromine GRF | `.grf`                                       | По опорным точкам; высота из файла              |

- Приоритет: GeoTIFF → world → TAB → GRF; по опорным точкам остальных файлов считаются отклонения (в свойствах).

- Растр в плане на заданной высоте; пусто — под самым низким объектом. Отсечение действует. Стороны больше **4096** px для показа уменьшаются.

- **«Уровень растров по Z»** (мастер): «высота, м» — вместо высоты привязки; «сдвиг, м» — ± для всех растров, включая вертикальные (все углы); запятая и точка. В свойствах — «Высота», «Сдвиг по Z» + «Сдвинуть»; без высоты сдвиг недоступен.

- **Вертикальные** (сканы разрезов): GRF с точками `col row X Y Z` на разных высотах — в их плоскость; без привязки при проведённой линии — в плоскость разреза (края по линии в пределах данных, верх и низ — по высотам данных). Свойства: «Левый край X/Y», «Правый край X/Y», «Верх Z», «Низ Z», «На текущий разрез» (и для растра в плане; `raster.place_on_section {raster_id, z_top}`, confirm). При отсечении — подложка (как в Micromine), иначе — обычный объект.

- Непрозрачность 0,05–1, высота (`raster.set`).

**Хранение.** Файлы — в хранилище; преобразование, высота, сдвиг, вертикальная привязка, непрозрачность — в проекте.

**Приёмка.** JPG + JGW встаёт точно по левому верхнему пикселю. При TFW и TAB используется TFW, отклонения по TAB — в свойствах. Сдвиг −5 опускает все углы вертикального растра на 5 м. При отсечении скважины поверх вертикального растра.
