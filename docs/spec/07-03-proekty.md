### 7.3. Проекты \[Э2\]

**Назначение.** Изолированные рабочие пространства; данные проектов не пересекаются.

| **Функция**    | **Требование**                                                                                                                                |
|----------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| Создание       | `project.new` (confirm): пустой проект с названием, сразу открывается                                                                         |
| Открытие       | Список в заголовке; в окне «Проекты» — «Открыть» или двойной щелчок; последний проект открывается при запуске                                 |
| Переименование | В окне «Проекты» и в строке любого проекта; `project.rename` (confirm); названия уникальны                                                    |
| Описание       | Месторождение, лицензия, стадия работ; сохраняется при уходе фокуса из поля                                                                   |
| Удаление       | Все данные: наборы, каркасы, линии, растры, блочные модели, графики, задания, файлы хранилища; подтверждение; `project.delete` (confirm)      |
| Сводка состава | Наборы, скважины, замеры, пробы, интервалы таблиц, каркасы, линии, растры, блочные модели, графики, диалоги Claude; даты создания и изменения |
| Поиск          | По названию и описанию                                                                                                                        |
| Автосохранение | Каждое изменение записывается сразу транзакцией; после аварийного завершения проект открывается со всеми подтверждёнными изменениями          |

**Интерфейс.** Окно «Проекты» (⚙ у выбора проекта, «Главная → Проекты», `project.manage`): «Открытый проект» — название и «Переименовать», описание, даты, состав, «Экспорт»; «Все проекты» — поиск, у строки число скважин и объектов, дата изменения, «Открыть», переименовать, удалить, значок экспорта; внизу «Новый проект», «Демо-проект», «Импорт…».

**Хранение.** Проект — папка в папке данных проектов (по умолчанию в профиле пользователя, меняется в «Настройке»): файл SQLite (метаданные, таблицы скважин, журнал правок, настройки вида) и хранилище массивов и исходных файлов (7.6). \[сервер\] PostgreSQL и хранилище сервера.

**Приёмка**

- Переименование в занятое название отклоняется сообщением, дубликат не создаётся.

- Описание сохраняется при уходе фокуса и видно после перезапуска.

- После удаления данные проекта не встречаются ни в одном списке, папки проекта на диске нет.

- Поиск находит проект по слову из описания.

- Снятие процесса ядра сразу после правки ячейки не теряет правку.
