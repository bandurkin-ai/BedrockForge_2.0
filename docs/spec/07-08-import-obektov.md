### 7.8. Импорт объектов (мастер «Импорт файлов») \[Э3\]

**Назначение.** Каркасы, линии, растры, блочные модели и OMF — с предпросмотром состава и фоновым заданием.

Рамка мастера — Э3; форматы подключаются на этапах объектов: линии и растры — Э7, каркасы — Э8, OMF — Э11, блочные модели — Э17.

- Расширения: `.omf .tridb .dxf .obj .stl .str .jpg .jpeg .png .tif .tiff .bmp .jgw .jpgw .pgw .pngw .tfw .tifw .bpw .wld .tab .grf` и табличные `.dat .csv .txt .xlsx .xlsm .xls`.

- Тип определяется по файлам; `.DAT`/`.CSV` с полями центра и размера блока идут в импорт блочной модели, а не скважин.

- Мастер показывает состав и то, что не загрузится; для растров — блок «Уровень растров по Z» (7.19).

- Файлы — системным диалогом или из Проводника; ядро читает их с диска; файл до **4 ГБ**. \[сервер\] Загрузка частями (7.6).

- Импорт — задание `import.objects` с прогрессом, журналом, отменой; результат и статус «готово» — одной транзакцией.

**Хранение.** Объекты — по своим модулям; исходные файлы — в хранилище.

**Приёмка.** Отмена до последнего шага не оставляет объекта в дереве. Файл 1 ГБ импортируется без промежуточной копии. \[сервер\] Загрузка, прерванная на середине, продолжается с последней принятой части.
