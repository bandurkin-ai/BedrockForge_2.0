### 7.31. Блочные модели — базовые функции \[Э17\]

**Назначение.** Загрузка, проверка, показ и отчёт по блочным моделям до 20 млн блоков.

**Интерфейс.** Загрузка — «+» у «Блочных моделей» или перетаскивание; `.DAT`/`.CSV` с полями центра и размера узнаются по заголовку; импорт — заданием. Развитие (создание, заполнение и кодирование каркасами, вычисления, регуляризация, экспорт и др.) — раздел 8.

| **Что**                                              | **Требование**                                                                                                                                                                                                                                                                                                                        |
|------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Форматы                                              | Micromine DAT (типы C, N, R; cp1251 и BOCU-1; заголовок 4096 или 8192 байт); Micromine CSV (3 строки заголовка: имена, типы, сетка `x0, dx, y0, dy, z0, dz, CENTRE`); обычный CSV; OMF (регулярные)                                                                                                                                   |
| Поля блока                                           | Центр: `X/Y/Z`, `XC/YC/ZC`, `EAST/NORTH/RL`, `X_CENTRE`, `XCENTRE`, `Centroid X`…; размер: `_EAST`, `XINC`, `DIM_X`, `XLENGTH`, `Size X`, `DX`…; подбор по названиям, правка в мастере; без размеров — регулярная модель, размер из строки сетки или шага центров                                                                     |
| Субблоки                                             | Как есть (центр, размер) + родительская сетка: начало, размер родителя, число ячеек, занятые ячейки                                                                                                                                                                                                                                   |
| Проверки                                             | Блоки за началом сетки; субблоки через границу родителя; дубликаты; перекрытия (точно — на сетке наименьшего блока, иначе по объёму в родительской ячейке); пустые и постоянные поля; объём                                                                                                                                           |
| Свойства                                             | Сетка, проверки, поля с единицами (г/т, %, ppm, ppb — правятся), выбранный блок                                                                                                                                                                                                                                                       |
| Настройки показа                                     | Окно «Блочная модель · \<модель\>» (шестерёнка, меню); сразу, запоминается для модели                                                                                                                                                                                                                                                 |
| Ограничитель                                         | «поле — оператор — значение» (равно, не равно, больше, меньше, пусто…; категории — выбор значения); «И / Или»; обратный фильтр                                                                                                                                                                                                        |
| Раскраска                                            | Шкала (градиент, от / до, логарифмическая) или градации (классы на гистограмме); категории — цвета и флажки; «Взять раскраску» из отображений или библиотеки; «Сохранить…» в библиотеку (видят и скважины)                                                                                                                            |
| Просмотр                                             | Внешняя оболочка (по прошедшим ограничитель) или все блоки; «Срез на разрезе» — при отсечении сечение плоскостью подложкой под скважины; края — цвет и толщина; непрозрачность                                                                                                                                                        |
| Отчёт по бортам (`blocks.report {model_id, grades}`) | Окно «Содержание–тоннаж · \<модель\>»: тоннаж = объём × плотность (поле или константа); содержания взвешены по тоннажу; металл: г/т → тыс. унц, % → т; отбор по категориям, группы, кривая содержание–тоннаж, CSV. По умолчанию плотность — меняющееся поле `SG` (постоянное `DENSITY` = 2,6 пропускается), содержания — поля `*_CUT` |

**Скорость BF (ориентир):** 363 517 блоков, 23 поля, 127 МБ BOCU-1 — чтение 1,9 с, сетка и проверки 0,8 с; 8,3 млн блоков (DAT ~1 ГБ) — ~32 с, пик ~1,8 ГБ; OMF 47 млн ячеек — ~47 с, пик 4,5 ГБ.

**Хранение.** Блоки и поля — колоночные файлы (Parquet/NumPy), ограничитель и отчёт — расчёт NumPy/numba (детерминированно, побитно; решение № 145); сетка, единицы, проверки — в проекте; настройки показа — в настройках вида.

**Приёмка.** Перекрывающиеся субблоки дают находку «перекрытия». «AU \> 1 И DOMAIN = 2» оставляет только такие блоки, обратный фильтр — остальные. Борт 0 даёт полный тоннаж. `SG` выбирается плотностью сам. Модель 20 млн блоков импортируется, показывается с ограничителем и даёт отчёт.
