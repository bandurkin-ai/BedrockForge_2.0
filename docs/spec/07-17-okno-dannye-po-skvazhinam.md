### 7.17. Окно «Данные по скважинам» \[Э6\]

**Назначение.** Каротажная диаграмма нескольких скважин рядом.

**Интерфейс.** «Вид → Просмотр → Данные по скважинам» (`holes.data_window`, uiOnly), для Claude — `chart.striplog`. Только просмотр и экспорт.

| **Настройка** | **Варианты**                                                                                                                                                                                                               |
|---------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Таблица       | Сначала таблица набора (опробование, литология, события) — её поля становятся колонками; поля других — «+ колонка»                                                                                                         |
| Скважины      | До **30** рядом, поиск; общая шкала глубин или от своего устья                                                                                                                                                             |
| Глубина       | «От–до»; масштаб — вписать, 1:2000 … 1:50                                                                                                                                                                                  |
| Колонки       | Поле любой таблицы; порядок, ширина                                                                                                                                                                                        |
| Вид колонки   | Ступенчатая линия, столбцы, цветная колонка (категории — общая палитра на все скважины, числа — шкала), текст, цвет + текст; числа — цветом, шкалой или градациями (своими или из библиотеки); события — значки с подписью |
| Шкала         | От / до (по данным), логарифмическая; цвет линии и столбцов; границы интервалов                                                                                                                                            |
| Экспорт       | PNG, SVG, CSV                                                                                                                                                                                                              |

Подсказка: скважина, глубины, значение; под колонками — легенда категорий.

**Хранение.** Ничего не сохраняется.

**Приёмка.** 31-ю скважину выбрать нельзя. CSV содержит значения всех колонок по глубинам.
