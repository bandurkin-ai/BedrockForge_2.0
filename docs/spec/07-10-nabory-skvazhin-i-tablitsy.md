### 7.10. Наборы скважин и таблицы \[Э4\]

**Назначение.** Просмотр и ручная корректировка таблиц набора (нижняя панель «Таблица»). Наборы независимы: свои устья, инклинометрия, пробы, компоненты, аудит; номера скважин в разных наборах могут совпадать. Новый набор — «+» у «Скважин» (импорт) или `set.create` (пустой).

| **Таблица**                | **Обязательные поля**                         | **Требования**                                                                                                                                                           |
|----------------------------|-----------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Устья                      | Скважина, X, Y, Z, TD; азимут, наклон, статус | Свободные колонки — атрибуты строки (JSON)                                                                                                                               |
| Инклинометрия              | Скважина, глубина, азимут, наклон             | Азимут по часовой от севера, наклон вниз отрицательный                                                                                                                   |
| Пробы                      | Скважина, от, до; № пробы; компоненты         | Значения по имени компонента (`{"AU": 0.007}`); справочник компонентов с единицами                                                                                       |
| Другие таблицы опробования | Как у проб                                    | Например композиты. Название задаётся при импорте: «Пробы» — основная, иное — отдельная; при наличии проб новый файл по умолчанию — отдельная таблица                    |
| Интервальные               | Скважина, от, до                              | Литология, изменения, выветривание, RQD, доп. анализы — без ограничения числа. Числа — числами, остальное текстом. Одноимённая таблица заменяется, остальные не меняются |
| События                    | Скважина, глубина                             | Глубина без мощности, остальное — атрибуты                                                                                                                               |

| **Функция**       | **Требование**                                                                                                                                                                                             |
|-------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Открытие          | Щелчок в дереве или вкладка над таблицей; `table.open {kind}`: `collar`, `survey`, `assay` или id интервальной таблицы                                                                                     |
| Просмотр          | Постранично (`offset`, `limit`), окно не загружает таблицу целиком                                                                                                                                         |
| Сортировка        | По заголовку: возрастание → убывание → снять; пустые в конце                                                                                                                                               |
| Выбор скважины    | Щелчок по строке выбирает скважину в 3D и оставляет только её строки; ✕ снимает фильтр                                                                                                                     |
| Σ Статистика      | По полю: заполнено, пусто, мин, макс, среднее, медиана, ст. отклонение; у текстовых — число уникальных и частые значения; с учётом выбранной скважины                                                      |
| Правка            | Щелчок по ячейке; `Enter` — сохранить, `Tab` — дальше, `Esc` — отмена; пусто — очистить поле; «+ Строка», 🗑 строки. Числа с запятой и точкой. Проверки: обязательные поля, «до» ≥ «от», уникальность устья |
| Журнал правок     | Кто, что, было → стало; «Отменить» у каждой правки; удалённая строка возвращается новой строкой                                                                                                            |
| После правки      | 3D и графики перечитывают данные, аудит — «устарел»                                                                                                                                                        |
| Карточка скважины | В «Свойствах»: устье и находки аудита                                                                                                                                                                      |

**Хранение.** Таблицы, атрибуты, справочник компонентов, журнал правок (справочно `data_edit`), история импорта — в SQLite проекта.

**Приёмка**

- Строка с «до» \< «от» и второе устье с тем же номером отклоняются с сообщением.

- Отмена правки возвращает прежнее значение; отмена удаления — строку новой строкой.

- После правки Z устья ствол перерисовывается, итог аудита получает «(устарел)».

- «12,5» и «12.5» сохраняются как 12.5.

- Таблица на 5 млн проб листается, сортируется и фильтруется по скважине.
