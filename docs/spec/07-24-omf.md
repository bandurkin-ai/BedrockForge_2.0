### 7.24. OMF \[Э11\]

**Назначение.** Обмен с Leapfrog и другими программами через OMF v1.

**Интерфейс.** «Главная → OMF»: импорт, экспорт, журналы. OMF v1 (читает и пишет Leapfrog, OMF 0.9).

| **Действие**   | **Требование**                                                                                                                                                                             |
|----------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Импорт         | Через мастер (можно перетащить); показ элементов и того, что не загрузится. Все поверхности — один набор каркасов, все линии — один набор (слой на элемент), каждый объём — блочная модель |
| Большие модели | Регулярная сетка без тяжёлых проверок субблоков; пустые ячейки не загружаются; ≈ **100 байт на блок** (47 млн — 4,5 ГБ, около минуты); нехватка памяти — понятная ошибка; **2** попытки    |
| Не переносится | Точки, текстуры, данные на вершинах и гранях, повёрнутые модели — перечисляются в журнале задания                                                                                          |
| Экспорт        | Выбор каркасов, линий, регулярных моделей (субблочные недоступны — в OMF v1 только регулярная сетка); задание `export.omf`; \[сервер\] «Скачать», хранение 48 ч                            |
| Claude         | `omf.export {dataset_ids, filename}`: с `dataset_ids` — сразу экспорт, без — окно                                                                                                          |

**Хранение.** Импорт создаёт объекты своих модулей; экспорт проект не меняет.

**Приёмка.** Выгруженный OMF загружается обратно с теми же каркасами, линиями, регулярными моделями. Субблочная модель к экспорту не предлагается. Журнал перечисляет неперенесённое. Модель 20 млн ячеек импортируется (пик ≈ 2 ГБ).
