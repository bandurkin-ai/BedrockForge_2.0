### 7.30. Swath plot \[Э13\]

**Назначение.** Проверка оценки на смещение и сглаживание: средние содержания моделей и проб по полосам вдоль направления.

**Интерфейс.** «Анализ → Статистика → SWATH PLOT», «+» у «Аудита», `stats.swath {swath_id, azimuth, …}`. Вкладка «Swath plot», 3D на виду; объект раздела «Аудит»; настройки сохраняются сами, расчёт — по текущим данным.

| **Параметр**      | **Требование**                                                                                                                                                                                                                                                                           |
|-------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Направление       | X, Y, Z или азимут (от севера по часовой); блок и проба (середина интервала) относятся к полосе по центру                                                                                                                                                                                |
| Ширина            | По умолчанию — целые родительские блоки первой модели, не больше **50** полос; без модели — круглое число около 1/25 габарита; «Привязка» — координата границы; максимум **2000** полос                                                                                                  |
| Ряды              | До **12** в любом сочетании: поле модели или поле проб; несколько моделей и наборов, разные поля одной модели                                                                                                                                                                            |
| Средние по блокам | Вес — объём, тоннаж (объём × плотность) или нет; отбор по категориальному полю (домен)                                                                                                                                                                                                   |
| Средние по пробам | Без весов, по длине, полю, длине × поле; отрицательные — как есть, исключить, ½ модуля; урезка сверху                                                                                                                                                                                    |
| Какие пробы       | Все в кубоиде полос или только внутри блоков выбранного ряда модели (с его отбором)                                                                                                                                                                                                      |
| Кубоид            | По габаритам блоков рядов-моделей; без моделей — по пробам                                                                                                                                                                                                                               |
| График            | Линии средних; столбики (объём или вес блоков, число проб); в легенде — средние по всем полосам; подсказка; таблица с отклонением от первого ряда, %; экспорт PNG, SVG, CSV                                                                                                              |
| Диапазон          | Ползунки и «с … по …»: строится часть полос, в 3D остальные приглушены                                                                                                                                                                                                                   |
| 3D                | Галочка или «Полосы в 3D»: кубоид на полосах, над ним — график (точки над полосами), повёрнутый к наблюдателю вокруг оси кубоида (в плане — рядом, на разрезе — над моделью, для Z — сбоку); полоса под курсором подсвечивается в 3D; «Вписать» и стандартные виды держат график в кадре |

**Хранение.** Объект `swath` с настройками; включённые — в настройках вида.

**Приёмка**

- 13-й ряд не добавляется; ширина на 2000+ полос отклоняется.

- Ряд проб «внутри блоков» не учитывает пробы вне блоков.

- Наведение на полосу графика подсвечивает её в 3D.

- Ширина по умолчанию: без моделей — круглое число около 1/25 габарита проб; с моделью — кратна родительскому блоку, полос ≤ 50.

- После правки данных сохранённый swath пересчитывается. Swath по модели 20 млн блоков строится.
