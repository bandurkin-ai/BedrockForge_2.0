## 4. Общие сведения

### 4.1. Наименование и назначение

| **Пункт**           | **Значение**                                                                                                                                                                                                                           |
|---------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Полное наименование | Горно-геологическая информационная система «BedrockForge 2»                                                                                                                                                                            |
| Краткое             | BF2                                                                                                                                                                                                                                    |
| Брендинг            | «BedrockForge by Mikhail Bandurkin»                                                                                                                                                                                                    |
| Назначение          | Работа геолога с данными разведки и моделирования месторождения: импорт и проверка данных бурения, 3D-визуализация, разрезы, каркасы, статистика, геостатистика, блочные модели, подсчёт ресурсов, оптимизация карьера, выпуск графики |
| Пользователи        | Геологи, геологи-моделисты, маркшейдеры, горные инженеры; один пользователь на ПК; группа — через сервер ЛВС                                                                                                                           |
| Эталон поведения    | Micromine (данные, разрезы, каркасы, блочные модели, оптимизатор карьера), Leapfrog (неявное моделирование, мастер импорта, графики) — функциональные аналоги, интерфейс не копируется                                                 |

### 4.2. Цели

1.  Полная замена BF: все функции BF работают в BF2 без Docker, WSL и браузера.

2.  Базовый производственный цикл ГГИС без внешних программ: данные → проверка → разрезы → каркасы → композиты → вариограммы → блочная модель → оценка → ресурсы → карьер → печать.

3.  Точность, воспроизводимая и сверенная с эталонами (раздел 5.4).

4.  Производительность на офисном ПК (16 ГБ, встроенная графика) при объёмах крупного месторождения (раздел 5.3).

5.  Поставка одним файлом и установщиком, работа офлайн, лицензирование.

### 4.3. Термины и сокращения

| **Термин**             | **Значение**                                                                                  |
|------------------------|-----------------------------------------------------------------------------------------------|
| ГГИС                   | Горно-геологическая информационная система                                                    |
| Набор скважин          | Совокупность таблиц одной группы скважин: устья, инклинометрия, интервальные таблицы, события |
| Устья (collar)         | Таблица: имя скважины, X, Y, Z, глубина                                                       |
| Инклинометрия (survey) | Таблица: скважина, глубина, азимут, угол (DIP \< 0 — вниз)                                    |
| Интервальная таблица   | Таблица «от–до» по скважине: пробы, литология, геотехника и т. п.                             |
| Событие                | Точечная запись на глубине по скважине                                                        |
| Десуртинг              | Расчёт координат вдоль ствола по инклинометрии (минимальная кривизна)                         |
| Стринг                 | Линия (полилиния) с атрибутами; формат STR Micromine/Surpac                                   |
| Каркас                 | Триангуляционная поверхность или тело (TRIDB, DXF, OBJ, STL)                                  |
| ЦТМ / ЦМР              | Цифровая модель рельефа/поверхности (триангуляция)                                            |
| Блочная модель (БМ)    | Регулярная сетка блоков с субблоками и атрибутами                                             |
| Композит               | Проба, пересчитанная на интервал заданной длины или домена                                    |
| QAQC                   | Контроль качества анализов: стандарты, бланки, дубликаты                                      |
| RBF                    | Радиальные базисные функции — метод неявного моделирования                                    |
| LG                     | Алгоритм Лерча–Гроссмана для оптимального контура карьера                                     |
| Ядро                   | Локальный вычислительный процесс Python BF2 (`bf-core`)                                       |
| Оболочка               | Electron-приложение: главный процесс + окно интерфейса                                        |
| Задание                | Длительная операция в фоне с прогрессом, отменой и журналом                                   |
| Веха                   | Точка приёмки заказчиком (В1–В6)                                                              |
| Этап                   | Единица работ ИИ (Э0–Э26); один этап — один PR                                                |
| Чекпойнт               | Коммит + пуш + обновление `PROGRESS.md`                                                       |
