### 8.10. Подсчёт ресурсов \[Э20\]

Развитие отчёта по бортам BF (`blocks/report.py`): группы, ограничители, уступы, формы, экспорт. Закрывает CHECKLIST № 305, 337, 338.

    t_b = V_b·ρ_b·f_b,  f_b — доля в ограничителях (8.7.5), в карьере (PIT ≤ n или каркас), ниже рельефа
    уступ j: доля блока = перекрытие [z_b − dz/2; z_b + dz/2] с [Z_j; Z_j + H], делённое на dz
    группа G — сочетание до 3 полей (домен, категория, уступ, любое); борт c по полю g_б (может отличаться от отчётных, например AuEq):
      S = {b ∈ G: g_б,b ≥ c};  T = Σ_S t_b;  ḡ_e = Σ_S t_b·g_e,b / Σ_(S, g_e не NaN) t_b;  M_e = Σ_S t_b·g_e,b·k_e (BF `metal`)
    итог — сумма групп; блок без значения группы — группа «(пусто)»; балансовые g_б ≥ c_б, забалансовые c_з ≤ g_б < c_б
    кривые «тоннаж — содержание»: одна сортировка по g_б, накопленные суммы, 100 бортов от min до max
