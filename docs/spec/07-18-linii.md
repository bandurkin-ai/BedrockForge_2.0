### 7.18. Линии \[Э7\]

**Назначение.** Загрузка, показ и экспорт линий и точек.

| **Формат**         | **Что читается**                                                                                            |
|--------------------|-------------------------------------------------------------------------------------------------------------|
| Micromine STR      | `EAST`, `NORTH`, `RL`; новая линия при смене `JOIN` или `STRING`; слой = код `STRING`; свои поля — атрибуты |
| Surpac STR (текст) | `номер, Y, X, Z, описания`; сегменты разделены нулевой записью; слой = номер стринга                        |
| DXF                | LINE, LWPOLYLINE, POLYLINE, SPLINE, ARC, CIRCLE, ELLIPSE, POINT; слой = слой DXF; кривые → ломаные          |
| OMF                | Элемент линий = слой (7.24)                                                                                 |

- `.str` распознаётся по содержимому. Замкнута, если первая и последняя точки совпадают; линия из одной вершины — точка (значок). При отсечении видны части в окне.

- Свойства: цвет, видимость, длина, замкнутость, атрибуты.

- Экспорт: Micromine STR (двойная точность, побитно) и DXF.

**Хранение.** Геометрия float64 — в хранилище; слои, цвет, атрибуты — в проекте.

**Приёмка.** STR → экспорт STR → импорт дают побитно те же координаты.
