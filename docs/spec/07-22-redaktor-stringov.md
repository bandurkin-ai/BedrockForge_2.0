### 7.22. Редактор стрингов \[Э9\]

**Назначение.** Оцифровка и правка линий и полигонов с версиями слоя.

**Интерфейс.** Меню слоя «Редактировать», лента «Моделирование», `lines.edit`. Новый слой — «+» у «Линий» → «Новый слой» (`lines.new_layer`; название станет кодом стринга в STR).

| **Что**                            | **Требование**                                                                                                                                                                                                                                                                                                  |
|------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Куда ложатся точки                 | В плане — на `Z` из панели; при отсечении — в плоскость разреза (середина окна); при привязке — в точку объекта                                                                                                                                                                                                 |
| Инструменты (`lines.tool`)         | `select` (тянуть вершину или линию; `Ctrl` + тянуть — рамка; `Shift` — добавить), `line`, `polygon`, `point`, `tie` (тай-линия), `insert` (вершина)                                                                                                                                                             |
| Команды                            | Замкнуть, разомкнуть, разорвать в вершине, соединить две, развернуть; сдвиг и копия на вектор (и по Z); копия со смещением; проредить (Дуглас–Пекер); сгустить; сгладить; удалить; перенос в другой слой (`lines.move_selected`, оба слоя — новая версия)                                                       |
| Ввод координат                     | `X Y Z`; от предыдущей — `@азимут расстояние [наклон]` или `@@dX dY [dZ]`; `lines.add_line {points, closed}` — для Claude                                                                                                                                                                                       |
| Привязка                           | Вершина, середина, ближайшая точка сегмента; вершина и ребро каркаса; сечение каркаса на разрезе; устье, траектория, границы интервалов; узел сетки. Цели включаются по отдельности, радиус в px; на разрезе точки скважин и каркасов проецируются в плоскость (переключатель); точные цели по скважинам — ядро |
| Клавиши                            | Правая кнопка (щелчок без перетаскивания), `Enter`, двойной щелчок — закончить линию; `Backspace` — убрать точку; `Esc` — снять выбор; `Delete`; `Ctrl+Z` / `Ctrl+Y` (`lines.undo` / `lines.redo`); `Ctrl+S`                                                                                                    |
| Панель                             | Иконки в духе AutoCAD: название, действие, клавиши, причина недоступности                                                                                                                                                                                                                                       |
| Измерения (`lines.measure`)        | Вершины, длина 3D и в плане, площадь полигона в его плоскости и в плане, периметр; у слоя — сумма; с учётом несохранённых правок                                                                                                                                                                                |
| Сохранение (`lines.save`, confirm) | Новая версия слоя; если слой сохранён после начала правки (другим сеансом, \[сервер\] пользователем) — отказ, ничего не затирается                                                                                                                                                                              |
| Версии                             | Журнал сохранений (когда, линии и вершины было → стало); возврат к версии — новая запись, ничего не стирается                                                                                                                                                                                                   |
| Завершить                          | Выход из правки; при несохранённом — вопрос о сохранении                                                                                                                                                                                                                                                        |

**Модель данных:** правка — над рабочей копией в координатах проекта (float64), из сцены — только курсор; «сохранить → прочитать» возвращает координаты побитно; замкнутая линия хранится с повтором первой вершины в конце; код редактора не зависит от three.js и React и покрыт тестами.

**Хранение.** Сохранение — новая версия слоя и запись журнала версий; до сохранения рабочая копия есть только в окне.

**Приёмка.** `@90 100` от (0, 0, 0) даёт (100, 0, 0). Сохранение с устаревшей базовой версией отклоняется. Возврат к версии 1 создаёт версию N+1 с геометрией версии 1. Площадь квадрата 10×10 в плане — 100. Привязка к устью на разрезе даёт точку в плоскости разреза.
