### 7.28. Сохранённые графики \[Э13\]

**Назначение.** Графики набора в дереве вместе с настройками.

- Гистограмма, Q-Q, дендрограмма сразу сохраняются в набор → «Графики»; настройки — сами; имя следует за настройками, пока не переименовано вручную. Отображения по стволу — тот же механизм (`striplog`), но под «Стволами» и только по «Сохранить».

- Щелчок открывает график с сохранёнными настройками по текущим данным; меню — открыть, переименовать, удалить. Claude — `chart.open {chart_id}`.

**Хранение.** Графики с настройками и именем — в проекте; пересчитываются по текущим данным.

**Приёмка.** После правки пробы повторно открытая гистограмма пересчитана. Ручное имя не меняется при смене настроек.
