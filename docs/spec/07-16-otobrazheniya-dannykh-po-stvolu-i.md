### 7.16. Отображения данных по стволу и стили \[Э6\]

**Назначение.** Данные любых таблиц набора вдоль стволов и библиотека стилей.

**Интерфейс.** Меню «Стволов» → **Содержания… / Литология… / События…** (одна форма, пункт задаёт первое поле). Изменения сразу видны на скважинах; в дерево (строкой под «Стволами») отображение попадает только по «Сохранить». Строки — галочкой или щелчком, перетаскиваются в окно вида; двойной щелчок — настройки (тоже до «Сохранить»). Включённые отображения встают рядом: колонки подряд от ствола, трубки — одна в другой. Для Claude — `holes.show_data`.

| **Зона формы** | **Содержимое**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Шаблон         | Весь набор слоёв как стиль: из библиотеки, связь 🔗, ⋯ — сохранить, сохранить как, применить к другим таблицам, экспорт, импорт, удалить                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Слои           | Поля любых таблиц набора; «+ Добавить» (поиск, несколько); порядок от ствола перетаскиванием; глаз; ⋯ — дублировать, стиль, применить к другим полям, удалить; «Разложить» — трубка на стволе, остальные по сторонам; Shift/Ctrl — правка нескольких слоёв сразу                                                                                                                                                                                                                                                                                                                |
| Стиль слоя     | Выбрать, связать, сохранить, сделать умолчанием для поля (`AU`, `AU*`) — применяется сам при добавлении такого поля из любой таблицы                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Данные         | Таблица и поле; скважины все или выбранные; глубины от – до                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Вид            | Столбцы, ступени, линия, точки, трубка, лента, текст (у событий — значок); сторона слева / справа / обе; ширина и отступ в метрах или авто; прозрачность, зазор, заливка, точки на линии, разделение по порогу; трубка постоянной толщины или по значению                                                                                                                                                                                                                                                                                                                       |
| Шкала          | От – до (пусто — по данным), «мин – макс», «P2 – P98», «0 – P99»; логарифмическая; выше максимума — обрезать, с пометкой, как есть                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Цвет           | Один цвет. **Градации** на гистограмме: границы мышью и стрелками, двойной щелчок — новая; авто — квантили, равные, логарифмические, прогрессивная, двойная прогрессивная, круглые; градиенты; «вставить границы» списком; у класса — глаз, число и доля проб, подпись; цвет «нет данных». Непрерывная шкала: градиенты, растяжка линейная / логарифмическая / по квантилям, границы. Цвет по другому полю. Текстовые поля: значения с поиском, глазом, порядком, цветом для нескольких, импорт и экспорт «код;цвет» (CSV, буфер). Раскраска сохраняется и связывается отдельно |
| Фильтр         | Все / от борта / диапазон; пустые — пропуск или цветом; ноль и отрицательные — как есть, пустые, заменить; коды вроде −999 — пустые                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Подписи        | Шаблон (`{AU} г/т`, `{from}`, `{to}`, `{len}`), знаки, только ≥ X, размер, цвет класса или свой, у столбца или у ствола, не больше N (самые высокие)                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Низ            | «Сохранить», «Отменить изменения» (к сохранённому), `Ctrl+Z` / `Ctrl+Y`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

**Библиотека стилей проекта** (раскраска, стиль слоя, шаблон): выбранный стиль копируется; со связью 🔗 правка стиля («Изменить стиль» в предупреждении над разделами) перестраивает все связанные отображения; «Где используется»; удаление используемого стиля оставляет слоям копию настроек. Встроенные (только чтение): столбцы, градации, ступени, линия, трубка по шкале, лента по градациям, литология, события. Обмен — файл `.bfstyle.json`; при совпадении названий — заменить, оставить оба, пропустить. Раскраски доступны и блочным моделям.

**Легенда** в окне вида: слои и число интервалов в классах; щелчок по слою — его настройки. **Источники:** «Пробы», другие таблицы опробования, интервальные, события.

**Хранение.** Сохранённые отображения — графики вида `striplog` набора; библиотека стилей — в проекте; включённые — в настройках вида.

**Приёмка**

- До «Сохранить» отображения нет в дереве; «Отменить изменения» возвращает сохранённое.

- Правка связанного стиля перестраивает связанные отображения; удаление стиля их вид не меняет.

- Умолчание для `AU*` применяется к `AU_CUT` из другой таблицы.

- `.bfstyle.json` → импорт в другой проект даёт те же стили.
