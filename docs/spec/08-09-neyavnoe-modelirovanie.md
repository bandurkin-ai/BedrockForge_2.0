### 8.9. Неявное моделирование \[Э19\]

#### 8.9.1. Функции

Поверхности и тела интерполяцией радиальными базисными функциями (RBF), как в Leapfrog: домены литологии, оболочки содержаний, жилы, структурные тренды, расширение каркаса, обновление при изменении данных. Закрывает CHECKLIST № 263–267.

#### 8.9.2. Данные и интерполяция

    домен D (группа кодов) вдоль ствола: «в D» / «не в D»; интервал без кода — разрыв; контакт — смена, точка f = 0
    s(t) = −расстояние по стволу до ближайшего контакта в D, +расстояние вне D; точки через Δ_т (не реже одной на интервал) при |s| ≤ D_max
    ствол целиком в D (вне D) — точки −D_max (+D_max) через 2·Δ_т; ручные точки и линии: контакт 0, внутри −D_max/2, снаружи +D_max/2
    хронология: тело D = {f_D < 0} минус тела доменов с меньшим номером (manifold3d); остаток охвата — «прочее»
    f(x) = Σ_i λ_i·φ(‖A·(x − x_i)‖) + c0 + c·x,  A = diag(1, a1/a2, a1/a3)·R (8.6.3), без анизотропии A = I
    ядра: линейное φ(r) = −r; кубическое φ(r) = r³; с конечным радиусом a (аналог сфероидального) φ(r) = (1 − r/a)⁴₊·(4·r/a + 1)
    система участка [Φ + η·I, P; Pᵀ, 0]·[λ; c] = [f; 0], P — (1, x, y, z) в нормированных координатах участка
    сглаживание η = s·h̄ (линейное), s·h̄³ (кубическое), s (конечный радиус); h̄ — медиана расстояния до ближайшей точки
    разбиение единицы: охват (+10 %, после A) — октодерево до листьев с ≤ N_уч точек; участок — шар в центре листа,
      R = (1 + δ)·половина диагонали листа, при < N_min точек R × 1,25 до выполнения; локальная плотная система —
      scipy.linalg.lu_factor/lu_solve, BLAS в 1 поток, участки параллельно;
      f(x) = Σ_j W(‖x − c_j‖/R_j)·f_j(x) / Σ_j W(‖x − c_j‖/R_j),  W(r) = (1 − r)⁴₊·(4r + 1)
    структурный тренд: ориентация участка — главный собственный вектор Σ w·n·nᵀ замеров (точка, α, Aп) в радиусе R_тр
      (w = 1/расстояние) или нормаль опорного каркаса в ближайшей точке; малая ось — по нормали, отношения радиусов — общие

#### 8.9.3. Изоповерхность

    1. грубая сетка шага H = 2^L·h (h — итоговый шаг): f в узлах
    2. полоса — ячейки со сменой знака и их соседи (26-связность); для доменов — также ячейки с min abs(f) < 1,5·H
    3. ячейка полосы → кирпич 2^L×2^L×2^L ячеек шага h с общим слоем узлов на стыке; узлы с f = 0 получают +1e−9·h
    4. skimage.measure.marching_cubes (lewiner, уровень 0) по кирпичам; вершины общих рёбер сшиваются (1e−6·h)
    5. поверхность выходит на грань кирпича без соседа — соседняя ячейка добавляется в полосу, повтор до отсутствия выходов
    6. за границей модели поле продлевается значением +H — поверхность замкнута
    7. треугольники площадью < 1e−12·h² удаляются; проверки: замкнутость, многообразие, самопересечения, внешние нормали
    8. по выбору: удаление частей объёмом < V_min; упрощение pyfqmr с отклонением ≤ 0,1·h; обрезка охватом или каркасом (manifold3d)

| **Функция**         | **Правило**                                                                                                                                                                                                                                                                                                                                                                      |
|---------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Оболочки содержаний | Числовая: интерполяция g (линейно, логарифм или нормальные оценки), изоповерхность f = t. Индикаторная: значения \[g ≥ t\] − 0,5, изоповерхность p − 0,5 (p = 0,5; 0,3–0,7); оболочка порога k обрезается оболочкой k − 1                                                                                                                                                        |
| Жилы                | Висячий и лежачий бока — кровля и подошва интервалов жилы; опорная плоскость — главные компоненты контактов (оси u, v, нормаль w); поверхности w_ВБ(u, v), w_ЛБ(u, v) — 2D RBF φ(r) = r²·ln r с линейным полиномом; мощность ≤ t_min — выклинивание; граница — полигон в (u, v) или выпуклая оболочка контактов с отступом; тело — сетка (u, v) шага h: верх, низ, боковые грани |
| Расширение каркаса  | Знаковое расстояние до замкнутого каркаса (модуль — BVH, знак — чётность луча), поверхность d − Δ = 0 по 8.9.3; Δ \< 0 — сжатие                                                                                                                                                                                                                                                  |
| Обновление          | Модель хранит ссылки на входы и хеши; при изменении — «устарела»; «Обновить» пересчитывает участки с изменённым набором точек и покрытые ими кирпичи                                                                                                                                                                                                                             |

#### 8.9.4. Параметры, интерфейс, производительность

| **Параметр**       | **По умолчанию**                | **Диапазон**                          |
|--------------------|---------------------------------|---------------------------------------|
| Ядро               | линейное                        | линейное, кубическое, конечный радиус |
| Шаг h / уровни L   | диагональ охвата / 200 / 2      | 0,1–100 м / 0–4                       |
| N_уч / N_min / δ   | 1000 / 100 / 0,25               | 300–4000 / 20–500 / 0,1–1             |

«Моделирование → Неявные модели»: Новая модель (граница, шаг), Домены литологии, Оболочки содержаний, Жила, Структурные данные, Расширение каркаса, Обновить, В каркас. Дерево: модель → «Данные» (контакты, точки, замеры), «Поверхности», «Тела»; значок состояния (актуальна, устарела, считается, ошибка). Свойства: ядро, η, анизотропия с эллипсоидом в 3D, шаг, число точек и участков, наибольшая невязка в данных, время. Ручные точки и линии — редактором стрингов. В проекте: параметры, точки (Parquet), участки с хешами, решения участков (λ, c), каркасы.

Время (4 ядра): решение для 100 тыс. точек — ≤ 60 с, ≤ 3 ГБ; изоповерхность около 2 млн треугольников — ≤ 90 с; 5 доменов по 50 тыс. точек — ≤ 5 мин; 3 оболочки по 200 тыс. композитов — ≤ 5 мин; обновление после правки одной скважины (≤ 1 % точек) — ≤ 25 % полного построения.
