### 8.4. QAQC \[Э14\]

#### 8.4.1. Данные

Контроль качества анализов: стандарты (CRM), бланки, дубликаты, внешний контроль, отчёт. Закрывает CHECKLIST № 238–242.

Контрольные пробы (в таблице проб или отдельно): SAMPLE_ID, HOLE, TYPE, PARENT_ID (исходная проба дубликата и внешнего контроля), CRM_ID, LAB, BATCH, DATE, SEQ (номер в партии), элементы. TYPE: ORIG, CRM, BLANK, DUP_F (полевой), DUP_C (дроблёный), DUP_P (пульповый), UMP (внешний контроль); соответствие кодам файла задаётся в настройке («STD» → CRM). Справочник CRM: CRM_ID, элемент, ожидаемое μ, σ, единица, источник. Предел обнаружения DL — по элементу и лаборатории или полем.

#### 8.4.2. Алгоритмы

    стандарты: z = (x − μ)/σ;  смещение CRM = 100·(x̄ − μ)/μ, %
      abs(z) ≤ 2 — норма; 2 < abs(z) ≤ 3 — предупреждение; abs(z) > 3 — отказ
      две подряд (порядок DATE, SEQ для CRM × элемент × лаборатория) с 2 < abs(z) ≤ 3 по одну сторону μ — отказ второй
      9 подряд по одну сторону μ — предупреждение «систематическое смещение»
      abs(z) > 3 и abs(x − μ_j) ≤ 2σ_j для другого CRM j — пометка «возможна подмена: j»
      смещение: abs ≤ 5 % — норма, 5–10 % — внимание, > 10 % — недопустимо
    бланки: отказ при x > k_б·DL; перенос загрязнения — рассеяние «бланк — предыдущая проба партии»
    партия: отказ, если в ней отказ CRM или бланка
    дубликаты (x1 — исходная, x2 — дубликат): HARD = 100·abs(x1 − x2)/(x1 + x2);  HRD = 100·(x1 − x2)/(x1 + x2);  AMPD = 2·HARD
      в расчёт — пары со средним m = (x1 + x2)/2 ≥ k_д·DL, без NaN
      ранжированный HARD — HARD по возрастанию против 100·i/n; доли пар с HARD ≤ 10 % и ≤ 20 %
      критерий: ≥ 90 % пар с HARD ≤ 10 % (пульповые), ≤ 20 % (дроблёные), ≤ 30 % (полевые)
      рассеяние x1 — x2: линии 1:1, ±10 %, ±20 %, RMA-регрессия, r
    Томпсон–Ховарт (≥ 50 пар): пары по возрастанию m, группы по 11 (неполная последняя — к предыдущей);
      в группе — среднее m̄_g и медиана abs(x1 − x2);  МНК: med_g = a + b·m̄_g
      σ(c) = 1,048358·(a + b·c), 1,048358 = 1/(√2·Φ⁻¹(0,75));  точность P(c) = 200·σ(c)/c, %
    внешний контроль: метрики дубликатов; смещение = 100·(x̄_осн − x̄_контр)/x̄_контр; парный t-критерий (scipy.stats.ttest_rel);
      RMA: наклон и свободный член с 95 % интервалом (бутстрап 1000, зерно)

Контрольная карта (CRM × элемент × лаборатория): значения по дате или SEQ, линии μ, ±2σ, ±3σ, фактическое и скользящее (10) среднее, цвет по статусу; щелчок — сведения о пробе и подсветка партии. Фильтры — лаборатория, партия, даты, элемент, CRM, тип, префикс скважины, любое поле; действуют на все графики и отчёт и сохраняются в нём. Пороги (2σ/3σ, серия 9, k_б = 5, k_д = 5, группа 11, критерии HARD) настраиваются: 1–5σ, 5–20, 1–50·DL, 0–50·DL, 5–51 (нечётное).

#### 8.4.3. Интерфейс, отчёт, производительность

«Анализ → QAQC»: Настройка (типы, CRM, DL), Стандарты, Бланки, Дубликаты, Внешний контроль, Партии, Отчёт. Работа — во вкладке «QAQC» нижней панели: слева фильтры, справа подвкладки. Отчёт: XLSX (листы «Сводка», «Стандарты», «Бланки», «Дубликаты», «Внешний контроль», «Партии», «Параметры»; графики — PNG из интерфейса в 2×) и PDF через 8.12. В проекте: настройка QAQC, справочник CRM, объекты «Отчёт QAQC» (параметры, фильтры, хеш данных, файлы).

На 1 млн контрольных записей: пересчёт после смены фильтра ≤ 3 с; графики до 100 тыс. точек — ≥ 30 кадров/с; XLSX и PDF — ≤ 60 с каждый.
