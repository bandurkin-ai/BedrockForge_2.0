### 7.32. Ассистент Claude \[Э23\]

**Назначение.** Ассистент отвечает на вопросы по проекту и выполняет команды интерфейса.

**Устройство.** Панель отправляет в ядро сообщение и контекст экрана (проект, окна, выбранная скважина, шкала, разрез); ядро вызывает Claude API — единственная функция с сетью. Инструменты чтения данных выполняются в ядре: дерево проекта (с графиками и интервальными таблицами), сводка проекта или набора, список и карточка скважин, история объекта, итог и находки аудита, таблица набора, статистика компонента (справочно `data_*`). Команды интерфейса — все команды реестра без `uiOnly`, выполняются в окне; ход, ждущий окна, хранится в диалоге (`pending`).

**Окно «Claude: подключение»** (значок аккаунта, ссылка в строке состояния, «Подключить Claude» в панели)

| **Раздел**          | **Содержимое**                                                                                                                                                                                                                                                                                                                                                                                 |
|---------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Профиль             | Способ (аккаунт Anthropic, API-ключ, ключ из переменной окружения), организация и рабочая область, «Проверить связь», «Выйти»                                                                                                                                                                                                                                                                  |
| Вход                | **Аккаунт**: «Войти через Anthropic» открывает вход Anthropic Console в системном браузере, код вставляется в окно, доступ обновляется сам. **Ключ** `sk-ant-…` (console.anthropic.com → API Keys) проверяется до сохранения. Подписка Claude (Pro, Max, Team) панелью не используется — окно об этом сообщает                                                                                 |
| Модель              | Opus 5.5 `claude-opus-5-5` (по умолчанию), Sonnet 5.5 `claude-sonnet-5-5`, Haiku 5.5 `claude-haiku-5-5`, Fable 5.2 `claude-fable-5-2` — с ценой, \$ за 1 млн токенов вход / выход / чтение кеша: 4 / 20 / 0,20; 2 / 10 / 0,10; 0,10 / 0,50 / 0,01; 8 / 40 / 0,20; запись кеша = 1,25 × вход. Справочник цен обновляется с версией (у Haiku 5.5 запросы длиннее 100 тыс. токенов — 0,50 / 2,50) |
| Глубина рассуждений | `low` «Быстро», `medium` «Обычно» (по умолчанию), `high` «Тщательно», `xhigh` «Очень тщательно», `max` «Максимум»                                                                                                                                                                                                                                                                              |
| Расход              | Сегодня / 30 дней / всё время: запросы, токены, оценка в \$, по моделям                                                                                                                                                                                                                                                                                                                        |

**Хранение подключения.** Одно на пользователя Windows (\[сервер\] — на сервер). Ключ и вход — только в ядре, в профиле пользователя, зашифрованы средствами ОС; в окно — только маска. Вход аккаунтом — утилита `ant` 2.9.0 (`ant auth login --no-browser`) из дистрибутива, архив проверяется по SHA-256 при сборке; без `ant` — только ключ. Переменные: `ANTHROPIC_API_KEY` (если в окне ничего не подключено), `ASSISTANT_MODEL` (по умолчанию `claude-opus-5-5`), `ASSISTANT_EFFORT` (по умолчанию `medium`).

**Панель чата.** Быстрые запросы (7.0.4), «Новый диалог», модель в шапке; подтверждение `confirm` — название и описание действия, «разрешить» / «отклонить». **История диалогов** — в проекте: список с датой, числом вопросов и стоимостью; открыть (продолжение с места остановки), переименовать, удалить; при открытии проекта — последний диалог. Без сети — сообщение об отсутствии связи, история читается.

**Приёмка**

- Неверный ключ не сохраняется; ключ не попадает целиком в окно и журналы.

- «Покажи скважину X на разрезе» выполняет `hole.select` и `section.through_hole`, обе — в журнале с источником «Claude».

- Удаление проекта по просьбе требует подтверждения в чате.

- После перезапуска открывается последний диалог проекта.

- Расход показывает стоимость по моделям за сегодня, 30 дней, всё время.
