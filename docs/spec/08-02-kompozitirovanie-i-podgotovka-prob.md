### 8.2. Композитирование и подготовка проб \[Э12\]

#### 8.2.1. Функции

Закрывает CHECKLIST № 160–162, 164–168, 229.

Композиты по длине (правило остатка, минимальная доля опробованной длины), по доменам (композит не пересекает смену кода — поле интервальной таблицы или каркасы), по уступам; кодирование проб каркасами с делением на границе тела; объединение интервальных таблиц; урезка ураганных проб с отчётом «до/после» и инструментами выбора порога; эквивалент металла; таблица координат начала, середины и конца проб; декластеризация — перенос BF (ячейки и полигоны в плане) и ячейки в 3D с анизотропией (GSLIB declus: anisy, anisz), веса — поле `DECL_W`.

#### 8.2.2. Алгоритмы

    по длине — для каждого непрерывного участка домена [a; b] скважины (без доменов — [начало; забой]):
      отсчёт от a (по умолчанию), от устья или от кровли первой пробы;  D = b − a
      «равные»:  n = max(1, floor(D/L + 0,5)),  L' = D/n
      «остаток»: n0 = floor(D/L + 1e−9), r = D − n0·L;  r ≥ f_min·L — отдельный композит;
                 r < f_min·L — присоединить к последнему (по умолчанию) или отбросить; при n0 = 0 — отбросить с записью в журнал
    значение композита [c0; c1]: l_i — перекрытие пробы i, где g_i не NaN;  w_i = 1 или ρ_i (взвешивание по плотности)
      g_c = Σ l_i·w_i·g_i / Σ l_i·w_i;   ρ_c = Σ l_i·ρ_i / Σ l_i;   L_оп = Σ l_i
      L_оп < p_min·(c1 − c0) → g_c = NaN, FLAG = «мало проб»;  текстовые поля — мода по длине (при равенстве — первое)
      непробованные участки: NaN (по умолчанию), 0 или заданное значение
    по уступам: Z_j = Z_верх − j·H или список; глубины пересечения траектории с Z = Z_j — на дугах минимальной кривизны (1e−6 м);
      X, Y, Z композита — середина участка по длине; abs(Δz) < 0,2·длины — флаг «пологая»
    кодирование каркасами: траектория — хорды ≤ 1 м; пересечения с треугольниками через BVH во float64; внутри — по чётности;
      пробы делятся в точках входа и выхода; перекрытие тел — по приоритетам; без деления — код по середине и доля длины внутри
    объединение таблиц: все FROM/TO скважины по всем таблицам, уникальные по возрастанию; подынтервал берёт значения
      покрывающего интервала каждой таблицы, нет покрытия — NaN
    урезка: T — значение или перцентиль P проб домена, взвешенных по длине (правило BF `weighted_percentiles`);
      g_cut = min(g, T); поля AU_CUT и AU_CUT_F (1 — урезано); T хранится по доменам
    эквивалент: Eq = g_1 + Σ_(e≥2) g_e·(P_e·R_e·k_e)/(P_1·R_1·k_1);  P — цена, R — извлечение,
      k — перевод единицы содержания в единицу цены (г/т и $/унц: 1/31,1034768; % и $/т: 0,01)

Отчёт урезки по домену: n, число и доля урезанных, среднее, CV и максимум до и после, потеря металла 100·Σ l·(g − g_cut)/Σ l·g. Выбор порога: кривые «порог → среднее, CV, потеря металла, число урезанных» для P = 90…99,9 %; лог-вероятностный график (8.3); доли металла по децилям и по процентилям верхнего дециля с пометкой, если верхний дециль \> 40 % металла или верхний процентиль \> 10 % (пороги настраиваются). Порог автоматически не применяется.

|------------------------------------|-----------------------------|-----------------------|
| Длина L                            | 2 м                         | 0,1–100 м             |
| Правило остатка / f_min            | остаток, присоединить / 0,5 | равные, остаток / 0–1 |
| Мин. доля опробованной длины p_min | 0,5                         | 0–1                   |

#### 8.2.3. Интерфейс и данные проекта

«Анализ → Обработка проб»: Композиты (метод — вкладкой: по длине, по доменам, по уступам), Кодировать каркасами, Объединить таблицы, Урезка, Эквивалент металла, Координаты проб, Декластеризация. Окно композитов: источник (набор, таблица, поля), домен, параметры, предпросмотр на выбранной скважине (пробы и композиты рядом) и сводка «до/после»: число, общая длина, среднее и металл Σ l·g по полям. Результат — таблица набора скважин (6.5) с полями HOLE, FROM, TO, LENGTH, X, Y, Z, исходные поля, DENSITY, SAMPLED_LEN, N_SAMPLES, DOMAIN, FLAG и метаданными (источник, параметры, хеш). Урезка добавляет поля в таблицу и объект «Урезка» с отчётом.

| **Операция (50 тыс. скважин, 5 млн проб, 10 полей)**    | **Цель**                |

| Кодирование каркасами общим объёмом 1 млн треугольников | ≤ 90 с                  |
| Объединение таблиц 5 млн + 1 млн интервалов             | ≤ 30 с                  |
| Анализ урезки                                           | ≤ 3 с                   |
