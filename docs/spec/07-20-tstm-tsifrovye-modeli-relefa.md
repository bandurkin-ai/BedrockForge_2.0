### 7.20. ЦТМ — цифровые модели рельефа \[Э7\]

**Назначение.** Раздел **ЦТМ** хранит топографические поверхности отдельно от рудных тел. Растр на рельефе — реализуемая функция.

| **Действие**          | **Требование**                                                                                                                                    |
|-----------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| В ЦТМ                 | Меню каркаса «Перенести в ЦТМ», значок в строке, кнопка в свойствах, «Моделирование → Поверхности → В ЦТМ»; после переноса открываются «Свойства» |
| Вернуть в каркасы     | Там же; настройки рельефа сбрасываются                                                                                                            |
| Настройки ЦТМ         | Шестерёнка, «Настройки ЦТМ…», щелчок по строке; вверху «Свойств»                                                                                  |
| Растр на рельефе      | Растр в плане (карта, ортофото) повторяет рельеф на всех уровнях детализации; вертикальные не предлагаются                                        |
| Скрыть данные за ЦТМ  | Виден только растр на ЦТМ; без галочки остальное плоско вокруг на своей высоте                                                                    |
| Цвет растра           | Множитель изображения (белый — без изменений)                                                                                                     |
| Непрозрачность растра | 0–1, перекрытие собственного цвета поверхности                                                                                                    |
| Тени рельефа          | Свет и тень на изображении; без галочки — цвета как есть                                                                                          |
| Атрибуты              | Добавить, изменить, переименовать, удалить                                                                                                        |

- Объект остаётся каркасом: изолинии, объём, обрезка, экспорт DXF/OBJ работают.

- `wireframe.dtm {wireframe_id, on, raster_id, clip, tint: "#rrggbb", opacity: 0–1, shade}`: настройки без `on` переносят в ЦТМ; без `wireframe_id` — выбранный каркас; `raster_id: 0` снимает растр.

**Хранение.** Признак ЦТМ и `{raster_id, clip, tint, opacity, shade}` у каркаса.

**Приёмка.** Растр повторяет рельеф при приближении на всех уровнях детализации. «Вернуть в каркасы» сбрасывает растр. Вертикальный растр не предлагается.
