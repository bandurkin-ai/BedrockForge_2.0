### 7.13. Главное 3D-окно \[Э6\]

**Назначение.** Одна сцена со всеми объектами: скважины, каркасы, ЦТМ, линии, растры, блочные модели, swath plot, отображения по стволу.

**Панель над окном** (иконки с подсказками): Повернуть вид (В план, Сбоку Z/X, Сбоку Z/Y); Вписать; Разрез, Разрез через скважину, Авто-разрез (пока линии нет); Отсечение, Предыдущий/Следующий профиль, В плоскость разреза, План, Сбросить разрез; поле «Азимут линии разреза»; Вертикальное преувеличение (1, 2, 3, 5); Непрозрачность каркасов (0,1–1); Отображение: Перспектива, Сетка («Координатная сетка с подписями»); Данные по скважинам.

| **Вид**                                      | **Требование**                                                                                                 |
|----------------------------------------------|----------------------------------------------------------------------------------------------------------------|
| В план (`top`, `T`)                          | Сверху (Y вверх, X вправо) на то, что на экране: поворот вокруг центра вида, масштаб сохраняется, не вписывает |
| Сбоку Z/X (`front`, `X`) / Z/Y (`side`, `Y`) | На север: Z вверх, X вправо / на запад: Z вверх, Y вправо                                                      |
| Изометрия (`iso`)                            | Из команды или палитры                                                                                         |
| В плоскость разреза (`section`)              | Z вверх, линия слева направо; без линии — ошибка «Линия разреза не задана: сначала section.set»                |
| Вписать (`scene.fit`, `F`)                   | Все видимые объекты без поворота; при отсечении — только объекты в окне разреза                                |

**Гизмо осей:** левый нижний угол (отступ 10 px слева, 26 px снизу; 92×92 px), поворачивается с камерой каждый кадр. X `#ef4f5f`, Y `#3fbf6f`, Z `#4c8dff`, подложка — полупрозрачный круг; оси к наблюдателю — поверх, от него — с непрозрачностью 0,45. Щелчок по головке оси (r = 8) — «Вид вдоль оси X (с её положительной стороны)», по кружку напротив (r = 4) — «Вид с отрицательной стороны оси X». Поворот плавный, центр и масштаб сохраняются, новый прерывает начатый; строго сверху или снизу экран держит Y вверх.

**Прочее**

- Проекция по умолчанию ортогональная; `scene.style {perspective, grid, vexag, wireframe_opacity}`; непрозрачность каркасов по умолчанию 0,7. Вращение, сдвиг, масштаб мышью.

- Координаты — float64 без округления; для показа — float32 относительно центра объекта: до 16 км в поперечнике погрешность ≤ 0,5 мм; расчёты — float64. Разбор геометрии — в фоновом потоке без копирования.

- Работа на встроенной графике ПК приёмки при объёмах 7.0.1.

**Выбор по клику:** скважина — в 3D, таблицах и «Свойствах» (`hole.select`), `Esc` снимает; объект — `object.select` (свойства каркаса, слоя линий, растра, модели); треугольник каркаса — вершины, площадь, угол и азимут падения по точным данным; блок — его свойства.

**Хранение.** Параметры вида — в настройках вида проекта (7.0.10).

**Приёмка**

- `T` из любого положения даёт вид сверху без изменения масштаба и центра; «Вписать» не поворачивает камеру.

- Головка Z на гизмо — вид сверху, отрицательный кружок Z — вид снизу.

- Точки в 0,001 м друг от друга в объекте 10 км рисуются раздельно.

- Щелчок по каркасу показывает азимут и угол падения треугольника.
