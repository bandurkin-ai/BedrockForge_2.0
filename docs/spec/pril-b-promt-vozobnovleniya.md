## Приложение Б. Промт возобновления

### Б.1. Новая веха или новая сессия

Перед отправкой: `/model opus`, `/effort high` (по желанию `/autocompact 400k`).

    Продолжи разработку BedrockForge 2 по ТЗ docs/TZ/BF2-TZ.docx (разбито в docs/spec/).
    1. Прочитай только CLAUDE.md и PROGRESS.md.
    2. Проверь git status, git log -5, состояние PR и CI текущего этапа.
       Прошлая ветка (если сессия новая): <имя ветки из PROGRESS.md> — влей её в ветку
       этой сессии, если её PR не слит.
    3. Незакоммиченные изменения после пересоздания контейнера: оцени, закоммить как wip
       или откати. Переустанови зависимости, если их нет.
    4. Включи страховку от лимита (раздел 15.3), если её нет.
    5. Продолжай с «Следующего действия». ТЗ целиком не перечитывай — только файлы spec
       текущего этапа по docs/spec/00-index.md.
    6. Если ты на вехе и ждёшь приёмки — ответь одной строкой «Жду приёмки Вn» и остановись.
    Все разрешения и правила мастер-промта (Приложение А ТЗ) действуют.

### Б.2. Та же сессия после лимита (и текст страховочной задачи)

    Продолжай по PROGRESS.md с «Следующего действия». Сначала git status: всё ли запушено.
    Если работа уже идёт или ты на вехе — ответь одной строкой и ничего не делай.

### Б.3. Принятие вехи

    Веха Вn принята. Замечания: <нет / список>. Закрой веху в PROGRESS.md, слей
    оставшиеся PR, удали страховочные задачи и дай промт для новой сессии следующей вехи.
