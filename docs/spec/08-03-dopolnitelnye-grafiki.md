### 8.3. Дополнительные графики \[Э13, расширение\]

Устроены как графики BF (плавающее окно, сохранение в дереве, PNG/SVG/CSV, веса и отсечки гистограммы). Выделение рамкой или лассо подсвечивает пробы в 3D и таблице, и наоборот (№ 237). Закрывает № 224–228. Время на 5 млн проб — ≤ 2 с, контактный анализ на 50 тыс. скважин — ≤ 10 с.

| **График**                       | **Содержание**                                                                                                                                                                                                                                                                                    |
|----------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Рассеяние                        | Поля одной или двух таблиц (связь по ключу пробы), цвет по полю, лог-оси; МНК, RMA (b = sign(r)·σ_y/σ_x), взвешенная регрессия; r Пирсона и Спирмена; линия 1:1; больше 200 000 точек — плотность ячейками 100×100                                                                                |
| Ящики с усами                    | По доменам: квартили по BF `weighted_percentiles`, усы — крайние значения в \[Q1 − 1,5·IQR; Q3 + 1,5·IQR\], выбросы — точки (до 5000), среднее, n; лог-шкала — по логарифмам                                                                                                                      |
| Лог-вероятностный                | x — содержание (лог), y — Φ⁻¹(P), P = (C − w/2)/W; несколько доменов; щелчок по перегибу передаёт порог в окно урезки                                                                                                                                                                             |
| Контактный анализ                | Точки смены доменов A↔B вдоль ствола; пробы на расстоянии ≤ D (20 м) по стволу в шагах b (1 м): сторона A — отрицательные расстояния, B — положительные; среднее по шагу (вес — длина) и n; вариант — расстояние до каркаса контакта. Ступень — жёсткая граница, плавный переход — мягкая (8.8.2) |
| Тернарная, статистика по доменам | Три поля, нормированные на сумму; таблица по доменам: n, длина, взвешенное и декластерированное среднее, медиана, σ, CV, min, max, P10, P50, P90                                                                                                                                                  |

| **Тест** | **Ожидание**                                                                                             |
|----------|----------------------------------------------------------------------------------------------------------|
| Т8.3-1   | Квартили ящика равны `weighted_percentiles` BF (1e−12); y = 2x + 1 без шума: МНК и RMA дают b = 2, a = 1 |
| Т8.3-2   | В A везде 1,0, в B — 3,0: средние шагов −D…0 равны 1, шагов 0…D — 3 точно                                |
| Т8.3-3   | Лассо на рассеянии: в 3D подсвечены ровно выбранные пробы                                                |
