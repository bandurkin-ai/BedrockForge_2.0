### 7.14. Разрезы (отсечение) \[Э6\]

**Назначение.** Вертикальный разрез по линии и отсечение данных окном «от / до».

| **Функция**                    | **Требование**                                                                                                                                                                                                                             |
|--------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Провести (`section.draw`, `S`) | Два клика в текущем виде (без поворота и вписывания) или на мини-плане; точки на плоскости через центр вида (в плане — горизонтальной, сбоку — вертикальной к зрителю); между кликами — оранжевая «резинка»; линия от края до края         |
| После второго клика            | Включается отсечение; вид в плоскость разреза (Z вверх, линия слева направо, наблюдатель справа), вписана линия от края до края                                                                                                            |
| Окно                           | **От** (к наблюдателю) и **До** (от наблюдателя), по умолчанию 25 и 25 м; шаг профиля = От + До; `section.window {towards, away, clip}`                                                                                                    |
| По параметрам                  | `section.set`: азимут по часовой от севера, `length = null` — без ограничения                                                                                                                                                              |
| Отсечение (`C`)                | Вкл./выкл. без поворота; вращать можно и при отсечении, «В плоскость» возвращает                                                                                                                                                           |
| Профили (`[` / `]`)            | Сдвиг линии на ширину окна к наблюдателю / от него                                                                                                                                                                                         |
| Авто-разрез                    | Поперёк простирания устьев через их центр                                                                                                                                                                                                  |
| Через скважину                 | Через устье по азимуту скважины в плане (от устья к забою): скважина целиком в плоскости; у вертикальной азимут прежний                                                                                                                    |
| Мини-план                      | План с данными (до **20 000** точек), линией, окном «от / до», стороной взгляда (оранжевый треугольник); крестик скрывает, «План» открывает                                                                                                |
| Сбросить                       | Удаляет линию, выключает отсечение                                                                                                                                                                                                         |
| Что отсекается                 | Скважины, интервалы, линии (части в окне), блоки («срез на разрезе» — сечение подложкой), растры. Каркасы — линиями сечения, точные сечения float64 считает ядро только по задетым частям. Вертикальный растр — подложка, остальное поверх |

Наклонный, горизонтальный, ломаный разрезы и серии — раздел 8 (Э10).

**Хранение.** Отсечение — в настройках вида проекта (7.0.10).

**Приёмка.** После двух кликов вид смотрит на плоскость, объекты вне окна скрыты. `]` сдвигает линию ровно на (от + до). Разрез через наклонную скважину содержит всю траекторию. Каркас, пересекающий плоскость, показан замкнутой линией сечения.
