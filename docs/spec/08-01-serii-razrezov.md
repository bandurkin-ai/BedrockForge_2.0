### 8.1. Серии разрезов \[Э10\]

#### 8.1.1. Функции

Набор параллельных разрезов или планов с общими параметрами, переход клавишами, показ только данных окна, оцифровка на разрезе, каркас по контурам серии, печать серии. Закрывает CHECKLIST № 199–202.

Типы серий: вертикальная (две точки P1→P2 в плане или P1 и азимут линии A); горизонтальная — планы (верхняя и нижняя отметки, шаг по Z); наклонная (P1, A, наклон плоскости φ, 90° — вертикальная); ломаный разрез (ломаная P0…Pm в плане и ширина коридора, одна развёртка); из существующего — через скважину, поперёк простирания устьев (как в BF), серия из одного разреза.

#### 8.1.2. Геометрия

    ŝ = (sin A, cos A, 0)                       — линия разреза, слева направо на экране
    v̂ = (−cos A·sin φ, sin A·sin φ, −cos φ)     — направление взгляда; при φ = 90° наблюдатель справа от линии
    ŵ = ŝ × v̂                                   — «вверх» на экране (φ = 90°: +Z; план при A = 90°: север)
    s_k = s0 + k·Δ,  k = 0…K−1,  K = floor((s1 − s0)/Δ + 1e−9) + 1;   O_k = P1 + s_k·v̂  («следующий» = k + 1, дальше от наблюдателя)
    t(p) = (p − O_k)·v̂;   в окне: −w_к ≤ t < w_от   (w_к — к наблюдателю, w_от — от наблюдателя)
    координаты на разрезе: u = (p − P1)·ŝ,  w = (p − P1)·ŵ (у вертикального — отметка Z);   план: v̂ = (0, 0, −1), z_k = z_верх − k·Δ

Окно полуоткрытое: при Δ = w_к + w_от окна соседних разрезов делят пространство без зазоров. Разрезу можно задать свои w_к, w_от. Ломаный разрез: точка относится к ближайшему в плане сегменту (у излома — с меньшим номером), если расстояние до него ≤ ширины коридора; u развёртки = длина предыдущих сегментов + u на сегменте; в 3D вид ставится перпендикулярно текущему сегменту, `[` `]` переключают сегменты.

Имена — шаблон с переменными `{k}` (с 1), `{s}`, `{X}`, `{Y}`, `{Z}` (координаты O_k) в формате Python. По умолчанию: A = 90° или 270° — `{Y:.0f}N`; A = 0° или 180° — `{X:.0f}E`; планы — `{Z:.0f}`; иначе `{s:+.0f}`. Повтор имени в серии запрещён.

Параметры по умолчанию (диапазон): w_к = w_от = 25 м, как в BF (0,01–10 000 м); Δ = w_к + w_от (0,01–10 000 м); s0, s1 — охват видимых данных по v̂, кратно Δ (K ≤ 5000); φ = 90° (0–90°); коридор 25 м; тень — предыдущий разрез (нет, предыдущий, следующий, оба).

#### 8.1.3. Навигация и показ окна

| **Действие**                 | **Клавиша**               | **Поведение**                                                                                                                                        |
|------------------------------|---------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| Следующий / предыдущий       | `]` / `[`                 | k ± 1; без активной серии — сдвиг на ширину окна (как в BF); на краю — без изменений, сообщение в строке состояния                                   |
| Первый / последний / перейти | `Home` / `End` / `Ctrl+G` | k = 0 / K − 1 / ввод имени или номера с подсказками                                                                                                  |
| Зафиксировать вид            | `L`                       | Ортогональная камера по v̂, верх — ŵ; вращение отключено, сдвиг и масштаб работают; при смене разреза точка с теми же (u, w) остаётся на месте экрана |
| Отсечение                    | `C`                       | Как в BF                                                                                                                                             |

При отсечении: скважины и отображения по стволу — части в окне; линии, точки — части в окне; каркасы — точная линия сечения плоскостью t = 0 (сервер, float64), по выбору — часть каркаса в окне; блоки — срез (8.7.6) или блоки в окне; растры — как в BF. Объекты вне окна не выбираются кликом и не служат целями привязки. Тень — контуры серии с соседних разрезов серым пунктиром.

#### 8.1.4. Оцифровка и каркас по серии

- Вершина ложится на плоскость t = 0 (пересечение луча курсора с плоскостью во float64 на CPU); при привязке точка проецируется на плоскость вдоль v̂ (переключатель «оставить 3D»). Контур получает атрибуты `SECTION_SET`, `SECTION`, `SECTION_NAME`; правятся только контуры текущего разреза (фильтр «все» снимает ограничение).

- «Каркас по серии»: контуры соседних разрезов связываются, если их проекции на плоскость разреза перекрываются, иначе — если расстояние между центроидами ≤ Δ; таблица связей правится щелчками по контурам; 1→N — разветвление. Сшивка — перенос BF `app/geo/stitch.py` с тай-линиями.

- Торцы: по умолчанию крайний контур продлевается на Δ/2 наружу и закрывается плоско; варианты — крышка на крайнем разрезе, выклинивание в точку или линию на Δ/2. Результат — замкнутый каркас с отчётом (объём, треугольники, проверки); при провале проверки каркас не создаётся, ошибка называет разрезы.

#### 8.1.5. Интерфейс, данные, производительность

Вкладка «Разрезы»: «Серия» — Менеджер серий, Новая серия, Из линии разреза, Через скважину; «Навигация» — Первый, Предыдущий, Следующий, Последний, Перейти; «Вид» — Зафиксировать вид, Отсечение, Тень; «Оцифровка» — Контур на разрезе, Каркас по серии; «Печать» — Печать серии (8.12.3). Менеджер серий: список серий (создать, копировать, удалить, сделать активной), параметры, таблица разрезов (номер, имя, s, свои окна), линии на мини-плане. Активная серия и разрез — в строке состояния; в дереве — «Серии разрезов», клик по разрезу — переход. В проекте хранятся тип, P1, P2 или A, φ, s0, s1, Δ, окна и их переопределения, шаблон имён, текущий k, шаблон макета печати; имена и O_k вычисляются.
