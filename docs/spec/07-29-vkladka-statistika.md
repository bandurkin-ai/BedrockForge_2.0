### 7.29. Вкладка «Статистика» \[Э13, Э16\]

**Назначение.** Базовая геостатистика по компоненту набора.

**Интерфейс.** «Анализ → Статистика», `stats.open {analysis, component, set_id}` (для Claude). Один компонент, выбранная таблица опробования; интервал — точка в середине на траектории; декластеризация и вариограммы — в плане (X, Y). Декластеризация, нормальные оценки, бутстрап — Э13; вариограммы и карта неопределённости — Э16 (развитие — раздел 8).

| **Анализ**  | **Что показывает**                                                                                                                       |
|-------------|------------------------------------------------------------------------------------------------------------------------------------------|
| `declus`    | Среднее с весами и без; кривая «размер ячейки → среднее»; лучший размер; ячейки или полигоны                                             |
| `nscore`    | Таблица нормального преобразования (можно с весами декластеризации); обратное преобразование                                             |
| `variogram` | Экспериментальная всенаправленная или по 4 направлениям; модель (самородок + структуры), кривая модели — и без данных; число пар в лагах |
| `map`       | γ по сдвигам (ΔX, ΔY); пустая ячейка, если пар меньше порога                                                                             |
| `bootstrap` | Доверительные интервалы среднего, медианы, σ, CV, P10, P90; можно с весами декластеризации                                               |
| `local`     | Разброс оценки IDW в плане: реализация — выборка скважин с возвратом; карты среднего, σ, P10, P90, вероятности превысить порог           |

Больше **20 000** интервалов не считается (расчёт по парам) — совет композитировать (раздел 8, Э12). Расчёты — NumPy/SciPy в ядре (из GeostatsPy).

**Хранение.** Результаты в дерево не сохраняются, пересчитываются при открытии.

**Приёмка.** На регулярной сетке без кластеров декластеризованное среднее = обычному. 20 001 интервал — отказ с советом композитировать.
