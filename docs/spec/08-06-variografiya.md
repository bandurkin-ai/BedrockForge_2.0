### 8.6. Вариография \[Э16\]

#### 8.6.1. Функции

Расширение BF `stats/variogram.py` (2D, до 20 000 точек) до 3D, моделей с анизотропией и подбора. Закрывает CHECKLIST № 314, 315, 318, 319.

Функции: направленные 3D-вариограммы (лаг, допуски, азимут, погружение, полосы — определения GSLIB gamv); вдоль скважин (пары одной скважины, расстояние — разность глубин; для самородка); веер N направлений в плоскости — роза дальностей; карта вариограмм в произвольной плоскости (щелчок задаёт направление); типы — полувариограмма, коррелограмма (на графике 1 − ρ), парная относительная, нормальные оценки (BF `nscore` с весами декластеризации, обратное преобразование модели); модель — самородок + до 3 структур (сферическая, экспоненциальная, гауссова) со своими ang1–ang3, a1–a3 (флажок «общие оси»); автоподбор и ручная правка; эллипсоид модели и поиска в 3D.

#### 8.6.2. Расчёт

    γ(h_k) = 1/(2·N_k)·Σ (z_i − z_j)² по неупорядоченным парам лага k (лаг k центрирован на k·L, как в BF)
    коррелограмма ρ_k = C_k/(σ_−·σ_+);  парная относительная γ_k = 1/(2·N_k)·Σ ((z_i − z_j)/((z_i + z_j)/2))²
    numba: сетка ячеек h_max = (nlag + 0,5)·L, перебор пар соседних ячеек, накопители [направление × лаг] у потоков
      складываются в фиксированном порядке; оценка числа пар > 2·10⁹ — случайная выборка данных (зерно) с сообщением

#### 8.6.3. Модели и анизотропия

    a = 90° − ang1 при 0 ≤ ang1 < 270°, иначе 450° − ang1;   b = −ang2;   t = ang3        (setrot GSLIB)
    R = [[  cos b·cos a,                       cos b·sin a,                      −sin b      ],
         [ −cos t·sin a + sin t·sin b·cos a,   cos t·cos a + sin t·sin b·sin a,   sin t·cos b ],
         [  sin t·sin a + cos t·sin b·cos a,  −sin t·cos a + cos t·sin b·sin a,   cos t·cos b ]]
    строки R — оси a1, a2, a3 в мировых координатах;   h_r = ‖diag(1, a1/a2, a1/a3)·R·Δ‖ / a1
    сферическая c·(1,5·h_r − 0,5·h_r³) при h_r < 1, иначе c;  экспоненциальная c·(1 − e^(−3·h_r));  гауссова c·(1 − e^(−3·h_r²))
    γ(Δ) = C0·[Δ ≠ 0] + Σ_s γ_s(Δ);   C(Δ) = C0 + Σ c_s − γ(Δ)   (практическая дальность, как в BF)
    обратное преобразование модели нормальных оценок (разложение Эрмита):
      Z = Φ_Z(Y) — таблица нормальных оценок с хвостами BF backtr;  φ_n = E[Φ_Z(Y)·H_n(Y)] — квадратура Гаусса–Эрмита, 200 узлов
      H_0 = 1, H_1 = y, H_(n+1) = (y·H_n − √n·H_(n−1))/√(n+1);   ρ_Y = 1 − γ_Y;   C_Z = Σ_(n=1..30) φ_n²·ρ_Y^n;   γ_Z = C_Z(0) − C_Z
      Σ φ_n²/Var(Z) < 0,95 — предупреждение; кривые γ_Z по трём осям аппроксимируются моделью МНК
    автоподбор: min Σ_d Σ_k w_k·(γ̂_dk − γ(h_dk·u_d))², w_k = N_k/h̄_k (варианты N_k, N_k/γ²);
      неизвестные C0, c_s, a1–a3 (углы — по выбранным направлениям); C0 ≥ 0, c_s ≥ 0, C0 + Σ c_s ≤ 1,2·σ² (для нормальных оценок = 1),
      L/2 ≤ a ≤ 2·h_max; scipy.optimize.least_squares (trf), 8 стартов на сетке, лучший по невязке;
      начальный C0 — экстраполяция к 0 первых трёх лагов вдоль скважин (≥ 0)

#### 8.6.4. Параметры, интерфейс, данные

Параметры по умолчанию (диапазон): лаг L — длина композита × 5; 15 лагов (1–100); допуск лага L/2 (0–L); допуски азимута и погружения 22,5° (0–90°); полосы 3L по горизонтали и 2L по вертикали (\> 0 или ∞); точка строится при ≥ 30 парах (1–1000); веер — 12 направлений (4–72).

«Геостатистика → Вариография»: Вариограммы, Вдоль скважин, Веер, Карта вариограмм, Нормальные оценки, Модели. Окно «Вариография»: данные (таблица, поле, домен, преобразование), графики трёх осей и вдоль скважин с числом пар, таблица модели. Правка мышью: самородок — у h = 0, вклад — горизонтальная линия, дальность — вертикальная линия на графике своей оси; отклик ≤ 50 мс. Кнопки: Подобрать, Эллипсоид в 3D, Сохранить. Модель — объект «Геостатистика → Модели вариограмм» (JSON: домен, поле, преобразование и ссылка на таблицу нормальных оценок, C0, структуры, параметры расчёта, невязка, хеш); экспериментальные точки — Parquet. Обмен: JSON и параметры GSLIB (`nst c0`, `it cc ang1 ang2 ang3`, `a1 a2 a3`).

Время (200 тыс. композитов, h_max = 300 м): 3 оси + вдоль скважин, 20 лагов — ≤ 15 с, ≤ 2 ГБ; веер 12 направлений и карта 41×41 — ≤ 20 с; подбор 3 структур — ≤ 3 с.
