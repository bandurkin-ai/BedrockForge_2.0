#### 7.0.5. Строка состояния

Слева направо через «·»: (1) точка и состояние ядра — «Запуск ядра…», «Ядро работает», «Нет связи с ядром» (\[сервер\] — то же для сервера с адресом), опрос раз в **15 с**; (2) «Проект: \<название\>»; (3) «Набор: \<имя\> (N скв.)» или «Набор: —», число в `ru-RU`; (4) «Выбрана: **\<скважина\>**» — при выборе; (5) «Вид: \<режим\>» — вид и параметры разреза; (6) справа ссылка «Claude: не подключён / аккаунт / ключ / подключён · \<модель\>» → окно подключения; (7) «Аудит: E / W / I» (критично / предупреждения / информация), «(устарел)» после изменения данных; без аудита — «Аудит не запускался».

#### 7.0.6. Горячие клавиши

**По умолчанию:** `T` / `X` / `Y` — в план / сбоку Z/X (на север) / сбоку Z/Y (на запад); `F` — вписать; `S` — провести разрез; `C` — отсечение; `[` / `]` — профиль назад / вперёд; `Esc` — снять выбор; `Ctrl+K` — палитра; `Ctrl+J` — Claude; `Ctrl+B` — дерево; `Ctrl+Ё` (клавиша над Tab) — нижняя панель; `Ctrl+F1` — лента. В редакторе стрингов — 7.22; в форме отображения по стволу — `Ctrl+Z` / `Ctrl+Y`; в правке таблицы — `Enter` сохранить, `Tab` следующая ячейка, `Esc` отмена.

**Правила**

- Буквенные клавиши работают в любой раскладке; одиночные клавиши и `Esc` не срабатывают в поле ввода, сочетания с `Ctrl` — везде.

- Пока открыты палитра или окно импорта, клавиши ленты отключены; недоступная кнопка по клавише не запускается.

- Функция = команда + аргументы; аргументы да/нет — переключатель («Показать сетку» и «Скрыть сетку» — одна функция).

**Своё назначение** («Настройка» → «Быстрые клавиши»): таблица «Функция — Сочетание» с поиском по функции и сочетанию; «Назначить» → «нажмите сочетание…», «Убрать сочетание», «Вернуть по умолчанию», пометка «· изменено»; занятое сочетание — диалог «Сочетание уже занято» с «Переназначить» (у другой функции снимается); «Сбросить» с подтверждением «Вернуть сочетания по умолчанию? Изменённых: N». Нельзя назначить зарезервированные Windows и оболочкой: `Alt+F4`, `Alt+Tab`, `Ctrl+Alt+Delete`, сочетания с Win, `F5`, `F11`, `Ctrl+Shift+I`. Назначения хранятся в файле настроек пользователя и действуют везде (подсказки ленты, палитра, клавиши); запись, равная умолчанию, удаляется, чтобы новые умолчания доходили до пользователя.

#### 7.0.7. Палитра команд (`Ctrl+K`)

- Поиск по всем кнопкам ленты: подпись, «вкладка › группа», подсказка; справа — клавиша, недоступные помечены.

- «скв » — поиск только скважин по номеру (подстрока, без учёта регистра), выбор → `hole.select`; без префикса скважины ищутся при запросе от **2** символов.

- Не больше **60** результатов; `↑`/`↓`, `Enter` — выполнить, `Esc` — закрыть. Поиск скважин должен работать на 50 000 скважин.

#### 7.0.8. Журнал команд

Колонки: Время (`ru-RU`), Кто («Вы», «Claude»), Команда, Параметры (`ключ=значение`), Результат; неудачные строки выделены. Последние **200** записей, новые сверху; импорт файла тоже пишется; команды `silent` не пишутся. Пустой журнал: «Здесь появятся выполненные команды: ваши и ассистента Claude.»

#### 7.0.9. Темы

Тёмная (по умолчанию) и светлая; переключатель в заголовке и «Вид → Оформление». Тема действует на 3D-сцену, диалоги, графики; выбор запоминается.

#### 7.0.12. Плавающие и модальные окна

- Плавающее окно (один компонент): перетаскивание за заголовок, размер за угол, развернуть, закрыть; несколько окон, щёлкнутое — наверху; заголовок не уходит за пределы окна приложения. Размеры: компактный, средний, форма, обычный.

- Плавающие: гистограмма, Q-Q, дендрограмма, «Данные по скважинам», формы отображений («\<название\> (новое) · \<набор\>»), «Стволы · \<набор\>», «Устья · \<набор\>», «Блочная модель · \<модель\>», «Содержание–тоннаж · \<модель\>», «Проекты», «Настройка», «Claude: подключение». Заголовок графика — «\<имя графика\> · \<набор\>».

- Модальные: экспорт и импорт проекта, мастера импорта, экспорт OMF, журналы, диалоги операций моделирования.

#### 7.0.14. Критерии приёмки интерфейса

- При 1024 px все области видны без горизонтальной прокрутки; уже 1024 px окно не сжимается.

- Первый запуск: тёмная тема, открыты дерево (280 px) и «Свойства» (340 px), нижняя панель закрыта, вкладка «Главная», сетка включена, проекция ортогональная, преувеличение 1.

- Все кнопки 7.0.4 есть, подписаны и вызывают свои команды; недоступные — серые с причиной.

- Клавиши 7.0.6 работают в русской и английской раскладке; одиночные не срабатывают в поле ввода.

- Своё сочетание сохраняется после перезапуска и видно в подсказке ленты и в палитре.

- После перезапуска восстанавливаются панели и размеры, тема, видимость слоёв, проекция, проект, активный набор, скважина и таблица.

- В коде нет `window.confirm/prompt/alert` и системных окон сообщений.

- Команда Claude с `confirm` выполняется только после подтверждения; при отказе результат — «Пользователь отклонил действие».

- После остановки ядра строка состояния показывает «Нет связи с ядром» не позже чем через 15 с, оболочка перезапускает ядро.

- Повторный запуск `.exe` не создаёт второй экземпляр. Запрос к ядру без токена получает 401; с другого адреса ядро недоступно.

- Без сети работает всё, кроме ассистента.
