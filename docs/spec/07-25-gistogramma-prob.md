### 7.25. Гистограмма проб \[Э13\]

**Назначение.** Распределение и описательная статистика проб.

**Интерфейс.** Меню набора, «Пробы» или «Содержания»; «Анализ → Графики»; `chart.histogram {set_id, field, weight, weight_field, log, bin_width, bins, start, end, negatives, bottom_cut, bottom_mode, top_cut, top_mode}`. Плавающее окно, можно несколько.

| **Настройка** | **Варианты**                                                                                                                                                                                       |
|---------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Таблица, поле | Любая таблица опробования; компоненты, числовые атрибуты, длина интервала                                                                                                                          |
| Вес           | Без веса · длина интервала (по умолчанию) · поле · длина × поле (тоннаж, например с плотностью)                                                                                                    |
| Значения \< 0 | Оставить · половина предела (модуль/2 — для «\<0.01», записанных как −0.01) · исключить; отдельно — исключить нули                                                                                 |
| Отсечки       | Снизу и сверху: «исключить» или «заменить значением» (урезка сверху, подъём до предела снизу); по умолчанию снизу — исключить, сверху — урезать; статистика — после отсечек; параметры общие с Q-Q |
| Бины          | Линейная или логарифмическая шкала; авто, ширина (log10 для логарифмической) или число; диапазон «от — до»                                                                                         |
| Вид           | Ось Y: доля %, сумма весов, число проб; накопленная кривая; отметки среднего, медианы, P90, P97.5, отсечек; цвет                                                                                   |
| Экспорт       | PNG (вдвое крупнее экрана), SVG, CSV бинов                                                                                                                                                         |

**Статистика** с весом и без рядом: число, сумма весов, мин, макс, среднее, медиана, σ, дисперсия, CV, асимметрия, P5–P99, геометрическое среднее, среднее и дисперсия логарифмов. Взвешенные процентили — по GSLIB (середина накопленного веса); дисперсия генеральная.

**Хранение.** Сохранённый график с настройками — в наборе (7.28).

**Приёмка.** Взвешенное по длине среднее = Σ(cᵢ·lᵢ)/Σlᵢ. Верхняя отсечка «заменить» делает максимум равным отсечке при прежнем числе проб. PNG вдвое больше окна. Гистограмма по 5 млн проб строится.
