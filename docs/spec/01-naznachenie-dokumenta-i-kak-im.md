## 1. Назначение документа и как им пользоваться

### 1.1. Что это

- Техническое задание (ТЗ) на разработку с нуля desktop-ГГИС **«BedrockForge 2»** (далее **BF2**) для Windows 11.

- ТЗ написано для ИИ-исполнителя — **Claude Code в облачной сессии claude.ai/code** — и выполняется **одним запросом**: мастер-промт (Приложение А) + этот документ.

- Основа ТЗ — анализ текущей ГГИС **BedrockForge** (далее **BF**): код ветки `base-functional` (коммит `7ec289c`), 19 веток git, 14 PR, 31 сессия разработки 14–16.11.2026.

- Документ состоит из трёх частей:

| **Часть**                      | **Для кого**                | **Содержание**                                                                                                            |
|--------------------------------|-----------------------------|---------------------------------------------------------------------------------------------------------------------------|
| I. Подготовка и запуск         | Заказчик                    | Как запустить работу, принятые решения, итоги анализа BF                                                                  |
| II\. Техническое задание       | Исполнитель (ИИ)            | Требования к системе, архитектура, функции, форматы, качество, этапы и приёмка                                            |
| III\. Регламент ИИ-исполнителя | Исполнитель (ИИ) и заказчик | Модели и уровень усилий, экономия токенов, восстановление после лимитов, git/PR/CI, правила                               |
| Приложения                     | Оба                         | Мастер-промт, промт возобновления, шаблоны CLAUDE.md и PROGRESS.md, субагенты, настройки, карта переиспользования кода BF |

### 1.2. Порядок запуска (для заказчика)

| **№** | **Действие**                                                                                                                                 | **Где**                     | **Результат**                              |
|-------|----------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------|--------------------------------------------|
| 1     | Создать пустой приватный репозиторий, например `bandurkin-ai/BedrockForge2`, с веткой `main`                                                 | github.com                  | Репозиторий BF2                            |
| 2     | Положить этот файл в `docs/TZ/BF2-TZ.docx` и закоммитить в `main`                                                                            | GitHub, «Add file → Upload» | ТЗ в репозитории                           |
| 3     | Убедиться, что приложение Claude для GitHub имеет доступ к `BedrockForge2` и `BedrockForge`                                                  | github.com/apps/claude      | Сессия видит оба репозитория               |
| 4     | Создать облачное окружение для `BedrockForge2` (сеть: по умолчанию + `github.com`, `objects.githubusercontent.com`)                          | claude.ai/code → окружение  | Окружение BF2                              |
| 5     | Открыть новую облачную сессию на `BedrockForge2`, добавить к ней `BedrockForge` (только чтение)                                              | claude.ai/code              | Сессия готова                              |
| 6     | Выбрать модель и усилия: `/model opus`, `/effort high`; при желании `/autocompact 400k`                                                      | Строка ввода сессии         | Основная сессия на Opus 5.5, high          |
| 7     | Вставить мастер-промт (Приложение А) целиком и отправить                                                                                     | Строка ввода                | ИИ начинает этап Э0                        |
| 8     | На каждой вехе (В1–В6) скачать `.exe` из GitHub Actions/Releases, проверить по чек-листу из отчёта, ответить «Принято» или списком замечаний | ПК с Windows 11             | Веха принята                               |
| 9     | Начать следующую веху в **новой** сессии: шаг 5–6 и промт возобновления (Приложение Б)                                                       | claude.ai/code              | Новая веха с чистым контекстом             |
| 10    | Если работа остановилась из-за лимита и сама не продолжилась — после времени сброса отправить промт возобновления                            | Та же сессия                | Работа продолжается с последнего чекпойнта |

### 1.3. Что заказчик делает сам

- Приёмка вех на своём ПК (Windows 11, 16 ГБ ОЗУ, встроенная графика).

- Ответы на вопросы ИИ, если тот остановился с блокером (их список всегда в `PROGRESS.md`, раздел «Блокеры»).

- Контроль расхода: `/usage` раз в день; при недельном расходе \> 75 % — решение о режиме экономии (раздел 13.4).

- Выпуск файлов лицензий утилитой `bf-license` (появится на этапе Э24); закрытый ключ хранится только у заказчика.

- Покупка сертификата подписи кода — по желанию (без него Windows SmartScreen предупреждает «Неизвестный издатель»).
