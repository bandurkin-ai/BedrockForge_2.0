### 8.8. Оценка содержаний \[Э18\]

#### 8.8.1. Методы

Запись оценок в блочную модель и проверка оценки. Закрывает CHECKLIST № 320–329, 333, 334.

| **Метод**       | **Суть**                                                                                                                                                                                                                                                                                                                                                 |
|-----------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Ближайший сосед | Значение ближайшей пробы по расстоянию поиска (при равенстве — меньший номер)                                                                                                                                                                                                                                                                            |
| IDW             | z\* = Σ w_i·z_i / Σ w_i, w_i = 1/h_i^p, h_i — анизотропное расстояние поиска; h_i \< 1e−9·r1 — среднее совпадающих проб (как BF `idw`)                                                                                                                                                                                                                   |
| SK, OK          | Простой (среднее m — декластерированное среднее домена или заданное) и ординарный; точечный или блочный                                                                                                                                                                                                                                                  |
| Индикаторный    | Пороги z_1 \< … \< z_K, i_k = \[z ≤ z_k\], OK по индикаторам (модель на порог или одна — медианный IK); поправка порядка GSLIB (обрезка в \[0; 1\], среднее поправок вверх и вниз); поля P_k и E-type = Σ (F_k − F\_(k−1))·m_k, m_k — декластерированное среднее проб класса                                                                             |
| SGS \[Э18б\]    | Нормальные оценки (с весами декластеризации) → случайный путь по родителям (зерно) → SK со средним 0 по пробам (n_max 24) и смоделированным узлам (12) → BF `backtr` → N реализаций (20, float32, Parquet); реализации параллельно, каждая последовательно; постобработка — BF `local_expectation`, `local_std`, `local_percentile`, `local_prob_exceed` |

#### 8.8.2. Кригинг, поиск, домены

    SK:  Σ_j λ_j·C_ij = C̄_iV;              z* = m + Σ λ_i·(z_i − m);   σ²_SK = C̄_VV − Σ λ_i·C̄_iV
    OK:  Σ_j λ_j·C_ij + μ = C̄_iV, Σ λ_j = 1;  z* = Σ λ_i·z_i;          σ²_OK = C̄_VV − Σ λ_i·C̄_iV − μ
    C_ij = C(x_i − x_j), C(0) = C0 + Σ c_s (8.6.3); дискретизация: N = nx·ny·nz точек u_k в центрах подъячеек блока
      N = 1: C̄_iV = C(x_i − x_0), C̄_VV = C(0)
      N > 1: C̄_iV = (1/N)·Σ_k C*(x_i − u_k), C̄_VV = (1/N²)·Σ_k Σ_l C*(u_k − u_l); C* — без самородка, C*(0) = Σ c_s
             (соглашение GSLIB kb2d/kt3d); C̄_VV считается один раз на размер блока
    наклон регрессии b = Σ λ_i·C̄_iV / (Σ λ_i·C̄_iV − μ) = (BV − KV − μ)/(BV − KV − 2μ), BV = C̄_VV, KV = σ²_OK; для SK b = 1
    эффективность KE = (BV − KV)/BV
    LU с выбором главного элемента (numba, n ≤ 129); главный элемент < 1e−12·C(0) — блок не оценивается в проходе (журнал)
    пробы одного домена с совпадающими координатами (≤ 1e−6 м) усредняются до расчёта (число — в журнал)
    эллипсоид поиска: ang1–ang3, r1–r3; h_s = ‖diag(1, r1/r2, r1/r3)·R_s·Δ‖, проба внутри при h_s ≤ r1
    кандидаты: cKDTree в координатах, где эллипсоид — шар; k_c = max(4·n_max, 64) ближайших в радиусе r1;
      если после ограничений проб < n_max, а k_c-е расстояние < r1 — повтор с k_c × 4
    отбор по h_s (при равенстве — по номеру): n_min ≤ n ≤ n_max; ≤ n_скв проб скважины; ≤ n_окт в октанте и ≥ k_окт октантов
      (октанты — в осях эллипсоида); ≥ n_скв_min скважин
    проходы 1…P (P ≤ 5): радиусы по умолчанию ×1, ×2, ×3 и свои ограничения; блок оценивается первым проходом, где ограничения выполнены

- Жёсткая граница: блок домена D — только пробы D. Мягкая: для D — список доменов S и расстояние d_м; проба S допускается, если расстояние до центра блока ≤ d_м (по умолчанию 0 — жёсткая).

- Субблоки: по умолчанию оценка по родителю — для каждого домена D в родителе P оценка в центре P с дискретизацией P, все субблоки P домена D получают её; вариант — каждый субблок со своей дискретизацией.

- План оценки — строки «домен × поле × метод × параметры» одним заданием; строка — объект «Параметры оценки» с повторным запуском.

Выходные поля (префикс задаёт пользователь, например AU_OK\_): EST — оценка; KV — дисперсия кригинга; NS, NH — число проб и скважин; AD, DMIN — среднее и наименьшее расстояние до проб; PASS — проход; SLOPE, KE, LAGR — наклон регрессии, эффективность, μ; SNW — сумма отрицательных весов; NOCT — заполненные октанты.

| **Параметр**             | **По умолчанию**             | **Диапазон**     |
|--------------------------|------------------------------|------------------|
| Степень IDW p            | 2                            | 0,5–5            |
| Дискретизация            | 4×4×2                        | 1–10 по оси      |
| n_min / n_max (проход 1) | 4 / 24                       | 1–128            |
| n_скв; n_окт / k_окт     | 0 (выкл.); 0 / 0 (выкл.)     | 0–64; 1–16 / 1–8 |
| Радиусы                  | дальности модели вариограммы | \> 0             |

#### 8.8.3. Проверка оценки

| **Функция**              | **Суть**                                                                                                                                                                                                                                                                                                                     |
|--------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Перекрёстная проверка    | Исключение пробы или скважины (по умолчанию), те же параметры. Таблица: истинное, оценка, ошибка, KV, ошибка/√KV; сводка: средняя ошибка, СКО, MAE, r, наклон «истинное на оценку», среднее (ошибка²/KV); рассеяние, гистограмма ошибок, ошибки в 3D                                                                         |
| Анализ окрестности (KNA) | Тестовые блоки — щелчком или три автоматически (много, средне, мало проб); перебор n_max 4…64 шагом 4, радиусов ×0,5…×2, дискретизации 1…5, размера блока; показатели KE, SLOPE, KV, сумма отрицательных весов, вес дальней пробы, μ. #### 8.8.4. Интерфейс, данные, производительность

«Геостатистика»: «Оценка» — Оценка содержаний (мастер), План оценки, Эллипсоид поиска в 3D; «Проверка» — Перекрёстная проверка, Анализ окрестности, Swath plot, Глобальная статистика, Q-Q; «Моделирование» — SGS, Индикаторы. Мастер: модель, ограничитель, поля назначения → пробы (таблица, поле, домен, урезка, веса) → метод и модель вариограммы → поиск и проходы (в 3D у выбранного блока — эллипсоид, отобранные пробы и их веса) → выходные поля → задание. В проекте: «Параметры оценки», результаты проверок (Parquet), реализации SGS.
