# Фирменный стиль BedrockForge

Источник: доска «Brand Concept Board — Concept 6» (`concept-6.webp`), утверждена заказчиком 2026-11-17 для
приложения и **всех выпусков**. Решение и лицензии шрифтов — ADR 0006.

## Знак и название

| Файл | Где используется |
|---|---|
| `logo-mark.png` | Знак-куб «B» с прозрачным фоном (вырезан с доски); заголовок окна, заставка, пустое 3D-окно |
| `app-icon-256.png` | Иконка приложения 256 px (скруглённый квадрат); из неё собран `app/assets/icon.ico` (16–256 px) |
| `concept-6.webp` | Исходная доска: палитра, шрифты, примеры |

- Название: **Bedrock** — Anthracite (на тёмном фоне — Light Stone), **Forge** — Copper Orange; ниже «by Mikhail Bandurkin».
- Слоган: «Explore. Model. Plan. Mine.»; в интерфейсе по-русски: «Геологическое моделирование · Планирование горных работ · Разведка».
- Знак не перекрашивать и не растягивать; минимальная высота — 24 px.
- Векторный знак и иконка высокого разрешения — по получении от заказчика (сейчас — растр с доски).

## Палитра

| Цвет | HEX | Назначение | Токен интерфейса |
|---|---|---|---|
| Anthracite | `#1B222B` | Основной тёмный, фон, текст на светлом | `--bg-elev` (тёмная), `--text` (светлая) |
| Cobalt | `#1F6BFF` | Акцент: выбор, ссылки, данные, модели | `--accent` |
| Copper Orange | `#F46A1A` | Выделение, оруденение, активные вкладки, «Forge» | `--highlight`, `--brand-orange` |
| Light Stone | `#E6E9EE` | Поверхности, панели, текст на тёмном | `--text` (тёмная), `--bg` (светлая) |
| Slate | `#8A99A8` | Вторичный текст, рамки, значки | `--text-dim` (тёмная), `--border-strong` (светлая) |

Токены обеих тем — `ui/src/styles/tokens.css`; заставка — `app/static/splash.css`.

## Шрифты

| Шрифт | Где | Пакет |
|---|---|---|
| Montserrat 500/600/700 | Заголовки, название, вкладки, подписи данных | `@fontsource/montserrat` (OFL-1.1) |
| Inter 400/500/600 | Текст, метки, интерфейс | `@fontsource/inter` (OFL-1.1) |

Шрифты встроены в приложение (работает офлайн); тексты лицензий — `app/static/fonts/OFL-*.txt`.

## Выпуски (каждый)

- [ ] `.exe` и установщик — с иконкой `app/assets/icon.ico` (electron-builder берёт её из `buildResources`).
- [ ] Заставка и заголовок окна — знак и название в фирменных цветах.
- [ ] Описание выпуска на GitHub начинается со строки «**Bedrock**Forge by Mikhail Bandurkin — <версия>» и слогана;
  к выпуску прикладывается `app-icon-256.png` при первом выпуске вехи.
- [ ] Снимки экрана в отчёте вехи — в тёмной теме с фирменной палитрой.
