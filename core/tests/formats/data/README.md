# Test data of `tests/formats`

Synthetic files only (no customer data).

- `book.xls` — Excel 97-2003 workbook (BIFF8 in an OLE2 container), written by LibreOffice:
  `python make_book.py book.xlsx && soffice --headless --convert-to xls book.xlsx`.
  Sheets «Пусто» (empty), «Устья» (title row, header, numbers, text numbers, dates, a boolean,
  an error cell `#N/A`, codes with leading zeros), «Замеры» (times). xlrd cannot write, so the file
  is kept in the repository; everything else is generated by the tests.
